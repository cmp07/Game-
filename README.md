# Sandpile Tycoon

Steam idle particle/resource tycoon — a desktop Godot game.

Inspired by Particool-like particle idle games, with original IP, systems, and presentation. Players grow, shape, and automate particle sandpiles into a resource empire.

## Layout

- `game/` — Godot 4 project and game code
- `docs/` — design notes, Steam checklist, GDD
- `research/` — references and competitive notes

## Stack

- Godot 4 (desktop / Steam)
- Windows-first development
