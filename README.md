# Game- (cmp07)

Planning and production workspace for a sequence of **small, separate Steam desktop games** (real Windows `.exe`, not browser) priced roughly **$2.99–$9.99**.

**Start here:** [`docs/GAME_PLAN.md`](docs/GAME_PLAN.md)  
**Market deep dive:** [`docs/research/MARKET_DEEP_DIVE.md`](docs/research/MARKET_DEEP_DIVE.md)

## Strategy (short) — revised

- **One pure category per product** — do not mash genres into a hybrid “first game.”
- **Sequential small Steam releases**, not one mega-scope title:
  1. **Idle / incremental** (recommended Game 1 — **confirm before production**)
  2. Systems / automation (TFWR lane, scoped)
  3. Non-poker synergy toy *or* coin-machine
- Research scores & comps: [`docs/research/CATEGORY_RANKING.md`](docs/research/CATEGORY_RANKING.md)
