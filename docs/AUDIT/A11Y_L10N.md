# Audit — Accessibility + Localization vs RELEASE

**Scope:** Cloud-only static audit of `game/echo_lattice` against [`docs/RELEASE/ACCESSIBILITY.md`](../RELEASE/ACCESSIBILITY.md) and [`docs/RELEASE/LOCALIZATION.md`](../RELEASE/LOCALIZATION.md) (companions: Deck / store / FAQ / compliance).  
**Base:** `cursor/echo-lattice-rc1` @ `03e9a7a`  
**Method:** Source + catalog + Python validators (`validate_locale.py`, `test_a11y_settings.py`). No Godot binary / no Deck hardware in this pass.  
**Verdict:** Core a11y **services and settings surface exist** and unit smoke is green, but RELEASE “ship / ✅” claims overstate end-to-end completeness. Localization catalog parity is green for chambers + main chrome; **settings, subtitles, glyphs, and demo copy are largely unkeyed**. **CJK font is not vendored** — `zh_Hans` will tofu on Deck / minimal Windows.

## 2. CJK font vendoring gap

| Check | Result |
|---|---|
| Planned path | `game/echo_lattice/fonts/cjk/NotoSansSC-Regular.otf` (OFL) |
| Repo contents | `fonts/cjk/.gitkeep` only — **no `.otf`/`.ttf`, no `OFL.txt`** |
| `.gitignore` | Explicitly ignores `fonts/cjk/*.{otf,ttf,ttc,otc}` (and latin faces) |
| Runtime | `LocaleManager._apply_font_for_locale` loads first candidate; else `push_warning` and Latin fallback → **Han tofu** |
| Compliance | `COMPLIANCE_FINAL.md` credits Inter / IBM Plex / Noto **Serif** — **does not list Noto Sans SC** |

**Ship blocker for Simplified Chinese:** without a vendored face (or a CI fetch + depot include), zh_Hans is translation-only. LOCALIZATION test plan items “with Noto Sans SC vendored” / “without font warning once” are unchecked and still accurate.

Latin stack under `fonts/latin/` is also empty — Godot default until compliance C8 clears; secondary to CJK for this audit.

## 3. A11y end-to-end holes (colorblind / flash / remap / subtitles / UI scale)

### 3.1 Colorblind — mostly wired

**Works:** Settings → `AccessibilityService.set_colorblind_mode` → `role_color` / `fossil_style_changed` → chamber redraw; patterns via `_draw_role_pattern` on echo walls, overuse, chalk trail, ghost assist. Selftest asserts protan echo ≠ default rust.

**Holes:**

- Pattern cues **not** drawn on checkpoint stamps / goal (color-only chrome for those roles).
- Mode + pattern labels untranslated (§1).
- No automated contrast / grayscale audit beyond hex count in `test_a11y_settings.py`.
- ACR / Deck manual checklists in RELEASE remain unchecked (no sign-off dates).

### 3.2 Reduce flash / motion — rewrite path

**Works:** `Juice.flash` → `FlashGate.gate`; reduce-flash caps ≤0.25 + desaturate; chamber rewrite margin heartbeat skipped when `_reduce_flash()`; reduce-motion forces shake off + short-circuits slam hitstop.

**Mitigated:** `Juice.rewrite_punch` no longer calls full-screen flash (Field Ledger reserves cadmium for the page-margin heartbeat). Double-gate hole is gone for rewrite. Shake defaults off.

### 3.3 Remap — keyboard only; prompts desynced

**Works:** Settings rebind listens for keys; `ActionRemap` steals conflicts; joypad buttons + stick axes reattached after keyboard erase; bindings in `user://echo_lattice_settings.json`.

**Holes:**

| Gap | Detail |
|---|---|
| No gamepad rebind | ACR “configurable controls” is keyboard-only; pad map fixed in `GAMEPAD_DEFAULTS` |
| Glyphs ignore remap | `InputGlyphs` hardcodes Z/R/Esc (KBM) and X/Y/Start (pad) — rebinding Undo to `U` still shows `Z` on HUD/footer |
| Footer never uses remap labels | See §1.3 `last_device >= 0` |
| Confirm omitted from Settings rows | `confirm` skipped in `_build_binding_rows` (intentional?) — players cannot rebind confirm from UI |
| Selftest weak | Only checks `ghost_assist` exists + undo labels non-empty — does **not** rebind a key and assert pad X still undoes |

### 3.4 Subtitles — EN stubs; background incomplete

**Works:** Overlay instanced from `main.gd`; size small/medium/large; PA announcer + chamber rewrite/win/assist call `show_line`; toggle + size in Settings.

**Holes:**

| Gap | Detail |
|---|---|
| No `tr()` | `STUB_LINES` English constants |
| No subtitle-background UX | Setting exists in JSON + `subtitle_background()` getter + style path, but **no** `set_subtitle_background`, **no** Settings checkbox |
| Large @ Deck bezel | RELEASE manual item unchecked; overlay is bottom `CanvasLayer` — no automated bezel clearance test |
| zh_Hans + missing CJK font | Even if stubbed into CSV, glyphs tofu until §2 fixed |

### 3.5 UI scale — apply path thin

**Works:** Slider 0.85–1.5 → `AccessibilityService.set_ui_scale` → `Window.content_scale_factor` (skipped on headless). Settings content lives in a `ScrollContainer` (helps overflow).

**Holes:**

- Selftest only asserts `ui_scale()` value, **not** that the window factor changed (and cannot on headless).
- No `--deck-layout-check` / layout_report run at scale **1.25** / **1.5** in CI (DeckProfile layout check exists but is scale-agnostic in docs).
- Interaction with stretch mode `canvas_items` + Deck fullscreen not documented as verified.
- Settings chrome itself does not reflow labels under CJK width at 1.25 (blocked on font + tr anyway).

| Expected (Deck / ACR) | Actual |
|---|---|

## 5. Priority fix list (engineering)

Ordered for RC1 / Next Fest honesty:

1. **Vendor Noto Sans SC** (or CI fetch) + `OFL.txt` + compliance credit — unblock zh_Hans rendering.
2. **Key Settings + FossilPalette + ActionRemap display strings + SubtitleOverlay stubs** into CSV; call `tr()`; listen to `locale_changed` on settings / chamber / end.
3. **Wire language OptionButton** in Settings using existing `locale.*` keys → `LocaleManager.apply_locale`.
4. **Fix InputGlyphs**:
   - Keyboard labels from `ActionRemap.get_binding_labels`
   - Localized templates (`hud.restart` style `%s`)
   - Include ghost-assist / confirm where shown
   - Fix menu footer condition so EN `tr("menu.controls_hint")` is not dead code
5. **Fix `rewrite_punch` double FlashGate**.
6. **Add `set_subtitle_background` + Settings toggle** (or drop the setting from defaults/docs).
7. **Glyph art or honest docs**: either ship textured glyphs + store Controllers tag, or downgrade `STEAM_DECK.md` “Implemented” and keep FAQ Week-1 framing.
8. **Align SUPPORT_FAQ A2** with shipping `zh_Hans`.
9. Extend `validate_locale.py` to fail on known unkeyed surfaces (settings scene texts / `STUB_LINES` keys) once keys land.
10. Deck QA: UI scale 1.25 + Protanopia + reduce-flash chamber + large subtitles — fill ACCESSIBILITY sign-off table.
