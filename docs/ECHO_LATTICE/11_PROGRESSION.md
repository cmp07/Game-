## 0. Thesis

Progression in Echo Lattice is **becoming more legible to yourself**. Chambers teach rewrite grammar; meta modes pressure and archive handwriting; stars measure cleanliness — nothing gates the story behind grind.

**One-sentence spine:**

```
walk → fossilize → name → pressure → archive → race
```

**Weaver rule:** progression UI and rewards must obey Field Ledger materials ([`09_VISUAL.md`](09_VISUAL.md)) and institutional audio ([`10_AUDIO.md`](10_AUDIO.md)). If a reward needs neon meters, XP bars, or loot toast to feel “real,” it is the wrong reward.

| Banned | Why |
|---|---|
| Battle pass, season drip, FOMO energy meters | Wrong product; breaks offline-first |

## 2. What “progress” means (four layers)

| Layer | Player feels | Systems | Must not become |
|---|---|---|---|
| **Curriculum** | “I learned a rewrite idea” | Campaign acts I–IV; teach → remix → identity boss | Content bloat / clone maps |
| **Portrait** | “It read how I walk” | HabitSignature → archetype READ; Echo Card; identity stamps | Stat-strip therapy speak |
| **Mastery** | “Cleaner handwriting” | Stars vs BFS par; Hard+ purification; undo/rewind fairness | DPS gear treadmill |
| **Memory** | “I can see who I was” | Museum selves; ghost race; Daily appointment | Graveyard UI with no race-back |

If a feature does not feed one of these four, it is out of progression scope.

## 3. Campaign craft (curriculum)

Authority: content bible + balance act table + chamber standard.

| Act | Job | Balance id | Craft gate |
|---|---|---|---|
| I Induction | Silence → first rewrite → base ops | SEED | Demo path sacred; hush + paper sparse |
| II Reflection | Dual-axis literacy → portrait | GROWTH | Identity boss readable as portrait |
| III Pressure | Habits hurt; multi-commit nets | PRISM | Pressure from *bias*, not HP |
| IV Mastery | Compose + sign | MASTERY | Nameplate / Open Lattice feel authored |

**Chamber roles:** each map teaches **one** idea, then remixes. Exact geometry clones fail craft ([`../AUDIT/CONTENT_CHAMBERS.md`](../AUDIT/CONTENT_CHAMBERS.md)).

**Continue default (META v3):** after Mirror Birth, prefer Short Run (≈3 chambers, 8–15 min) so the book does not intimidate. Full campaign remains available — not deleted, just not the only “real” path.

**Hard fence:** Hard variants unlock from parent clear only; honest `hard_variant_of`; measurable tighten. Demo stays Hard+-off.

## 4. Habit → geometry progression (the real skill tree)

There is no skill tree. The lattice *is* the tree.

| Stage | Craft requirement |
|---|---|
| Walk / buffer | Punch-card ribbon + chalk ghost encode the last moves |
| Checkpoint commit | Telegraph ≤3 steps; slam phrase + origami (visual/audio lock) |
| Forced transform | Pedagogy spine — still the lesson even when habit cells add |
| Habit cells (V3) | Soft TEACH before hard CALCIFY; evidence cells diegetic |
| Identity / Mirror Birth | Ceremony scarce; stamp grade as drama, not live DPS meter |
| Echo Card | Names archetype in plain language (“You leaned right.”) |

**North-star line (Act II):** *“It punished my looping.”* — said without reading jargon.

Determinism + BFS solvability remain non-negotiable. Score bias never bricks a clear.

## 6. Stars & fairness craft

| Rule | Craft |
|---|---|
| 1★ any legal clear | Celebration = ledger stamp, not fireworks |
| 2★ / 3★ vs BFS par (+ act/mode slack) | Shown on Echo Card + chamber card as ink stars |
| Best-of ledger | Re-clear with fewer stars never lowers best |
| Anti-frustration | Undo / rewind / STALLED ≠ Game Over; restart ≤1 intentional input |
| Telemetry | Local JSONL only; tunes clear rates, never shames the player in UI |

Target clear-rate bands stay in [`14_BALANCE_V2.md`](14_BALANCE_V2.md). Progression craft fails if players believe the game cheated.

## 8. Echo Card — glue moment checklist

Every clear (all modes), before Advance / Menu:

1. Archetype title (Museum-shared strings)  
2. Dominant bias % + one plain sentence  
3. Stars vs par  
4. One contextual CTA (Continue / friend code / climb / compare / race delta)  

**Visual:** loose ledger page, stamp numerals, rust rules — [`09_VISUAL.md`](09_VISUAL.md) G2/G5.  
**Audio:** soft stamp + open queue-next hunger — [`10_AUDIO.md`](10_AUDIO.md) §7.  

Without Echo Card, modes feel like add-ons and Museum stays a graveyard.

## 11. Acceptance playtest (one evening session)

1. **Cold path** — boot → title → Quiet Span → Mirror Birth; feel taught, not graded.  
2. **Clear** — Echo Card names a bias in plain speech; CTA is obvious.  
3. **Short sitting** — 8–15 min Short Run or Daily completes without meta overwhelm.  
4. **Museum** — archive visible; race (when shipped) re-enters a chamber.  
5. **Star re-clear** — fewer stars do not erase best; no unlock brick.  
6. **Eyes + ears** — no XP bar, no purple level-up, no brass parade; paper + institutional hush only.
