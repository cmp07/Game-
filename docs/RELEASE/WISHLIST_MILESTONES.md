## Conversion hygiene

- Steam news at every tier (not only social).
- One clearest CTA per post: Wishlist **or** Demo — not both fighting.
- Put the slam GIF in the first Steam screenshot slot after the menu lockup.
- Next Fest / festivals: treat as a separate milestone column, not a replacement for the ladder.
