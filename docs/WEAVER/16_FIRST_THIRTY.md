---

## 1. Thesis

> In thirty minutes the player does not *learn a genre* — they **touch material, tension a line, and leave one Structure that still stands when they look back.**

| Arc | Clock | Feeling |
|---|---|---|
| Material literacy | 0:00–8:00 | Fragments are stuff, not loot icons |
| Line literacy | 8:00–16:00 | Threads carry load; slack and snap read |
| Authorship ceremony | 16:00–24:00 | First Structure that *does a job* |
| World answer | 24:00–28:00 | The field notices; one readable consequence |
| Desire close | 28:00–30:00 | One CTA / one next-session hook — no dump |

**Hard gates for any vertical slice claiming “first thirty”**

- First **useful Structure** (not a tutorial prop) by **≤24:00**.
- Zero mandatory multiplayer, trade, or account gates in this window.
- No wall-of-text lore; captions teach, one coach line max per beat.
- No purple-void / neon-time aesthetic — materials read as fiber, dust, timber, wire, chalk, rusted hardware.

## 2. Fantasy contract (what the thirty minutes sells)

| Sell | Do not sell yet |
|---|---|
| Gather → spin → tension → Structure that works | Full economy, player auction houses, guild politics |
| Physics / load / slack as the judge | Combat mastery, skill trees, RNG rarity chase |
| One place that remembers your work | Open-world tourism, biome checklist |
| Quiet craft identity | “AI worldbuilder” pitch, purple chronomancy |

**Motion budget (≥3 intentional motions):** (1) Fragment settle into palm/bin with weight, (2) Thread draw with audible tension climb, (3) Structure lock — joints bite, dust falls, camera holds. Supporting: footfalls, wind in loose fiber, one world-answer cue when the field reacts.

## 3. Minute-by-minute spine

Clock starts at **first interactive frame** after boot fade.

### 0:00–3:00 · Boot & brand

| t | Event |
|---|---|
| 0:00–0:40 | Atmosphere first: loom-shed light, fiber dust in a shaft of sun / lamp. Brand is hero-level; no dashboard. |
| 0:40–1:30 | One headline + one sentence + one CTA (**Begin** / **Continue**). No stats strip. |
| 1:30–3:00 | Enter the **Shed Yard** — small, readable, edge-to-edge place. Hands free. Camera teaches scale.

### 3:00–8:00 · Fragments (material literacy)

| Beat | Goal |
|---|---|
| Find 3 Fragment types | Distinct materials (e.g. reed, copper scrap, chalk grit) — **not** rarity tiers |
| One failed gather | Wrong tool or weak tug; teach weight without a tip spam |
| Bin / spindle home | Fragments live somewhere tactile |

**Exit criterion:** Player can name (in their head) what each Fragment *wants to become* — soft, tensile, or stiff.

### 8:00–16:00 · Threads (line literacy)

| Beat | Goal |
|---|---|
| Spin first Thread | Hold-to-spin or draw-between-points; length and thickness readable |
| Slack demo | Loose line does nothing useful — comedy, not punishment |
| Tension demo | Load a post / weight; hear and see strain |
| Cut / re-pin once | Editing is part of craft, not a fail state |

**Exit criterion:** Player has routed one Thread that carries a trivial load (gate, pulley, rain deflector, signal flag — pick **one** job for the slice).

### 16:00–24:00 · Structures (authorship ceremony)

| Beat | Goal |
|---|---|
| Blueprint of one Structure | 3–6 parts max; no catalog dump |
| Assemble under gravity / tension rules | Physics judges; collapse is clip-friendly and fair |
| Lock / dedicate | Ceremony: Structure gets a name plate or chalk mark — **your** work |
| Use it once | Open a path, lift a weight, shelter a flame, ring a bell — **one** verb

**Exit criterion:** A Structure remains standing and useful. If it fell, rebuild path is ≤2 minutes and still lands the ceremony.

### 24:00–28:00 · World answer

| Beat | Goal |
|---|---|
| Field reaction | Wind shifts, dust path, NPC glance, light change, or distant echo — **one** readable answer |
| Echo of authorship | Optional ghost outline of your Thread paths — teach “the place learned a line” |
| Soft meta | One unlock for next session (new Fragment, new joint, new Yard corner) — **not** a skill tree

### 28:00–30:00 · Desire close

- Save is automatic and obvious.
- One line of desire copy (“The east post still won’t hold dawn wind.”).
- Demo builds: wishlist CTA only. Full game: quit-to-menu without a shop.

## 4. Pedagogy rules

| Do | Don’t |
|---|---|
| One job per beat; silence after success | Tip spam, floating badge clusters |
| Fail with material comedy | Soft-lock, invisible requirements |
| Teach cut/re-pin early | Punish experimentation |
| Hold camera 2–3s after first Structure lock | Smash-cut into economy UI |
| Keyboard/mouse **and** gamepad parity for draw/tension | Mouse-only precision gates |

**Stuck recovery:** If no Structure by 20:00, offer a single coach line + highlight the missing joint — never a multi-page tutorial.

---

## 5. Demo vs full-game first thirty

| Surface | Includes | Excludes |
|---|---|---|
| **Next Fest / wishlist demo** | Shed Yard, 3 Fragments, Thread literacy, **one** Structure job, world answer, CTA | Economy, multiplayer, Legacy meta, Act map |
| **1.0 cold start** | Same spine + one adjacent Yard corner tease | Player trade, seasons, full biome tour |

Shared rule: the first thirty minutes must still feel complete if the player never returns — a finished craft story, not a funnel stump.

---

## 6. Acceptance checks (playtest)

A cold player should answer **yes** to all:

1. Did I make something that *worked*?
2. Could I feel tension before I understood the UI words?
3. Would I show someone the collapse or the lock moment?
4. Do I know what I’d try next session in one sentence?

If any answer is no, cut systems — do not add tutorial slides.
