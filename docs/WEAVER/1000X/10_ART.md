**1000×** is not denser particle soup or a second art track. It is **one visual verb made undeniable** from title still → recover → bind → Tension seat → inhabit → residue:

## 1. Visual pillars (P1–P7)

Any asset that fails **two** pillars ships back.

| # | Pillar | Promise | Fail if… |
|---|---|---|---|
| **P1** | **Legibility above spectacle** | Diagram of craft: ports, load, gap readable in 5 s | Moodboard haze beats port glyphs |
| **P2** | **Fiber on page, not glow on void** | Warm bone / canvas substrate; ink seams; shed lamp | Clear color is black bag; bloom sells mystery |
| **P3** | **Seat, don’t radiate** | Tension = crease → lift → seat; stress = rust creep | Energy beams, portal swallow, confetti clear |
| **P4** | **Process visible** | Chalk scuff, ink pressure, saw-cut, stamp residue | Soft painterly “premium” with no tool marks |
| **P5** | **One person’s craft** | Residue / gallery is *your* silhouette — not loot chrome | Rarity borders, rainbow tiers, neon XP |
| **P6** | **Object honesty** | UI and world share shed physics: tags, underlines, thickness | Glass HUD, floating orbs, frosted panels |
| **P7** | **Cartographer’s honesty** | Every flourish names a systems fact (capacity, stress, gap) | Decorative particles with no job |

**Pillar one-liner:** show a mute greyscale frame; if you cannot name Survey → Recover → Bind → Tension from that frame, art owes P1 more work.

## 2. Anti-AI-slop — hard ban (enforceable)

Every rule below exists to stop Discord-banner / Midjourney-fantasy defaults. If a choice looks “premium” in isolation but matches the ban table, it is **wrong for Weaver**.

### 2.1 Banned looks

| Banned | Why it reads as slop | Replace with |
|---|---|---|
| Near-black / pure `#000` clear as “space” | Generative void plate | `page_bone` / `canvas_raw` + `shed_air` drop only behind tears |
| Neon / cosmic purple, violet bloom, magenta cyber | Gameslop + fights Fragment ban | Kiln rust / copper ≤10%; Pulse = brass/patina |
| Soft painterly haze, god-rays, volumetric aether | Enchantment language | Single practical lamp / skylight; hard-ish falloff |
| Circles / discs / orbs as default Fragment mesh | Node-editor cosplay | Family silhouettes (§5) |
| Neon Threads / hard-light bridges | RTS / sci-fi ghost build | Chalk slack → ink / waxed seam |
| Glassmorphism, frosted HUD, holographic rarity | OS chrome / loot ladder | Stamped tags, cardstock, underlines |
| Chronoshard / hourglass / “time fragment” icons | Banned Time lane | Pendulum, bellows, knocker — beat tools |
| Prefab house menu art / neon build ghosts | Wrong shelf | Stood-graph archetypes only |
| Echo Lattice maze chrome / film plates / punch-card habit UI | Separate SKU mash | Shed Yard loom ambient only |
| Multi-layer drop shadows + bloom stack | Fake depth | One contact shadow under lift |
| Idle UI breathe / pulse / tracking cinematic orbit | Template motion | Fiber draw, press-seat, dust settle, stamp |
| Cream + terracotta + purple accent mash | AI landing-page cluster | Locked palette §3 only |

### 2.2 Hex / hue ban (non-exhaustive)

Do **not** commit production art containing:

- Cosmic violets: `#7F00FF`, `#B026FF`, `#8A2BE2`, saturated “mystery” purple fills  
- Neon cyan, hot magenta, vaporwave grids, holographic foil  
- Lava-orange on pure black; TV-scanline green as identity  
- Pure `#000000` or pure `#FFFFFF` as clear / fill in shipped frames  
- Rainbow rarity gradients; chroma sparkle particle defaults  

**Anti-purple law:** if a beat “needs” violet to feel special, rewrite the tell (silhouette, brass tick, rust creep) — never the hue.

### 2.3 Prompt / gen hygiene (cloud + human)

When generating concept refs or placeholders:

| Do | Do not |
|---|---|
| Prompt: shed, loom, torn canvas, chalk survey, timber span, kiln copper, letterpress | Prompt: mystical void, ethereal, neon, cyber, portal, chronomancy |
| Reject plates with floating orbs / nebula | “Fix” with a brown LUT and ship |
| Prefer photo refs of workshops / textiles / print shops | Prefer fantasy key-art moodboards |

AI tools may **draft**; they may not **define** the look. Final authority is this bible + greyscale audit.

## 4. Materials atlas (workshop, not PBR fantasy)

Name materials the way a craftsperson would — **process + substrate**. Engine shaders simulate process; they do not import Unity stone packs.

### 4.1 Substrate stack (far → near)

| Layer | Material | Look | Notes |
|---|---|---|---|
| **0 · Shed air / drop** | Cool-neutral air through gap | `shed_air`; value −8…−12% from page | Clear **only** behind torn margin; no stars |
| **1 · Page / cloth** | Warm printer stock or raw canvas | Fiber grain; faint weave | ~60% of frame |
| **2 · Dust / chalk** | Provisional marks | Dashed slack fiber; survey ticks | Threads before Tension |
| **3 · Ink / seated seam** | Ruling pen / waxed thread | Taut; matte | Passed Tension |
| **4 · Timber / wire** | Span / Anchor / brace bodies | Greyscale-readable silhouettes | Craft ~25% |
| **5 · Kiln / brass** | Heat, Charge, Pulse beat, stress | Matte oxide; **emissive = 0** | ≤10% combined |
| **6 · Shed light** | Single lamp / skylight | Hard-ish falloff; dithered edge | No bloom stack |
| **7 · Apparatus / shell** | Stamps, tags, Yard objects | Material UI — never glass | Brand-first on title |

### 4.2 Material cards (artists / tech art)

**Field page (healthy)** — `page_bone`; micro fiber noise ≤12% opacity; no bevel; no AO puddle under avatar.

**Worn page** — `page_deep` where feet / carts pass; elliptical chalk scuffs; cap overlays before residue silhouette takes over.

**Frayed margin** — irregular tear into drop; fiber whiskers in `ink_soft`; chalk survey ticks; occasional nail holes from a failed prior span.

**Void drop** — cooler shed air; optional sparse dust ≤2%; **never** starfield, nebula, or purple fill.

**Provisional Thread** — dashed `chalk_mark` / slack fiber; slight sag; contact shadow only where it crosses the tear.

**Seated Thread** — taut `ink_seat` or waxed seam; thickness encodes load; `kiln_rust` creep when near overload.

**Illegal snap** — `snap_warn` / white flash → settle; culprit seam named by one glyph; no full-screen glitch.

**Span Fragment** — plank / cloth strip; end grain or weave; ports = stamped glyphs on body — **not** glowing sockets.

**Anchor Fragment** — peg / stake / weight; grounded mass; short cast shadow on page.

**Channel Fragment** — culvert / trough / duct; open section reads in greyscale.

**Charge Fragment** — spring / bladder / kiln-heart; compression reads stored push; warm body ok, emissive 0.

**Filter Fragment** — sieve / baffle / one-way flap; aperture is the tell.

**Pulse Fragment** — pendulum / bellows / knocker; beat accent = `brass_beat` / `patina_tick` only ([`21_FRAGMENT_FEEL.md`](../21_FRAGMENT_FEEL.md)).

**Structure seat** — crease in cloth/page → brief lift with contact shadow → seat with quiet weight. Walkable/usable law; no confetti.

**Yard / Shed hub** — same substrate family; loom / spindle / shelf as place-menu; gallery wall = local silhouettes, not social feed chrome.

**Shell tags / buttons** — stamped cardstock, underlines, punched holes; thickness + contact shadow; never neon pills.

### 4.3 Process-visible checklist (anti-slop moat)

Every shipped material should show at least one tool mark:

| Process | Residue |
|---|---|
| Chalk survey | Scuff, dashed ticks, soft edge |
| Ink / wax seat | Pressure squash, 0–1 px tremor |
| Timber work | Saw-cut end grain, wire twist |
| Kiln | Matte oxide, never emissive glow |
| Stamp | Uneven ink, 1–3° micro rotation |
| Fiber pull | Twist, slack sag, dust mote on settle |

AI moodboards emit glow. Workshops leave residue. **We ship residue.**

### 4.4 Material bans

- Normal-mapped dungeon stone, moss, blood, crystal, lava  
- Any emissive wall / floor / Fragment / UI panel  
- Glass, frost, blur panels, neon tubes  
- Soft painterly haze as a “material”  
- Prefab sci-fi hard-light

## 5. Object grammar (silhouettes first)

### 5.1 Fragments — six MVP families

| Family | V1 trap | 1000× tell | Greyscale test |
|---|---|---|---|
| **Span** | Horizontal capsule | Beam / plank / cloth strip; length = capacity | Long axis reads |
| **Anchor** | Filled circle | Peg / stake / weight | Grounded mass blob |
| **Channel** | Two circles as pipe | Culvert / trough / duct | Open section notch |
| **Charge** | Glowing orb | Spring / bladder / kiln-heart | Compression body |
| **Filter** | Ring / donut | Sieve / baffle / flap | Aperture pattern |
| **Pulse** | Pulsing disc | Pendulum / bellows / knocker | Beat tool outline |

Ports = **glyphs stamped on the body**. Capacity = thickness / stitch density — not DPS numbers. Seat = press into cloth/page — never catch-beam VFX. Recover settle per [`21_FRAGMENT_FEEL.md`](../21_FRAGMENT_FEEL.md).

### 5.2 Threads — fiber, not neon

| State | Look |
|---|---|
| Provisional | Dashed chalk / slack fiber; sag readable |
| Healthy seated | Taut ink / waxed seam |
| Approaching overload | Rust creep along the fiber |
| Illegal snap | Flash → settle; port conflict in one glyph |
| Tear | Gap at culprit — collapse comedy in one glance |

Drawing feels like **pulling fiber across a page**, not laying RTS power lines.

### 5.3 Structures — crease → lift → seat

Stood graphs only ([`05_STRUCTURES.md`](../05_STRUCTURES.md)). Archetypes (Span, Culvert, Kiln, Gate, Scaffold, Loom-mark) remix families — no prefab house menu art, no hard-light ghosts.

Stand juice: **crease → lift → seat** (quiet weight). Inhabit must read as law change (walkable span, opening gate, flowing channel) — not VFX costume.

### 5.4 Gap anatomy (void must show ≥3 tells)

1. Torn edge — fiber whiskers / deckle / splintered plank ends  
2. Value step — substrate → cooler `shed_air` (not pure black)  
3. Occlusion — Thread or Span casts a thin contact shadow across the tear  
4. Scale cue — dust, stitch length, or plank thickness  
5. Load-path scar — chalk ticks or nail holes from a prior failed span  

If the gap is only a darker rectangle, 1000× art has not landed.

## 6. Lighting bible — one lamp, paper thickness

Lighting sells **substrate thickness** and **one practical tool**. It must never sell magic.

### 6.1 Sources (complete list)

| Source | Color | Shape | Rules |
|---|---|---|---|
| **Page / shed ambient** | Near-flat warm | Full field | ±4% value drift; no vignette crush to black |
| **Yard lamp / skylight** | `lamp_warm` | Hard-ish disk or soft rectangle | **Only** persistent diegetic light; dithered falloff; no Gaussian bloom |
| **Snap warn** | `snap_warn` | Culprit / margin flash | ≤1 frame equivalent; nowhere else |
| **UI / shell** | Unlit | — | Stamped tags on cardstock; no dynamic lights on menus |

No second fill light. No purple bounce. No rim-light “premium.”

### 6.2 Falloff law (shed lamp)

```
intensity(d) =
  1.0                     if d ≤ inner (≈0.5 field units)
  lerp(1, 0.35, t)        through mid ring
  lerp(0.35, 0.0, t)      through outer ring
  0                       beyond — page stays readable via ambient
```

Edge is **ordered dither** into page (4×4 Bayer or blue-noise tile), never soft bloom. Outside the disk the page remains readable — accent, not horror flashlight.

### 6.3 Explicit lighting bans

- Screen-space bloom, god-rays, volumetric fog, lens flare  
- Colored rim lights, purple fill, neon tubes  
- Emissive Fragments or “powered” Thread glow  
- Ambient occlusion that turns the shed into a cave  
- Full-screen white flash on Tension (removed; do not reintroduce)

### 6.4 Depth from light + occlusion (not fog)

Depth is authored planes ([`25_VOID_ART_V2.md`](../25_VOID_ART_V2.md) §3) plus contact shadows during lift. Camera fog is forbidden as a mood plate.

## 7. Typography

Weaver is a **workshop document**, not a HUD skin. Type is part of the art direction.

### 7.1 Locked stack (three faces max)

| Role | Face direction | Where |
|---|---|---|
| **Display** | Condensed workshop grotesk (e.g. IBM Plex Sans Condensed or licensed equivalent) | Brand lockup **THE WEAVER**, field titles |
| **Body** | Newsprint / work-order serif (Plex Serif / PT Serif class) | Craft lines, settings, job copy |
| **Mono** | Grotesk mono (Plex Mono class) | Seeds, stamps, debug, port codes |

**Hard rules:** no Inter / Roboto / Arial as identity. No fourth “cute” display. No script. No variable-font tracking gimmicks. No neon outlined type.

### 7.2 Hierarchy

1. **Brand** — largest signal on shell (`THE WEAVER` or locked name from [`../31_NAME_LOCK.md`](../31_NAME_LOCK.md)).  
2. **Craft line** — one short supporting sentence.  
3. **CTA** — material object (stamped tag / underline), not a pill cluster.  
4. **Meta** — mono seed / stamp — never competing with brand size.

### 7.3 Type motion

- Stamp-in or paper-settle. **No** fade-from-black, blur-in, or cinematic tracking expand.  
- Nothing pulses or breathes. Paper is still; fiber, dust, and the weaver’s hand move.

## 9. Signature motions & VFX language

Ship **2–3 intentional motions** on shell + Tension. Physics readability > particle noise.

### 9.1 Allowed / forbidden

| Allowed | Forbidden |
|---|---|
| Fiber draw, chalk slack, press-seat, dust settle, stamp residue | Idle breathe, tracking orbit, chromatic explosion |
| Crease → lift → seat with contact shadow | Portal swallow, warp bloom, confetti clear |
| Illegal snap + settle naming culprit | Full-screen glitch / RGB split |
| Reduce-motion → hard seat / cut | Ugly time-stretch of physics |

### 9.2 Tension seat (visual half — locked)

| Stage | Must show | Must not |
|---|---|---|
| Pull | Fiber across gap; chalk slack | Energy beam |
| Crease | Cloth/page gathers at pins | Screen warp |
| Lift | Brief cast shadow / weight | Rim-light magic |
| Seat | Seam locks; Structure becomes law | Portal, confetti, XP fanfare |
| Stress tell | Rust creep if near fail | Floating red DPS |

Sync earprint with [`../10_AUDIO.md`](../10_AUDIO.md) / [`../26_AUDIO_V2.md`](../26_AUDIO_V2.md). Progression never paints Tension as level-up ([`../11_PROGRESSION.md`](../11_PROGRESSION.md)).

### 9.3 Particle budget

Particles encode **craft residue** (chalk grit, fiber mote, kiln dust) — not sparkle. If a particle cannot name the systems fact it shows, cut it.

### 9.4 Shader constraints (Godot 4 target)

| Rule | Spec |
|---|---|
| Bloom | **Off** for identity look |
| Fog / god-rays | **Forbidden** |
| Grain | One tiled grain, `ink_soft` family, ≤8% opacity, screen-locked preferred |
| Lamp | Hard falloff + dither mask — not Gaussian glow |
| Emissive | Playfield materials = **0** |
| Deck class | Integrated GPU / Steam Deck–class; no SM 6.0 requirement |

Concrete shader inventory lives with tech-art siblings; this bible owns the **look contracts** they must satisfy.
