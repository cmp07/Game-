## 0. Thesis

1000× progression is **not** more XP, more seasons, or a taller loot ladder. It is a **content graph** the player *walks with their hands* — each node a craft noun they can name — where depth comes from literacy, authorship, and memory.

```
Phase I Hands → II Stitch → III Seat → IV Yard → V Memory
         (content graph expands; session scarcity stays tight; grind stays banned)
```

**Player line:** *“I got better at the loom — the yard didn’t grind me.”*

**Weaver rule:** every phase unlocks a **new craft sentence**, never a level number. Celebration materials stay with visual/audio craft ([`../09_VISUAL.md`](../09_VISUAL.md), [`../10_AUDIO.md`](../10_AUDIO.md), [`../26_AUDIO_V2.md`](../26_AUDIO_V2.md)).

**Authority note:** MVP cuts in [`../17_MVP.md`](../17_MVP.md) win until slice metrics clear. Phases IV–V schedule ecology / Legacy evolution **after** vertical-slice gates — they do not reopen bans (trade, battle pass, purple loot, always-online).

## 1. Hard bans (inherited + sharpened)

| Banned | Why (1000× failure mode) |
|---|---|
| Battle pass / seasons / FOMO energy | Live-service spine; wrong product |
| XP bar / level-up fireworks / purple ascension | Gameslop; fights material identity |
| Rarity rainbow Fragment ladder | Slot dopamine as fake depth |

| Infinite job generators as “content” | Volume without authored novelty |

| Power creep from Legacy stamps | Memory becomes grind currency |
| Always-online gates / appointment worlds | Offline-first breach |
| Echo Lattice act map / habit archetypes as Weaver meta | Separate SKU ([`../PIVOT.md`](../PIVOT.md)) |

If a proposal needs one of these to “feel like progress,” it is the wrong proposal.

## 2. What “1000× progress” means

Four layers from [`../11_PROGRESSION.md`](../11_PROGRESSION.md) stay law. 1000× adds a fifth measurement: **graph elegance under short sessions**.

| Layer | Player feels | 1000× signal |
|---|---|---|
| **Literacy** | “I know which port takes a Brace” | Illegal-snap → next Thread without tip stack |
| **Catalog** | “I earned a wider Span / a Pulse” | New family via job stamp, not rarity drip |
| **Authorship** | “That gate is mine” | Inhabit clears; build-alone never wins |
| **Memory** | “I can see what I stood” | Gallery + residue bias; optional evolve post-slice |
| **Elegance** *(1000×)* | “I cleared with fewer Threads / cleaner seams” | Optional stars / re-clears teach craft, never gate story |

**Content graph definition:** a directed acyclic unlock graph whose nodes are **jobs, Thread types, Fragment families, Structure recipes, Yard corners, and Legacy shelves**. Edges are literacy predicates (illegal-snap cleared, inhabit clear, stamp earned) — never currency sinks or login clocks.

## 3. Five phases to the 1000× content graph

Phases are **player literacy arcs**, not Steam Partner phases and not Echo Lattice Acts. Ship content *into* these phases; do not invent parallel meta tracks.

### Phase map (one screen)

| Phase | Craft sentence | Content graph nodes (order) | Session fit | Exit gate |
|---|---|---|---|---|
| **I — Hands** | Fragments are stuff | Survey → Recover → carry 3–5 · 2–3 Fragment families | 3–8 min teach | Player sorts families by settle/feel without rarity words |
| **II — Stitch** | Threads carry load | Brace → Feed → Oppose → Echo (one-at-a-time) · illegal-snap literacy | 8–15 min | Second Thread type unlocks only after snap literacy |
| **III — Seat** | Structures do jobs | Tension → Inhabit → Residue · ≤3 Structure recipes · 8–12 slice jobs | 12–24 min first useful Structure | First useful Structure ≤24:00; inhabit mandatory |
| **IV — Yard** | The board answers | More contracts · ≤8→≤20 recipes · ecology teach (late) · optional second corner | 10–20 min returns | Jobs teach verbs; catalog never outruns jobs |
| **V — Memory** | The shed kept my seam | Local gallery · residue chains · elegant re-clears · sandbox dessert | 8–15 min hooks | Pride without power creep; airplane mode complete |

```
                    ┌─ Fragment families (I→IV)
Hands ─► Stitch ─► Seat ─► Yard ─► Memory
                    │         │         └─ gallery / evolve / elegance
                    │         └─ recipes · ecology · board density
                    └─ Thread types (II) · Structure recipes (III+)
```

### Phase I — Hands (material literacy)

| Lock | Spec |
|---|---|
| **Nodes** | Recover verb · carry slots · 2–3 Fragment families (slice) · bin/shelf home |
| **Edges** | Complete Survey/Recover teach job |
| **Must feel** | Weight, ports, plain names — reed / timber / copper, never grey→purple |
| **Must not** | Loot magnet suck, rarity ping, tip carousel |
| **Hook out** | One unfinished shelf or frayed post visible — next session has a noun |

Authority clocks: [`../32_FIRST_FIVE.md`](../32_FIRST_FIVE.md) · [`../16_FIRST_THIRTY.md`](../16_FIRST_THIRTY.md) minutes 0–8 · feel [`../21_FRAGMENT_FEEL.md`](../21_FRAGMENT_FEEL.md).

### Phase II — Stitch (line literacy)

| Lock | Spec |
|---|---|
| **Nodes** | Four Thread types as **serial** unlocks · slack demo · cut/re-pin · Thread budget awareness |
| **Edges** | Illegal-snap literacy on type *N* before type *N+1* |
| **Must feel** | Slack comedy → taut climb → tear culprit |
| **Must not** | Full Thread palette day one; spreadsheet port matrix |
| **Hook out** | One Thread type named but not yet held — chalk teaser, not FOMO timer |

Authority: [`../04_THREADS.md`](../04_THREADS.md) · discovery without wiki [`../22_DISCOVERY_UX.md`](../22_DISCOVERY_UX.md).

### Phase III — Seat (authorship ceremony)

| Lock | Spec |
|---|---|
| **Nodes** | Tension commit · collapse readability · first Structure recipes (≤3 slice / ≤8 vertical) · inhabit as win · residue stamp |
| **Edges** | Inhabit clear of teach Structure → recipe stamp → next job unlock |
| **Must feel** | “I wove that — and now I have to live in it” |
| **Must not** | Build-alone auto-win; XP fireworks; meta dump after first seat |
| **Hook out** | Silhouette on the gallery wall + one next contract noun |

This phase *is* the vertical-slice proof. Demo may stop at Phase III + CTA ([`../17_MVP.md`](../17_MVP.md)).

### Phase IV — Yard (board density without encyclopedia)

| Lock | Spec |
|---|---|
| **Nodes** | 40–60 jobs at 1.0 · ≤12 Fragment families · ≤20 Structure recipes · Yard corners · late ecology classes ([`../24_STRUCTURE_ECOLOGY.md`](../24_STRUCTURE_ECOLOGY.md)) |
| **Edges** | Job clears unlock adjacent contracts; ecology teach after Gate + Echo literacy |
| **Must feel** | Harder graphs, tighter budgets, inhabit timing — never HP or coin walls |
| **Must not** | Besiege-scale catalog; open-world tourism; catalog ahead of jobs (risk D3) |
| **Hook out** | Soft-suggest next literacy from hand signature / bias — offline, no appointment |

Stars (if any) score **Thread economy + graph elegance**, not speed tax alone ([`../11_PROGRESSION.md`](../11_PROGRESSION.md) §4).

### Phase V — Memory (mastery corpus)

| Lock | Spec |
|---|---|
| **Nodes** | Local gallery shelves · ghost replays · residue chains / evolve ticks (post-slice, [`../28_LEGACY_V2.md`](../28_LEGACY_V2.md)) · sandbox dessert · optional share codes |
| **Edges** | Stood + inhabited Structures → stamps → bias / scars that **invite literacy**, never buff DPS |
| **Must feel** | Quiet pride; yard weathering; “same loom, different hands” |
| **Must not** | Server monuments; seasonal wipe; tradable stamps; login evolution |
| **Hook out** | One scar or elegant re-clear invitation — always abandonable without shame |

**Power test preserved:** wiping Legacy never blocks campaign clears.

## 4. Content graph rules (authoring law)

| Rule | Spec |
|---|---|
| **Jobs before catalog** | A recipe node may not unlock until a job that *needs* it exists |
| **One new noun per edge** | An unlock edge introduces ≤1 craft noun (family, Thread, recipe, or corner) |
| **Teach → test → twist** | Every new noun gets one teach job, one honest test, optional elegance twist |
| **DAG only** | No circular “farm X to unlock X” sinks |
| **Softlock forbidden** | Every node keeps undo / recover / abandon path |
| **Offline complete** | Full graph walkable with Steam disabled |
| **Clone ban** | New jobs must change graph pressure, not recolor the last field |

### Honest mountain (aligned to MVP)

| Milestone | Phase ceiling | Graph size intuition |
|---|---|---|
| **W1 spike** | I–II skim + III micro | 1 field · 2 Fragments · 1 Thread · 1 Structure |
| **Vertical slice / demo** | Through III | 1 Yard · 4–6 Fragments · Thread literacy · 3 Structures · 8–12 jobs |
| **MVP 1.0** | Through IV (+ thin V gallery) | ≤12 Fragments · ≤20 Structures · 40–60 jobs · local gallery |
| **Post-1.0 deepen** | Full V | Ecology composition · Legacy evolve · optional async ghosts — pick lanes, don’t stack all |

Do **not** schedule World-tourism / Multiplayer / trade as progression nodes.

## 5. Short-session hooks

Weaver is a **short-session craft toy**. Progression must leave a **single next noun**, not a chore list.

### 5.1 Session lengths (design for these)

| Session | Target | What completes |
|---|---|---|
| **Micro** | 5–8 min | One Recover→Bind experiment, or one elegant re-tension |
| **Standard** | 10–20 min | One Yard job clear (teach or mastery) |
| **Evening sit** | 25–40 min | Two jobs **or** one mastery + gallery linger — never a forced marathon |

Natural stop after any **Residue** beat. Save is automatic and obvious ([`../16_FIRST_THIRTY.md`](../16_FIRST_THIRTY.md)).

### 5.2 Hook types (allowed)

| Hook | When it fires | Player hears / sees | Ban variant |
|---|---|---|---|
| **Noun teaser** | End of clear | One craft noun for next job (“east post still won’t hold dawn wind”) | Quest-log novel |
| **Silhouette itch** | Gallery stamp | Empty nail beside a new cloth panel | Streak counter |
| **Bias invitation** | Residue tag | Next field softly favors/counters your hand | Mandatory counter that softlocks |
| **Elegance whisper** | Optional | “Fewer Threads possible” as a quiet star — never required | Par timer shame |
| **Scar door** | Phase V | Legacy scar opens a literacy job | Permanent power buff |
| **Same-loom code** | Post/thin | Offline comparable seed — “same loom, different hands” | Ranked ladder / FOMO daily |

**Budget:** ≤1 primary hook per session end. Secondary chrome (ghosts, dailies) never crowds the hero composition ([`../11_PROGRESSION.md`](../11_PROGRESSION.md) §7).

### 5.3 Hook acceptance

A cold player, quitting after one standard session, answers **yes**:

1. I finished a craft sentence (not a half-tutorial).  
2. I can name **one** thing I’d try next time.  
3. Nothing punished me for leaving.  
4. No energy bar, login calendar, or “come back in 3h” gate appeared.

## 6. Mastery without grind

Mastery is **graph skill under scarcity**, not hours-spent currency.

### 6.1 Mastery vectors (ship these)

| Vector | Player proof | Implementation |
|---|---|---|
| **Thread elegance** | Clear with fewer / smarter Threads | Optional stars; never gates story jobs |
| **Collapse literacy** | Names culprit joint after fail | Culprit flash + tear; refund Fragments |
| **Multi-channel compose** | Late jobs layer two rewrite channels | Teach one channel at a time first ([`../05_STRUCTURES.md`](../05_STRUCTURES.md)) |
| **Ecology answer** | Beacon / Recorder / Gateway composition | Late Phase IV — catalog budget shared |
| **Hand signature** | Residue bias readable across sessions | Local only; wipe-safe |
| **Sandbox dessert** | Free-build after literacy | Optional prompt; Exit always clear; never replaces Yard spine |

### 6.2 Grind shapes (kill on sight)

| Grind shape | Why it fails Weaver |
|---|---|
| Repeat same job for currency / XP | Session scarcity is not a meta wallet |
| Login N days for Fragment drip | Appointment product |
| Farm scraps for recipe RNG | Gacha gravity |
| Widen catalog without new jobs | Encyclopedia without authorship |
| Infinite procedural jobs as mastery | Authored novelty dies; wiki rises |
| “Play 10h to unlock the real verb” | Verb must sing by first Structure |

### 6.3 Difficulty without mash

Harder nodes tighten **ports, Thread budget, inhabit timing, collapse readability** ([`../27_SOLO_ECONOMY_V2.md`](../27_SOLO_ECONOMY_V2.md)). They do **not** add HP, coin walls, or friend-gates.

**Solo song test:** a mastery field is hard because of graph skill, not missing coin or missing friends.

**Relief test:** collapse → re-tension feels informative within one retry, not a punitive sink.

## 11. Acceptance playtests

### 11.1 Cold evening (Phases I–III)

1. Cold player completes one Structure job without tip-stack drowning.  
2. Second Thread type unlocks only after illegal-snap literacy.  
3. Clear requires **inhabit**, not merely Tension.  
4. No XP bar, rarity gems, or purple level-up in shell.  
5. Gallery shows a recognizable silhouette without UI chrome.  
6. Quit leaves **one** next-session noun — not a choreboard.

### 11.2 Return week (Phases IV–V thin)

1. Three standard sessions advance three different graph nodes (not the same farm).  
2. Optional elegance stars never block a story/job unlock.  
3. Legacy wipe still leaves campaign solvable.  
4. Airplane mode clears the week’s jobs.  
5. Player describes progress as craft literacy (“I can Oppose now”), not grind hours.

### 11.3 Anti-grind audit

| Prompt | Fail if |
|---|---|
| “Why replay?” | Answer is currency / XP / login |
| “Why is this hard?” | Answer is missing friends / missing coin |
| “What did I unlock?” | Answer is a level number or rarity color |
| “Can I stop?” | Answer requires waiting on a real-world timer |

## 13. Lock line

Weaver 1000× progression is a **five-phase content graph** — Hands → Stitch → Seat → Yard → Memory — walked in short sessions, mastered by elegance, remembered by the shed. If it needs a battle pass, a login calendar, or a purple fragment to feel like progress, it is the wrong loop.
