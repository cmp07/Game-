## 4. Grades — plain capacity, never rarity

Grades answer “how much can this atom hold?” — not “how shiny is the border?”

### 4.1 Two axes (multiply, don’t rainbow)

| Axis | Values | Player speech | Reads as |
|---|---|---|---|
| **Size** | **S / M / L** | “bigger Span,” “small Anchor” | Silhouette scale of the *same* outline |
| **Temper** | **Green / Seasoned / Banded** | “seasoned stake,” “banded culvert” | Material readiness — fiber density / wrap / kiln set |

```
grade = size × temper
capacity ≈ size_weight[size] × temper_weight[temper]
```

| Size | Weight feel | Carry comedy |
|---|---|---|
| **S** | Soft tug; palm settles fast | Fits crowded hands |
| **M** | Default teach mass | Normal settle |
| **L** | Stubborn reach; longer settle squash | First to trigger “Hands full.” |

| Temper | Craft meaning | Tell (not rarity) |
|---|---|---|
| **Green** | Fresh / soft / unfired | Lighter stitch density; chalkier edge |
| **Seasoned** | Worked / dried / trustworthy | Default density; clean outline |
| **Banded** | Wrapped, strapped, or kiln-set | Visible band / strap / dark kiln lip — still greyscale-readable |

**Hard ban:** stars, skulls, gem sockets, chrome tiers, “Legendary Fragment,” purple borders, loot fanfare on grade-up.

### 4.2 Grade speech & UI

| Say | Do not say |
|---|---|
| “I needed a bigger Span.” | “I needed a rare.” |
| “Seasoned Anchor held.” | “Epic stake drop.” |
| “Banded Channel passed the surge.” | “Purple tier culvert.” |
| Shelf nests show **outline + thickness + optional band** | Numeric DPS / rarity pips |

UI may show plain tokens `S`·`M`·`L` and temper words — never a colour-ranked ladder. Accent, if any: kiln rust/copper for Banded heat lip; Pulse beat stays brass/patina ([`../21_FRAGMENT_FEEL.md`](../21_FRAGMENT_FEEL.md) §5).

### 4.3 Progression of grades (literacy, not XP)

| Moment | Unlock shape |
|---|---|
| First session | S/M only; temper mostly Seasoned |
| Slice → demo | L appears as a *problem* (“gap too wide”), not a reward chest |
| 1.0 | Green / Banded as authored field bias + residue scrap — never pity timer |

Mastery line stays: **which family, which grade, which bind** — not grade-chasing ([`../11_PROGRESSION.md`](../11_PROGRESSION.md)).

## 5. Mutations — field wear, not loot affixes

A **mutation** is an authored wear state from field ecology or residue — a single readable tell that bends capacity or port behaviour. It is **not** a random legendary roll.

### 5.1 Mutation contract

| Rule | Spec |
|---|---|
| **Authored** | Field seed / residue bias / job author picks mutation — no hidden loot table |
| **One tell** | ≤1 silhouette overlay + ≤1 material whisper; never a sticker stack |
| **Family preserved** | Mutation never invents a new outline language; greyscale family test still passes |
| **Named plainly** | Craft wear verbs — soaked, scorched, frayed — not “of the Void” |
| **Refund honesty** | Collapse refunds the mutated Fragment as mutated unless the field authors a sink |
| **Cap** | Carry may hold mutated atoms; shelf shows wear tell at nest scale |

### 5.2 Ship mutation set (1.0)

| Mutation | Who it may mark | Systems bend | Silhouette overlay | Ban confusion |
|---|---|---|---|---|
| **Soaked** | Span, Membrane, Channel, Ballast | Heavier settle; flow capacity up; brace stiffness down | Dark wet edge / drip notch | Not “ice rare” |
| **Scorched** | Charge, Vent, Latch, Filter | Release sharper; capacity brittle (fails sudden) | Char lip / ash mote | Not purple ember neon |
| **Frayed** | Span, Membrane, Guide | Capacity down; ports soft (illegal snap more forgiving visually, still illegal) | Thread-end whiskers | Not rarity tear badge |
| **Bent** | Hinge, Channel, Guide | Prefers one angle / route; pivot bias | Asymmetric kink in outline | Kink ≠ new family |
| **Packed** | Filter, Latch | Mesh / catch denser — refuses more | Tighter perforation grid | Not “epic sieve” |
| **Slack-wound** | Pulse, Latch | Beat / catch slower; brass tick duller | Longer arm rest / lazy pawl | **Never** hourglass; never rewind |

### 5.3 Mutation refuse list

| Temptation | Why out |
|---|---|
| Random multi-affix stacks | Diablo |
| Mutation as paid cosmetic tier | Monetization leak |
| “Chrono-warped” / time-stained | Purple Time lane |
| Mutation that changes family mid-hand | Breaks silhouette literacy |
| Shiny proc glow on mutate | Loot fanfare |

### 5.4 How mutations enter play

| Source | Shape |
|---|---|
| **Field ecology** | Wet basin → Soaked scrap; kiln job → Scorched Charge |
| **Residue bias** | Prior Pulse gate may leave Slack-wound knocker as next-field bias ([`../08_LEGACY.md`](../08_LEGACY.md)) |
| **Collapse comedy** | Rare authored fray on the culprit Fragment — teach wear, not punish RNG |
| **Never** | Pity timer, gacha crate, daily “mutate for fun” slot |

## 6. Silhouette grammar (1000×)

Color is secondary. Ports are glyphs. **Outline is law.**

### 6.1 Family matrix (all twelve)

| Family | Outer shape (greyscale) | Grade read | Port glyph zone | Anti-confusion |
|---|---|---|---|---|
| **Span** | Long rectangle / cloth strip; length ≫ height | Length + thickness | Ends (`brace`/`brace`) | Not Channel (no hollow bore) |
| **Anchor** | Peg / stake / wedge; wide base or pointed tip | Mass / footprint | Base (`ground`) + top (`brace`) | Not Ballast (grounded, not hung) |
| **Channel** | Open trough / culvert U or tube with bore | Bore width | Ends (`in`/`out`) | Hollow reads empty — never solid beam |
| **Charge** | Coil, bladder, or kiln-heart bulge | Belly volume | `in` / `out` / `release` cluster | Bulge ≠ Membrane patch |
| **Filter** | Flat baffle / sieve with perforations | Mesh density | Face + `sense` notch | Perforations required |
| **Pulse** | Pendulum bob + arm, bellows folds, or knocker | Arm length / fold count | `beat` crown + `out` | **No hourglass**; bob ≠ Charge belly |
| **Hinge** | Two plates + visible pin knuckle | Knuckle size | Pin (`pivot`) + plate `brace`s | Knuckle required — not a short Span |
| **Ballast** | Hung sack / block with hook or loop | Sack volume | Top `hang` + side `brace` | Hook/loop required — not grounded Anchor |
| **Membrane** | Soft irregular patch / sail panel | Area + slack ripples | Edge `seal` / `brace` | Ripple edge ≠ Filter holes |
| **Latch** | Hook + catch plate / pawl tooth | Tooth depth | `catch` mouth + `release` | Tooth asymmetry — not Guide ring |
| **Guide** | Ring / eye / fairlead loop | Eye inner diameter | `route` through-eye + `in`/`out` | Open eye required — not Latch tooth |
| **Vent** | Notch / chimney lip / spill slit | Slit width | `dump` mouth (often upward/out) | Open dump — not Filter mesh, not Charge belly |

### 6.2 Grade in silhouette

| Grade cue | Spec |
|---|---|
| **Size** | Uniform scale of the family outline — do **not** invent new outlines per S/M/L |
| **Green** | Softer corners; lighter fill hatch |
| **Seasoned** | Default crisp outline |
| **Banded** | One strap / wrap / kiln lip crossing the body — readable at 64×64 |

### 6.3 Mutation overlays (greyscale-safe)

| Mutation | Overlay (keep ≤1) |
|---|---|
| Soaked | Darker lower edge + single drip notch |
| Scorched | Rough char scallop on one lip |
| Frayed | 2–3 whisker ticks on one end |
| Bent | Single kink; family landmarks stay |
| Packed | Denser hole grid (Filter) or thicker tooth (Latch) |
| Slack-wound | Longer rest pose (Pulse arm) or open pawl gap (Latch) |

Overlays must survive `saturation = 0`. Never replace outline with a color-only flash. Reduce-motion: hard cut to nest OK ([`../21_FRAGMENT_FEEL.md`](../21_FRAGMENT_FEEL.md) §4.2).

### 6.4 Confusion matrix (must stay green)

| Pair | Failure mode | Fix |
|---|---|---|
| Span vs Channel | Both “long” | Channel **must** show hollow bore |
| Anchor vs Ballast | Both “chunky mass” | Anchor grounds; Ballast **hangs** (hook/loop) |
| Filter vs Membrane | Both “flat” | Filter = perforations; Membrane = ripple seal, no sort holes |
| Charge vs Pulse | Round bodies | Pulse keeps arm / folds / knocker asymmetry |
| Hinge vs Span | Short beam vs joint | Hinge shows **pin knuckle** |
| Guide vs Latch | Both metal hardware | Guide = open eye; Latch = catch tooth |
| Vent vs Filter | Both “openings” | Vent = single dump mouth; Filter = mesh field |
| Pulse vs “time loot” | Clock metaphor creep | Ban hourglass; bob is craft weight |
| Any + purple beat | Chronomancy read | Brass/patina/ochre only for Pulse |

### 6.5 Shelf / field / seat continuum

| Stance | Silhouette duty |
|---|---|
| Field-loose | Full family outline + grade + mutation overlay at world scale |
| Carried | Nest silhouette at HUD; ports dim until aim; wear tell still on |
| Provisional seat | Outline stable; no rarity pulse |
| Tension-seated | Family still readable inside the graph ([`../05_STRUCTURES.md`](../05_STRUCTURES.md)) |

## 9. Acceptance gates (1000×)

1. **Roster:** ≤12 ship families; teach six before any deepen introduce.  
2. **Greyscale twelve:** all families named from nest silhouettes alone.  
3. **Grade speech:** playtester says “bigger / seasoned / banded,” never “rare.”  
4. **Mutation tell:** each ship mutation identifiable with one overlay at 64×64 greyscale.  
5. **Family preserved under wear:** mutated specimen still passes family silhouette test.  
6. **Cliché:** zero hourglass / chronoshard / “Fragments of Time” / purple beat accents in mocks.  
7. **Pulse color:** brass / patina / ochre only ([`../21_FRAGMENT_FEEL.md`](../21_FRAGMENT_FEEL.md) §5).  
8. **Cap fence:** no 13th family without cutting another or an explicit post-1.0 reopen.  
9. **Shelf test:** doc still makes sense if monetization and multiplayer docs are deleted.
