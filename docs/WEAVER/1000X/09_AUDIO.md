## 0. Thesis

Sound is how players **feel load** before they read a number. Slack, taut, snap, and seat must be audible sentences. If the game looks like a shed loom but sounds like cosmic pads and UI candy, the fantasy collapses.

**1000× bar:** a stranger with headphones and Music muted can name Fragment family, Thread type, and Structure archetype from ear alone after one teach job — and clap the Tension seat phrase after three hearings.

**One-line brief:** _Workshop hush, fiber scrape, timber seat — Atom, Stitch, Cloth. Silence between stitches. No choir. No chronomancy chimes. No transit PA._

**Weaver rule:** visual Tension stages ([`../09_VISUAL.md`](../09_VISUAL.md) · [`../23_WEAVE_VERB.md`](../23_WEAVE_VERB.md)) and audio seat phrase are **one sentence**. Progression never celebrates unlocks with slot-machine jingles ([`../11_PROGRESSION.md`](../11_PROGRESSION.md)).

## 1. Three pillars (non-negotiable)

Any cue that fails two pillars goes back. These replace “more SFX polish” as acceptance language.

### P1 · Seat is a musical event

Tension seat (`Arm → Crease → Lift → Seat → Settle`, ~900–1200 ms) is **not** a one-shot “build complete” sting. It is a **scored phrase** with pitch, material, and authored rests — shared grammar for stages 1–4, archetype consonant on Settle. Players clap it after three hearings. Trailer and in-game share masters.

### P2 · Craft nouns are leitmotifs, not volume

Fragments, Threads, and Structures must sound like **different craft acts** — Atom cell, Stitch contour, Cloth cadence — not one fiber kit at three loudness levels. Habit / shed bed, if present, **states and varies a cell**; it does not only get louder.

### P3 · Silence is a tool

Silence is not “music not ready yet.” It is composition: Survey hush, post-snap rest that IDs failure class, post-seat settle into shed tone, title without chirp spam. Filling quiet with mystic pad because “it feels empty” is a ban ([`../34_ADVERSARIAL.md`](../34_ADVERSARIAL.md) C5).

## 2. Hard ban — slop ear

| Banned | Replace with |
|---|---|
| Epic orchestra / choir / “destiny” brass | Dry workshop bed or true hush |
| Cute UI blips, coin jingles, rarity fanfares | Soft fiber brush, wood tick, cloth stamp |
| Horror risers, jumpscare stingers | Honest snap + short rest |
| Magic whoosh / shimmer / aether pads | Crease → seat; dust fall |
| Time-rewind swooshes, hourglass shakes | Pendulum *tick* only as Pulse Fragment tell |
| Speech / VO / robot quips | Diegetic craft lines on-screen ([`../04_THREADS.md`](../04_THREADS.md)) |
| Wall-to-wall music under Survey teach | Authored silence / HVAC shed tone |
| Mystic void drone under menus / title | Shed air, distant kiln, silence |
| Echo Lattice transit PA / Ledger Cell contour | Weaver Atom / Stitch / Cloth only |
| Separate “marketing mix” that contradicts in-game | Trailer uses the same masters |
| Procedural sine/square “placeholder” character in public trailer | Authored material hybrids only |

**Anti-purple-void audio:** no mystic void drone. Title bed = shed air / distant kiln / silence. Blind listen must say “workshop,” not “space temple.”

## 3. Sonic world (workshop ear)

### 3.1 Material dictionary

Map visual materials ([`../09_VISUAL.md`](../09_VISUAL.md) · [`../25_VOID_ART_V2.md`](../25_VOID_ART_V2.md)) → sound. Prefer recorded / designed hybrids over pure oscillators.

| Visual / system | Sonic material | Ban |
|---|---|---|
| Page / cloth substrate | Soft fiber brush, cloth damp | Wet reverb halls, cinematic whoosh libraries |
| Chalk provisional Thread | Dry chalk scrape, low friction | White-noise “magic” sweeps |
| Taut seated seam | Waxed cord pull → settled tick | Laser blips, 8-bit coin |
| Timber Span / Anchor | Soft wood knock; mass on seat | Neon hard-light zaps |
| Wire / thin brace | Higher metallic filament | Sci-fi shield hum |
| Channel flow | Sparse liquid / dust sift | Hose-loop spam |
| Charge / kiln | Low warm body; vent as air dump | Explosion / rocket whoosh |
| Pulse / pendulum | Dry beat — clockwork craft | Rewind swoosh / chronochime |
| Illegal snap | Short white transient + rest | Cartoon error buzzer |
| Collapse tear | Fiber tear → culprit hold → refund rustle | Fail brass / laugh-track |
| Residue stamp | Pressed cloth / paper stamp | Slot-machine jingle |
| Frayed gap (physical void) | Dust fall column, air over drop — sparse | Cosmic pad under the gap |

### 3.2 Pitch & tuning

| Rule | Spec |
|---|---|
| Tuning home | Dry prepared plate / muted timber — never lush triad pads |
| Home interval | Open fifth for Span calm; grit via dry scrape / ♭ coloring on rust — not siren |
| Lattice | Think in **semitone steps on muted plate**, not lush chords |
| Seat tonic | Soft shed tonic under Arm; Seat downbeat lands **into** it |
| No vocals | Ever — meaning stays on-screen |
| Motif ownership | Family / type / archetype owns **gesture + material**, not a random timbre pack |

### 3.3 Tempo feel (not a metronome HUD)

| Context | Feel |
|---|---|
| Survey / title | Near hush; optional distant kiln pulse ≈ 50–60 BPM felt, not clicked |
| Draw / Bind | Player-driven scrape rate |
| Seat phrase | Fixed **~900–1200 ms** musical bar aligned to visual staging |
| Pulse Fragment / Gate | Readable pendulum tempo — player literacy, not remix HUD |
| Residue / queue-next | Stamp → **hungry open interval** (addiction without brass) |

## 4. Leitmotif grammar — Atom · Stitch · Cloth

Absorbs and locks [`../26_AUDIO_V2.md`](../26_AUDIO_V2.md). Composer may retune absolute pitch; **contour and material job** are normative.

### 4.1 Atom cell — Fragments

Working name: **Atom Cell**.

```
gesture:     pick → body → micro-rest
scale hint:  1      →  (optional) 5♭ or open 5
register:    family-colored (§5)
```

| Job | Spec |
|---|---|
| Recover | Full Atom consonant once |
| Seat into Structure | Atom consonant reappears as a **partial** inside Settle |
| Collapse refund | Soft reverse rustle of the same consonant (no “loot return” jingle) |
| Ban | Rarity arpeggios, collectible sparkle packs, chronoshard chimes |

### 4.2 Stitch contour — Threads

Working name: **Stitch Contour**.

```
gesture:     contact scrape → span travel → port kiss (or snap cut)
tension:     slack = breathy / incomplete; taut = waxed / settled tick
```

| Job | Spec |
|---|---|
| Provisional chalk draw | Contour at low friction; ends open |
| Legal commit (pre-Tension) | Contour completes with soft port kiss |
| Illegal bind | Contour shears mid-travel; rest length encodes failure class (§7) |
| Overload approach | Contour gains dry grit; pitch creep optional, never siren |

### 4.3 Cloth cadence — Structures

Working name: **Cloth Cadence**. Shared grammar with visual crease → lift → seat; archetypes own **Settle endings only**.

| Stage | Motif job |
|---|---|
| Draw / Arm (pre) | Dominant Stitch contours stack sparsely — still readable as separate fibers |
| Crease | Atom consonants of seated Fragments flicker as paper-fiber cascade |
| Lift | Shared air inhale (not whoosh library) |
| Seat | Shared timber/cord downbeat — loudest honest hit |
| Settle | **Archetype ending** (§6) lands into shed tone or silence |
| Fail | Snap/tear → rest → refund Atom rustle — no cadence completion |

## 5. Fragment leitmotifs (family consonants)

Six MVP families ([`../03_FRAGMENTS.md`](../03_FRAGMENTS.md)). Greyscale silhouette and ear literacy must agree.

| Family | Material consonant | Interval / envelope color | Recover tell |
|---|---|---|---|
| **Span** | Soft cloth strip / plank fiber | Open fifth, longer decay | Horizontal brush |
| **Anchor** | Peg / stake wood knock | Low perfect 1, short decay | Mass tick into ground |
| **Channel** | Hollow trough / duct air | Narrow hiss band → soft drip tick | Directed whisper |
| **Charge** | Spring / kiln-heart body | Warm low body + held pressure | Stored hum (≤200 ms), then rest |
| **Filter** | Sieve / baffle tick-stop | Bright cut-off (high → mute) | Refuse click |
| **Pulse** | Pendulum / knocker beat | Dry clockcraft 1–2; readable tempo | Beat body — **never** rewind swoosh |

**Capacity tiers (S/M/L):** same consonant; **body weight** only (louder fundamental, longer tail). Never new melody per tier. Never rarity rainbow.

**Port whisper (optional):**

| Port class | Ear hint |
|---|---|
| `brace` / `ground` | Wood / cord body |
| `in` / `out` / `release` | Directed air or liquid sift |
| `sense` / `beat` | Dry tick / pendulum |

Port mismatch uses **Thread snap** (§7), not a Fragment fanfare.

**Juice sync:** Recover suck ([`../35_JUICE.md`](../35_JUICE.md) `fragment_suck`) ends on Atom consonant — chalk/fiber wisps, not magnet beam whoosh.

## 6. Thread & Structure leitmotifs

### 6.1 Thread type contours

Four MVP types ([`../04_THREADS.md`](../04_THREADS.md)).

| Type | Contour character | Legal end | Failure ear |
|---|---|---|---|
| **Brace** | Waxed cord pull; mass in the middle | Settled wood tick | Overload tear (fiber split) |
| **Feed** | Directed flow scrape (dust / charge path) | Soft arrival kiss at `in` | Starve = thin hiss fade; burst = sudden dump |
| **Oppose** | Reverse / vent scrape (outward breath) | Air dump settle | Blowback = dump returns at player |
| **Echo** | Sparse copied ticks; no mass transfer | Alignment resolve | Desync chatter that locks when beat matches |

**Slack → taut (one contour):**

| Visual | Audio |
|---|---|
| Slack fiber (dashed chalk) | Contour incomplete; chalk dry; gaps audible |
| Taut ink | Contour completes; waxed body; settled tick |
| Rust creep | Grit along the **same** contour — not a new theme |

**Juice sync:** Bind combine flash ([`../35_JUICE.md`](../35_JUICE.md) `combine_flash`) is paper-press — soft stamp tick under Stitch port kiss, never full-screen energy wash. Weave pulse rides Thread body as cord-load scrape, not neon ring whoosh.

### 6.2 Structure archetype endings

Shared Cloth Cadence. Archetypes ([`../05_STRUCTURES.md`](../05_STRUCTURES.md)) own Settle only — stages Arm–Seat stay shared so the seat remains clap-able.

| Archetype | Primary channel | Settle ending (motif) |
|---|---|---|
| **Span** | Topology | Horizontal fifth lands; dust fall along the bridge line |
| **Culvert** | Flow | Soft liquid sift resolves into dry path hush |
| **Kiln** | Vent / Charge | Warm body dump + copper tick; vent air, not explosion |
| **Gate** | Pulse | Pendulum downbeat locks open/close; tempo readable |
| **Scaffold** | Load | Stacked low wood knocks (accretion); invites second Tension |
| **Loom-mark** | Residue | Pressed cloth stamp — same family as Residue beat |

Multi-channel mastery Structures may **layer two endings** at −6 to −9 dB under the primary — never a third unrelated theme.

**Inhabit voice:** footsteps / interactables inherit standing archetype material (timber on Span, trough damp on Culvert, kiln warmth near Charge). Pulse gates tick the Atom Pulse consonant. No combat hit fanfares.

## 7. Failure grammar (rest as ID)

Snap / tear must be distinguishable by **rest length + transient**, not by cartoon buzzers. Align clocks to [`../23_WEAVE_VERB.md`](../23_WEAVE_VERB.md) §4.3–4.5.

| Failure class | Transient | Rest after | Motif note |
|---|---|---|---|
| Port mismatch | Short white shear | **Longer** rest (~180–250 ms) | Contour cut before port kiss |
| Overload tear | Fiber split + grit | Medium rest (~120–160 ms) | Brace/Feed body was present |
| Starve | Thin hiss collapse | Soft open interval | Feed contour never arrives |
| Burst / blowback | Sudden dump | Short rest then Oppose vent color | Charge / Oppose consonant flashes |
| Echo desync | Chatter ticks | Resolves into Pulse Atom tempo | No rewind language |
| Collapse (Structure) | Tear → culprit hold | Hold ≥ seat downbeat gap | Cadence aborts; refund Atom rustle |

Illegal snap total phrase **≤0.55 s**. Collapse: tear onset → culprit hold → refund rustle (~900 ms); player drawing again before one second on bind fails.

Mastery is hearing **which** Thread failed — not a VO coach.

## 8. Signature phrase — Tension seat (deep dive)

Align to visual Arm → Crease → Lift → Seat → Settle ([`../23_WEAVE_VERB.md`](../23_WEAVE_VERB.md) §4.4 · [`../09_VISUAL.md`](../09_VISUAL.md)). Total authored length **900–1200 ms**.

| Stage | Clock (approx) | Sonic job | Silence job | Mix |
|---|---|---|---|---|
| **Arm** | 0–200 ms | Soft bed duck; Stitch contours promise ink | Leave Survey hush almost untouched | Music −3 dB |
| **Crease** | 200–550 ms | Cloth gather / multi-fiber rustle; Atom cascade | Micro-gaps — not noise wall | SFX lead |
| **Lift** | 550–750 ms | Soft mass inhale (air, not whoosh library) | One breath of hush under lift | No whoosh library |
| **Seat** | 750–950 ms | Wood/cord downbeat — loudest honest hit | No layering under the hit | Peak SFX; hitstop OK ≤90 ms |
| **Settle** | 950–1200 ms | Stitch lock + **archetype ending** (§6.2); Structure “is law” | Tail into shed tone or silence | Music returns gently |
| **Fail path** | collapse clocks | Snap or tear → rest → refund rustle | Never mask the culprit | Cadence aborts |

**Reduce-motion:** drop stages wholesale at boundaries; do not ugly-stretch or chipmunk.

**Trailer law:** 60–90 s verb cut uses the **same** seat masters as in-game — no separate trailer synth riser.

## 10. Bus layout & mix law

Godot buses ([`../14_TECH.md`](../14_TECH.md)); keep tiny. No PA bus for Weaver MVP.

```
Master
├── SFX
├── Music
└── UI
```

| Bus | Role | Default |
|---|---|---|
| **Master** | Final / mute-all | `0 dB` |
| **SFX** | Recover, draw, snap, seat, collapse, inhabit footsteps | `0 dB` |
| **Music** | Optional shed bed; default quiet or off in early teaches | `−6 dB` |
| **UI** | Menu / pause ticks — never before first intentional input | `−3 dB` |

### Rules

1. Every `AudioStreamPlayer` sets `bus` explicitly.  
2. Mute Music must **not** mute snap / seat / collapse (load literacy stays).  
3. No Master FX soup for MVP. Optional later: soft limiter on Master; short reverb send on **SFX** only for seat/collapse.  
4. Cold boot quiet except intentional title policy.  
5. Settings sliders map 1:1 to bus volume; persist under `user://settings.cfg`.  
6. Seat / snap may duck Music −3 to −4.5 dB for ~400–900 ms; authored hush after.

### Mix targets (1.0 guidance)

| Context | Target |
|---|---|
| Gameplay integrated | ≈ **−14 LUFS** short-term |
| Seat downbeat | Loudest one-shot family (honest peak, not brickwall) |
| Survey teach / title | Music digitally black or shed air only |
| UI | Never compete with seat / snap |
| Streamer Music-mute | Draw / seat / snap / collapse still teach load |

## 11. Silence policy

### 11.1 Field / teach caps

| Context | Max Music presence | Intent |
|---|---|---|
| Title / boot | Shed air or **0.0** | Brand as workshop, not cosmos |
| First teach Survey | **0.0–0.10** | Designed hush — locomotion + first identity |
| First successful Tension | Cap ≤0.25 under phrase | Phrase never pulls a music swell under it |
| Mid campaign jobs | ≤1.0 adaptive shed bed | Motif transforms, not playlist jumps |
| Gallery / ghost | Paper hush; Music optional low | No fanfare on browse |

Silence never mutes SFX. Returning players still honor teach caps on first-run flags.

### 11.2 Authored rests (mandatory)

| Rest | Duration | Where |
|---|---|---|
| Post-Atom recover | ≥60–90 ms | After every Recover consonant |
| Post-snap air | Class-specific (§7) | Inside every illegal bind |
| Post-Seat breath | 40–80 ms | Before archetype Settle grit |
| Post-collapse hold | ≥ seat downbeat gap | Culprit readable |
| Residue open interval | 300–600 ms hunger | After stamp — queue next job |
| Title / trailer tail | 0.4–0.6 s | Beat sheet end |
| After first teach seat | Optional +0.3 s Music hold-down | Pedagogy — let Structure read |

### 11.3 Silence acceptance

- [ ] First Survey: Music bus digitally black or shed-only; no accidental pad bleed.  
- [ ] First Tension: silence *around* the phrase makes it feel bigger than louder mixes.  
- [ ] Streamer Music-mute: snap / seat / collapse still teach the loop.  
- [ ] No “silence fear” filler — if the design is quiet, stay quiet.  
- [ ] Blind listen title: “workshop,” not “space temple.”
