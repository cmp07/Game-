## 0. One sentence

The 1000× world is a **seeded Yard of frayed cloth** — three strata (void, surface, core) presented as short solvable jobs — where the **gap is the antagonist**, procgen expands mastery without tourism, and every place has a **seed you can name and share**.

```
Seed → Core skeleton → Surface fray → Void gap staged → weave → residue → next seed
```

If a proposal needs seamless continents, living NPC plazas, or a black nebula “realm,” it fails this doc. If it cannot be replayed from a seed string, it is not World content.

## 1. Thesis — what 1000× upgrades

[`06_WORLD.md`](../06_WORLD.md) locked the MVP: one Shed Yard hub, authored fields as job panels, scarcity archetypes, deterministic seeds. That is the **correct spine**. Softnesses that still kill a finished indie:

| Soft spot in 06 | 1000× elevation |
|---|---|
| Seed named as a field property, not a player-facing identity | Seed is the **name of the place** — shareable, daily-rotating, gallery-linked |
| Fields feel hand-placed forever | **Procgen yards** from a grammar — same fairness, more cloth after teach |
| Gap listed as one archetype among seven | Gap is the **default antagonist** of the product; other scarcities are gap cousins |
| Depth described as art planes only ([`25_VOID_ART_V2.md`](../25_VOID_ART_V2.md)) | World systems also stack **void / surface / core** — play strata, not only paint |

**1000× is not a bigger map.** It is one Yard made undeniable: every still shows a torn place with a seed you could paste to a friend.

**Player line:** *“Same seed, same tear — my stitches are the difference.”*

## 2. Three strata — Void / Surface / Core

Depth is **authored layers with gameplay jobs**, not camera fog. Art planes in [`25_VOID_ART_V2.md`](../25_VOID_ART_V2.md) §3 remain visual authority. This section locks the **systems** reading of the same stack.

### 2.1 Layer table (far → near / deep → playable)

| Layer | What it is | Player verb | Failure if missing |
|---|---|---|---|
| **Void** | Physical absence — the drop, the missing span, the starved reach | Survey it; fear falling / failing the crossing | Cosmic emptiness **or** blank greybox (adversarial C) |
| **Surface** | Workable cloth / timber / page — where Fragments rest and Threads draw | Recover · Bind · Tension · Inhabit | Menu-on-black; no place to put hands |
| **Core** | Seeded skeleton — anchors, load spine, spawn grammar, clear predicate | Rarely touched directly; felt when Structures seat into law | Random mush; softlocks; “why did that stand?” |

```
        ┌─────────────────────────────────────┐
        │  SURFACE — cloth, planks, chalk     │  ← hands live here
        │    ╔═══════════════════════════╗    │
        │    ║  VOID — torn gap / drop   ║    │  ← antagonist
        │    ╚═══════════════════════════╝    │
        │  CORE (under) — seed skeleton       │  ← fairness machine
        └─────────────────────────────────────┘
```

### 2.2 Void (antagonist stratum)

| Rule | Spec |
|---|---|
| **Noun in systems** | Designer shorthand for the physical gap |
| **Noun in store / UI** | Prefer **fray / gap / seam / tear** ([`../34_ADVERSARIAL.md`](../34_ADVERSARIAL.md) C1) |
| **Must stage** | ≥2 material tells (torn edge + one of: missing plank, dust fall, starved trough, sealed peg, rust bite) |
| **Never** | Starfield, purple nebula, portal iris, infinite black bag |
| **Clear color under tear** | Cooler shed air −8…−12% from substrate — never pure `#000` |

The void does not attack. It **withholds walkability / flow / load** until a Structure rewrites the surface across it.

### 2.3 Surface (craft stratum)

| Rule | Spec |
|---|---|
| **Material** | Warm bone paper / raw canvas / timber yard floor — fiber grain visible |
| **Density** | ~60% substrate · ~25% craft objects · ~10% Threads · ≤5% kiln ([`../09_VISUAL.md`](../09_VISUAL.md) · adversarial C3) |
| **Fragment homes** | Spawns rest on surface, never float in void air as default |
| **Thread path** | Provisional chalk crosses void; seated seam becomes surface law |
| **Inhabit** | Walking / routing happens on rewritten surface — clear requires inhabit |

Surface is the only layer the player’s hands are allowed to treat as a desk.

### 2.4 Core (seed skeleton)

| Rule | Spec |
|---|---|
| **Owns** | Anchor points, legal Fragment pool, Thread budget, Structure slot count, clear predicate, residue policy |
| **Hidden?** | Partially — players feel core as fairness (“same seed, same fray”), not as a debug overlay |
| **Authored teach** | Core is fully designer-placed |
| **Procgen mastery** | Core is generated from seed + archetype grammar (§4), then surface/void dress it |
| **Collapse truth** | Solver reads core load spine; culprit highlight points at surface graph failing core law |

**Hard rule:** Core never rolls hidden loot. Core is a **pure function of seed + content table + residue bias**.

### 2.5 Layer acceptance tests

| Gate | Pass |
|---|---|
| **Strata test** | Mute Survey still: stranger can point to gap (void), desk (surface), and name “this place would replay the same” (core promise) |
| **No float test** | Zero Fragments default-spawn suspended in void air |
| **Seat test** | Standing Structure visibly rewrites surface across void; core clear predicate flips only after inhabit |

## 3. Gaps as antagonist

### 3.1 Product lock

Weaver’s opponent is **not** a mob, a rival weaver, or a clock. The opponent is the **gap** — a staged scarcity that refuses the job until you author a seam.

| Wrong antagonist | Right antagonist |
|---|---|
| Enemy camp / wave spawner | Torn span that will not hold a walk |
| Purple void mood plate | Missing plank + dust fall you can point at in 3s |
| Score attack / DPS race | Load spine that snaps on dishonest Tension |
| Other players’ stalls | Your own prior residue bias answering back |

Carry elevation **E04** ([`../20_ELEVATIONS_V2.md`](../20_ELEVATIONS_V2.md)): camera hero-shots the gap; clear color stays workshop, never nebula.

### 3.2 Gap family (scarcity grammar)

All field archetypes from [`../06_WORLD.md`](../06_WORLD.md) §3 remain valid. 1000× reframes them as **gap cousins** — each is an absence with a different withheld channel:

| Gap cousin | Withholds | Surface tell | Typical Structure answer |
|---|---|---|---|
| **Span gap** | Walkable topology | Torn plank / cloth tear | Span / Scaffold→Span |
| **Flow gap** | Dry path | Spill stain / starved trough end | Culvert / Filter chain |
| **Seal gap** | Passage through block | Peg sealed with kiln crust | Kiln + vent |
| **Beat gap** | Crossing except on pulse | Pendulum scar / knocker notch | Gate (Pulse + Filter) |
| **Load gap** | Safe weight on existing props | Splintered beam, rust bite | Anchor grid, then Span |
| **Feed gap** | Source→sink continuity | Broken channel mid-run | Feed chain literacy |
| **Memory gap** | Neutral teach (residue bias) | Prior silhouette chalk ghost | Answer or counter your last hand |

**Design rule:** every job names **one primary gap cousin**. Dual-channel gaps wait for composition fields ([`../05_STRUCTURES.md`](../05_STRUCTURES.md) · adversarial B2).

### 3.3 Staging contract (mandatory)

Every playable field — authored or procgen — ships this checklist:

1. **Pointable wound** — Survey ≤3s hand tell (adversarial A2).  
2. **Torn edge** — fiber / deckle / splinter into void stratum.  
3. **Scale cue** — stitch length, plank thickness, or dust that sells drop distance.  
4. **Load scar** — chalk survey marks or nail holes from a prior failed span (even if fictional).  
5. **Clear rewrite** — standing + inhabited Structure visibly closes or bridges the wound.

Sandbox free-build **always** spawns one authored fray (adversarial C6). Blank infinite grids are banned as default.

### 3.4 How the gap “fights” (without AI)

| Beat | Gap pressure |
|---|---|
| Survey | Wound occupies the hero plane; quiet ≠ empty |
| Bind | Slack Thread sags into void; illegal snaps flash at the tear |
| Tension | Collapse comedy names the joint that could not span the wound |
| Inhabit | Job rejects decorate-and-skip; you must use the seam |
| Residue | Bias may widen, twist, or cousin-shift the next gap |

## 4. Procgen yards

### 4.1 What “procgen” means here

**Procgen Yard** = deterministic assembly of a field (and optional hub weathering) from:

```
seed + archetype template + fragment pool + residue bias → Core → Surface dress → Void staging
```

It is **not** Perlin tourism, rogue loot floors, or LLM rooms.

| In | Out |
|---|---|
| Grammar modules (anchors, gap mouth, prop kits) | Open-world chunk streaming |
| Seed-stable layouts | Hidden rolls at runtime |
| Mastery / Daily / Endless expansion | Replacing the authored teach ladder |
| Same Loom, different cloth | Always-online shared instance |

### 4.2 Content mix (ship ladder)

| Milestone | World source | Note |
|---|---|---|
| **Vertical slice** | 100% authored jobs (8–12) | Prove verb + gap staging |
| **MVP 1.0** | Authored job mountain (40–60) + **optional** thin procgen dessert (Daily seed) | Teach stays authored |
| **Finished indie 1000×** | Authored campaign spine **plus** procgen Yard packs for mastery / Daily / Endless | Procgen never teaches Fragment families the campaign has not introduced |

**Fence:** Procgen may remix scarcity and prop dress inside unlocked pools. It may **not** unlock nouns ahead of jobs ([`../11_PROGRESSION.md`](../11_PROGRESSION.md)).

### 4.3 Yard generator pipeline

| Stage | Output | Determinism |
|---|---|---|
| **0 · Seed parse** | `yard_id`, archetype, difficulty band, dress skin | Pure |
| **1 · Core emit** | Anchor graph, gap mouth width, Structure slots, Thread budget, clear predicate | Pure |
| **2 · Surface dress** | Substrate skin (dust / damp / kiln-warm), prop kit, Fragment spawn points | Pure |
| **3 · Void stage** | Tear silhouette, dust column, scale cues (≥2 tells) | Pure |
| **4 · Bias apply** | Residue tag from prior clear twists gap cousin or prop kit | Pure of `(seed, bias)` |
| **5 · Softlock net** | Validate ≥1 legal standing graph exists within budget | Reject/re-roll **template params** only via seeded fallback list — never silent RNG |

### 4.4 Module kit (designer-authored atoms)

Procgen is **lego from authored kits**, not noise:

| Module | Role |
|---|---|
| **Gap mouth** | Width / angle / tear style for the antagonist |
| **Anchor set** | Peg clusters that define legal load spines |
| **Prop kit** | Spill barrels, kiln bricks, pendulum posts — skins on archetypes |
| **Spawn tray** | Fragment family subset + port glyph placements |
| **Clear stamp** | Predicate + inhabit path hint (chalk, not quest novel) |
| **Hub weather chip** | Optional Shed Yard cosmetic from corpus ([`../28_LEGACY_V2.md`](../28_LEGACY_V2.md) §6) |

### 4.5 Hub vs field procgen

| Space | Procgen policy |
|---|---|
| **Shed Yard hub** | **Authored** layout forever for brand test. Weathering + gallery only ([`../06_WORLD.md`](../06_WORLD.md) §2.1). |
| **Campaign fields** | Authored first; light seeded variants OK post-literacy (prop dress, gap width band). |
| **Daily / Endless** | Full pipeline §4.3 inside unlocked pools. |
| **Sandbox** | Seeded fray from module kit — never blank. |

### 4.6 Anti-creep fences

| Temptation | Kill |
|---|---|
| Second biome pack as “procgen content” | One Yard; biomes = surface dress skins |
| Infinite unique snowflakes | Caps: finite module kits; recognition > novelty |
| Heavy runtime PCG cost | Profile; prefer bake-at-enter from seed ([`../14_TECH.md`](../14_TECH.md) §3) |
| Procgen as excuse for empty void | Staging contract §3.3 is CI-checked |

## 5. Seed identity

### 5.1 Fantasy

A seed is not a debug int. It is the **identity of a cloth panel** — the name you can speak when you mean a place.

| Promise | Spec |
|---|---|
| **Fair replay** | Same seed + same content version → same Core / Surface / Void staging |
| **Authorship social** | “Same seed, different hands” — share without servers ([`../12_MULTIPLAYER.md`](../12_MULTIPLAYER.md)) |
| **Gallery linkage** | Legacy stamps store `seed_link` ([`../08_LEGACY.md`](../08_LEGACY.md)) |
| **No appointment tax** | Campaign seeds always available offline; Daily is dessert (adversarial A6) |

**Player line:** *“Play `YARD-7F2A` — the east tear is nasty.”*

### 5.2 Seed anatomy

| Field | Meaning |
|---|---|
| **`seed_string`** | Human-pasteable token (e.g. `YARD-7F2A-SPAN` or date-coded Daily) |
| **`content_rev`** | Content table revision — mismatch soft-warns, never cryptic desync |
| **`archetype`** | Primary gap cousin |
| **`dress`** | Surface skin (dust / damp / kiln-warm / fray-remnant) |
| **`bias_in`** | Optional residue tag consumed at enter |
| **`yard_role`** | `campaign` · `daily` · `endless` · `sandbox` · `friend` |

Internal RNG streams (layout, dress pick, fallback) are **hashed from seed_string** — no wall-clock entropy in generation.

### 5.3 Identity surfaces (where players meet seeds)

| Surface | Behavior |
|---|---|
| **Job board** | Campaign contracts show readable names; advanced tooltip may reveal seed token |
| **Field enter** | Quiet diegetic stamp (chalk / ticket) — optional, not a HUD novel |
| **Clear / gallery** | Silhouette stores seed_link for ghost replay |
| **Daily** | UTC date → seed_string; full offline from local clock / bundled rotation |
| **Friend handoff** | Clipboard paste only at MVP; no friends list required |
| **Share still** | Screenshot + seed token in corner is enough social |

### 5.4 Seed ≠ save, seed ≠ loot

| Seed does | Seed does not |
|---|---|
| Define the fray and fair rules | Grant Fragments or recipe unlocks |
| Enable ghost / Daily compare | Require network validation |
| Name the place in gallery | Become a tradable marketplace SKU |
| Drive procgen pipeline | Accrue offline while AFK |

### 5.5 Versioning & fairness

1. **Bump `content_rev`** when module kits change layout meaning.  
2. Ghosts / share codes embed `content_rev`; older rev plays in compatibility mode or shows “cloth revised.”  
3. Stars / elegance never gate seed access.  
4. Softlock net failure → seeded fallback template (logged for designers), never a stuck void.
