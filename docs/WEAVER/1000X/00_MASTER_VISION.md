## 9. Session arc (unit of feeling)

One field is a short garment, not a dungeon crawl.

1. **Survey** — fray announces the job in silhouette (≤3s to a hand).  
2. **Recover** — palm weight; tiny carry forces a plan.  
3. **Bind** — provisional chalk; slack jokes allowed; illegal snap teaches.  
4. **Tension** — held breath; crease → lift → seat or named tear.  
5. **Inhabit** — walk / route / vent through *your* law; this clears the job.  
6. **Residue** — stamp + optional bias whisper; no accrual clock.

Campaign is a stack of these garments hung in one Yard — literacy → catalog → authorship → memory ([`../11_PROGRESSION.md`](../11_PROGRESSION.md)) — never XP theater.
