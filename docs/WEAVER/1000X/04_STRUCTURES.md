## 2. Structure class taxonomy (1000×)

Every stood Structure wears **one primary class**. Archetype (Span, Culvert, Kiln, Gate, Scaffold, Loom-mark) names the *craft shape*; class names the *ecological role*.

### 2.1 Full class roster

| Class | Role in the yard | Primary rewrite | Typical craft shape | Teach phase |
|---|---|---|---|---|
| **Work** *(baseline)* | Does the job body — span, vent, route, brace | Topology / flow / load / pulse / vent | Span, Culvert, Kiln, Scaffold | First-thirty + Demo |
| **Beacon** | Marks a locus; calls attention / Recover | Soft Survey tell (sense → highlight) | Sense peg, flag-fiber, knocker post | Mid 1.0 |
| **Recorder** | Holds a beat or state the field must answer | Pulse / Echo latch | Ledger drum, bellows stamp | Mid 1.0 |
| **Gateway** | Thresholds passage between zones or beats | Topology + Pulse (pick one primary) | Cloth stile, pendulum hatch | Mid–late 1.0 |
| **Scaffold-Host** | Load class that *enables* Structure #2 without becoming a second ecology | Load → permission | Brace lattice, Anchor grid | Composition teach |
| **Residue-Mark** | Leaves a silhouette the next field can answer | Soft bias only (no live rewrite) | Loom-mark stamp | Clear / gallery |

**Naming rule:** craft nouns (beacon pole, ledger drum, threshold loom, brace host) — not myth towers, radar chrome, “AI sentinel,” or EL habit dials.

### 2.2 Class vs archetype (examples)

| Stood graph | Archetype (`05`) | Ecology class |
|---|---|---|
| Anchor–Span–Anchor bridge | Span | Work |
| Pulse + Filter timed door (single zone) | Gate | Work |
| Pulse + Filter door splitting two zones | Gate | **Gateway** |
| Sense-lit peg that reveals a frayed shelf | Loom-mark / custom | **Beacon** |
| Pendulum ledger that stamps a beat latch | — | **Recorder** |
| Scaffold that only enables Structure #2 | Scaffold | **Scaffold-Host** (or Work if no #2) |
| Cleared graph kept as gallery silhouette | Loom-mark | **Residue-Mark** |

**Promotion rule:** a Gate archetype **promotes** to Gateway only when the field authors a true threshold (two zones, clear predicate needs crossing). Otherwise keep Work — vocabulary bloat kills teach jobs.

### 2.3 Explicitly refused classes

| Temptation | Verdict | Why |
|---|---|---|
| Combat tower / aggro turret | **Refuse** | Genre mash |
| Fast-travel hub / biome portal | **Refuse** | Open-world tourism |
| XP shrine / buff totem | **Refuse** | Power Legacy |
| Habit soft/hard adaptation dial | **Refuse** | Echo Lattice import |
| Time-travel / rewind chamber | **Refuse** | Chronomancy ban |
| Prefab “place Beacon from menu” | **Refuse** | Deletes Fragment/Thread skill |
| Living MMO monument other players edit | **Refuse** | Always-online gravity |

## 3. Class specs (listen / answer)

Ecology classes do not merely rewrite — they **speak** a short protocol so composition reads as call → answer, not two unrelated toys.

### 3.1 Protocol vocabulary

| Signal | Emitter | Listener | Spatial tell |
|---|---|---|---|
| **Call** | Beacon | Work / Gateway | Dust mote drift toward locus |
| **Latch** | Recorder | Gateway / Work (Kiln, Culvert) | Chalk tick; seat phrase |
| **Threshold** | Gateway | Player inhabit (cross / send flow) | Cloth stile crease → part |
| **Permit** | Scaffold-Host | Work (Span #2) | Load fiber brightens legal #2 cells |
| **Stamp** | Residue-Mark | Next field / gallery | Pressed cloth silhouette |

Exactly **one primary signal** per stood Structure. Multi-signal Structures are mastery demoware — cut them.

### 3.2 Beacon (deepen)

| Spec | Lock |
|---|---|
| **Stand** | Filter/`sense` or Pulse/`beat` grounded; ≥1 Echo Thread legal |
| **Rewrite** | Soft Survey tell in an **authored radius mask** — recover slots, fray seams, or goal anchors |
| **Inhabit** | Must *use* the tell (walk revealed path / recover called Fragment) |
| **Listen** | None required (emitter) |
| **Answer** | Work or Gateway may require Beacon Call before legal Tension |
| **Residue** | Bias tag `beacon` |
| **Juice** | Mote drift + quiet knocker — no neon ping, no minimap swarm |

### 3.3 Recorder (deepen)

| Spec | Lock |
|---|---|
| **Stand** | Pulse seated; Echo to `sense`/`beat`; optional Charge Feed for sustained stamp |
| **Rewrite** | Writes **beat latch** or **state latch** (open window, flow phase, load permission) — oscillation only, never rewind |
| **Inhabit** | Clear requires acting *on* the latch |
| **Budget** | ≤1 active Recorder latch per field |
| **Residue** | Bias tag `recorder` / `pulse` |
| **Juice** | Audible seat phrase; chalk tick; rust if desynced |

### 3.4 Gateway (deepen)

| Spec | Lock |
|---|---|
| **Stand** | Filter + (Pulse **or** Oppose vent) + braced Anchors |
| **Rewrite** | Topology edge(s) appear/disappear on latch — **one** primary channel per recipe |
| **Inhabit** | Must cross (or send flow) through the threshold |
| **Listen** | May require Beacon Call (which stile) and/or Recorder Latch (when) |
| **Residue** | Bias tag `gateway` / `pulse` |
| **Juice** | Crease → lift → seat; stile opens as cloth parting |

### 3.5 Scaffold-Host & Residue-Mark

| Class | Stand | Rewrite | Inhabit | Fence |
|---|---|---|---|---|
| **Scaffold-Host** | Anchor brace lattice; load path grounded | Permits heavier Structure #2 cells | #2 must stand *and* be inhabited | Never a combat wall; never three-stand maze |
| **Residue-Mark** | Any cleared stood graph elected on clear | None in-field — bias / gallery only | N/A (post-clear) | Never loot; never trade stamp |

## 4. Structure evolution (offline)

Evolution answers: *“Does the yard ever change because of what I wove?”*  
Weaver’s answer is **local Structure evolution** ([`../28_LEGACY_V2.md`](../28_LEGACY_V2.md)) — the save file is the world clock. This section adds **class-aware stages** so ecology hands leave readable scars.

### 4.1 Evolution unit

The unit remains a **stood + inhabited Structure**. Loose Fragments, chalk plans, and uninhabited stands do **not** evolve.

### 4.2 Stages (craft aging, not ranks)

| Stage | Player feels | System | Class tint |
|---|---|---|---|
| **0 · Seat** | “It became floor.” | Pedigree row written on clear | All |
| **1 · Chain** | “This field answered my last kiln / beacon.” | `parent_refs` + rolling bias window | Work / Beacon / Recorder / Gateway tags |
| **2 · Weather** | “The shed wall shifted toward my spans.” | Hub cosmetics + job-board soft order | Dominant class silhouette on gallery |
| **3 · Scar** | “That gap still remembers a fallen scaffold.” | Optional authored field variants | Class-specific scar doors (§4.4) |

No stage called Level, Prestige, Season, or Sync. Stages never grant permanent damage/HP/meta buffs.

### 4.3 Class-aware bias tags

| Tag | Emitted when | Next-field answer (pick one authored beat) |
|---|---|---|
| `work` / archetype tags | Cleared with baseline Work only | Stay on `05` bias table (`span`, `scaffold`, `culvert`, …) |
| `beacon` | Cleared with Beacon Call used | Hidden recover until Beacon; **or** Work-first counter |
| `recorder` | Cleared with Recorder latch used | Beat-match Gateway; **or** starve Echo comfort |
| `gateway` | Cleared via threshold inhabit | Dual-zone Gap/Beat; **or** single-zone Span teach |
| `scaffold_host` | Cleared with Scaffold-Host → Work #2 | Longer #2 teach; **or** over-brace punish |
| `composition` | Cleared with a legal ecology pair | Offer a harder pair; never force three Structures |

**Caps (law):** one primary tag per clear · no softlock bias · no loot bias · determinism · abandon is quiet.

### 4.4 Class scars (literacy doors)

| Scar | Unlocked by | Effect | Fence |
|---|---|---|---|
| **Call scar** | `beacon` chain | Remix job hides a recover until a Beacon stands | Pre-authored mask only |
| **Latch scar** | `recorder` chain | Remix requires matching a stamped beat silhouette | No rewind; no slow-mo |
| **Threshold scar** | `gateway` chain | Dual-zone variant of a prior single-zone job | Still ≤2 stands |
| **Load scar** | `scaffold_host` chain | Earlier permission for a longer Span #2 teach | Thread budget stays honest |
| **Hand scar** | Mixed elegant clears | Optional praise stamp on gallery | Never currency |

Removing all Legacy data must leave the base campaign solvable ([`../08_LEGACY.md`](../08_LEGACY.md) power test).

### 4.5 Evolve ticks (reaffirmed)

| Trigger | May update |
|---|---|
| Field clear (stood + inhabited) | Pedigree, bias window, gallery stamp |
| Return to Shed Yard | Weathering pass |
| Campaign panel advance | Scar unlock checks |
| Manual gallery pin | Shelf layout only |

**Not triggers:** UTC midnight, Steam login, season start, other players’ clears, AFK idle.

## 5. Ecosystems (named formations)

An **ecosystem** is a named, authored pattern of class roles that *answer* each other inside a field — not a base-building island, not an MMO biome, not three-structure demoware.

### 5.1 Formation catalog (1.0)

| Formation | Classes | Player fantasy | Clear sketch | Phase |
|---|---|---|---|---|
| **Lone Work** | Work | “I spanned the gap I made.” | Stand → inhabit | Demo / first-thirty |
| **Call & Carry** | Beacon → Work | “The peg showed the scarce plank; I built the answer.” | Call → recover → Work → inhabit | Mid 1.0 |
| **Call & Cross** | Beacon → Gateway | “The knocker marked which stile; I crossed it.” | Call → threshold → cross | Late 1.0 |
| **Latch & Cross** | Recorder → Gateway | “The drum kept the beat I had to walk.” | Latch → timed cross | Late 1.0 |
| **Latch & Vent** | Recorder → Work (Kiln/Culvert) | “The latch permitted the release.” | Latch → vent/route → inhabit | Late 1.0 |
| **Brace & Span** | Scaffold-Host → Work | “The lattice let the longer bridge seat.” | Permit → Span #2 → inhabit | Composition teach |
| **Stamp Echo** | Residue-Mark (meta) | “The next yard whispered my silhouette.” | Prior clear bias → teach variant | Cross-field |

### 5.2 Ecosystem laws

1. **≤2 stood Structures per field** at 1.0 (Residue-Mark is post-clear, not a third stand).  
2. **One primary formation per job** — do not stack Call & Cross inside Latch & Vent.  
3. **Order is authored** — illegal order fails Tension or Frays the listener with a readable tell.  
4. **Determinism** — same seed + same graphs + same latch timeline → same ecosystem outcome.  
5. **Offline** — no server-synced “living” ecology; Legacy stays local ([`../28_LEGACY_V2.md`](../28_LEGACY_V2.md)).

### 5.3 Illegal / deferred ecosystems

| Pattern | Why deferred / refused |
|---|---|
| Beacon + Recorder + Gateway (three stands) | Slot & readability breach |
| Beacon → Beacon chains | Minimap meta; deletes Survey skill |
| Recorder → Recorder stacks | Chrono kit smell; desync hell |
| Gateway → Gateway maze | Habit-maze gravity (wrong SKU) |
| Yard-wide always-on ecosystem sim | Idle / MMO gravity |
| Player-built “village” of Structures | Base-building island |

### 5.4 Yard-scale ecology (meta, not in-field)

Across jobs, the Shed Yard may reflect the player’s dominant formation hand via weathering ([`../28_LEGACY_V2.md`](../28_LEGACY_V2.md) §6):

| Dominant hand | Yard whisper |
|---|---|
| Lone Work / Brace & Span | Gallery shelves lean Span / Scaffold silhouettes |
| Call & Carry / Call & Cross | Knocker props; soft “hidden shelf” job-board tips |
| Latch & Cross / Latch & Vent | Pendulum chalk; beat-literacy board order |
| Mixed composition clears | Dual-silhouette shelf; harder pair offered |

Whispers are **cosmetic + pedagogy**. Never loot, never FOMO timers, never online presence.

## 6. Composition grammar

Composition is how two stood Structures (or Scaffold-Host → Work) share a clear predicate without becoming Besiege megastructures.

### 6.1 Slot & budget

| Budget | Lock |
|---|---|
| Structure slots | **1** default; **2** on authored composition / ecology jobs |
| Thread budget | Shared across both graphs — teach scarcity, not two full looms |
| Latch budget | ≤1 Recorder latch |
| Beacon radius | Authored mask cells only |
| Channel teaching | One primary rewrite channel per Structure; dual-channel only as mastery after literacy |

### 6.2 Legal order (listen before answer)

| Order | Legal? | Fail tell |
|---|---|---|
| Beacon → Work / Gateway | Yes | — |
| Recorder → Gateway / Work | Yes | — |
| Scaffold-Host → Work (#2) | Yes | — |
| Work → Work (Scaffold→Span) | Yes (`05` composition) | — |
| Gateway before required Beacon Call | No | Stile stays chalk-ghost; coach soft warn |
| Gateway before required Recorder Latch | No | Edge absent; desync rust on attempted open |
| Work #2 before Scaffold-Host Permit | No | Floating seam / grounding fail |
| Three stands | No | Authoring reject |

### 6.3 Multi-channel mastery (post-teach)

MVP teaches **one channel** at a time (topology / flow / load / pulse / vent). Composition mastery may seat:

| Pair | Channels | Fantasy |
|---|---|---|
| Culvert (flow) + Span (topology) | Two | Route hazard, then walk the dry path |
| Scaffold-Host (load) + Gate/Gateway (pulse) | Two | Brace the stile, cross on the beat |
| Beacon (soft sense) + Kiln (vent) | Soft + vent | Call the seal, then vent it open |

**Hard fence:** never require three channels or three Structures. Never import EL dual-axis habit mazes as “composition.”

### 6.4 Inhabit is still the win

Standing both Structures is ceremony. **Using** the formation clears the job ([`../20_ELEVATIONS_V2.md`](../20_ELEVATIONS_V2.md) E07 · [`01_CORE_LOOP.md`](01_CORE_LOOP.md)). Build-alone never auto-wins — including ecology pairs.

| Formation | Inhabit verb |
|---|---|
| Lone Work | Walk / route / release through the Structure |
| Call & Carry | Recover called Fragment → inhabit Work |
| Call & Cross | Cross the called stile |
| Latch & Cross | Cross while latch open |
| Latch & Vent | Release / route during latch window |
| Brace & Span | Walk the #2 Span (Host alone never clears) |

## 7. Solver & implementation contracts

| Check | On Tension | On fail / Fray |
|---|---|---|
| Port legality | Threads match ports + type | Snap highlight |
| Class legality | Graph matches class recipe | Snap missing port |
| Single primary class | Exactly one class flag per stand | Reject stand |
| Formation order | Listener prerequisites met | Soft coach chalk or illegal Tension |
| Latch budget | ≤1 Recorder latch | Second latch illegal or Oppose-vents the first |
| Beacon radius | Authored mask only | Over-claim → coach warn |
| Gateway edge | Claimed edges exist in topology table | Floating stile → grounding fail |
| Slot cap | ≤ authored Structure slots | Reject third stand |
| Goal relevance | Soft warn if formation cannot touch clear predicate | Never auto-build |
| Determinism | seed + graphs + latch timeline → same outcome | No hidden rolls |

**Suggested types (later):** `StructureClass` enum · `FormationId` on job content · pure functions `adapt(seed, bias_tag, stands[])` · evolve in `game/weaver/scripts/meta/legacy_evolve.gd` (+ Python contract tests).
