## 0. One sentence

Hands gather scarce **Fragments**, fingers combine them into **Threads**, a commit weaves a **Structure** across a torn gap, and the Structure **expands** the field — but you only win when you **inhabit** what you authored.

```
GATHER → COMBINE → WEAVE → INHABIT → EXPAND → (gather again)
         └─ comedy fail / cheap retry ─┘
```

**1000× is not more verbs.** It is one craft cycle made undeniable at every timescale — palm micro-beats, field clears, Yard return, and residue memory — so a mute trailer and a two-hour Yard session still speak the same sentence.

## 1. Verb map (prototype ↔ systems GDD)

The live Loom (`gather` / `combine` / `weave` / emit) and the systems grammar (`Recover` / `Bind` / `Tension` / `Inhabit` / `Residue`) are **one loop with two faces**. This doc is the depth authority for how they nest.

| Prototype face (hand / UI) | Systems face (GDD) | What the player *owns* |
|---|---|---|
| **Gather** | Recover (+ Survey entry) | Fragments in palm — weight, not currency |
| **Combine** | Bind | Threads between ports — relation, not recipe toast |
| **Weave** | Tension → Stand | Structure seats or collapses with a named culprit |
| **Inhabit** | Inhabit | Walk / route / use the law you wrote |
| **Expand** | Residue + emit / field answer | The loom sheds new scarcity; next gather is earned |

| Soft alias (docs / coach) | Never ship as |
|---|---|
| Survey | A separate minigame or loading beat |
| Residue / Legacy | Offline drip, login reward, or trade good |
| Emit (Structure shed) | Idle autofarm while AFK |

**Hard rule:** if a feature cannot be pointed at as gather, combine, weave, inhabit, or expand, it is not core loop.

## 3. Layered loops (the depth model)

Weaver’s loop is a **stack**, not a checklist. Each layer reuses the same four verbs; only the *question* changes.

```
META   (campaign / Yard memory)     Residue bias · gallery stamp · literacy unlock
  └─ MACRO (job / field clear)      Survey → … → Inhabit clear → Expand close
       └─ MESO (graph draft)        Gather⇄Combine⇄Weave until a Structure stands
            └─ MICRO (gesture)      Palm settle · fiber scrape · seat phrase · foot plant
```

### 3.1 Micro-loop — gesture (tenths of a second → ~2 s)

The nervous-system unit. Authority clocks live in [`../23_WEAVE_VERB.md`](../23_WEAVE_VERB.md); this doc only names **which micro beats close which verb**.

| Verb | Micro beat (must feel) | Comedy fail (cheap) | Close signal |
|---|---|---|---|
| **Gather** | Palm mass settle 120–180 ms | Wrong-tug recoil; Fragment stays; dust puff | Slot depress / carry tick |
| **Combine** | Fiber scrape → port kiss or snap | Illegal snap; Thread budget unspent | Bind settle 30–50 ms |
| **Weave** | Crease → lift → seat (0.9–1.2 s) | Collapse holds culprit ~0.5 s; undo Tension | Joint bite + dust |
| **Inhabit** | First footstep on new law ≠ dirt | Mis-step off seam; Structure may fray, not delete pride | Goal predicate tick |
| **Expand** | Quiet shed / stamp / next-gap hunger | Overfull hands refuse emit pickup (comedy, not sell CTA) | New Fragment appears *or* residue seals |

**Micro invariant:** every fail is **readable in the body** before any caption. No modal essay.

### 3.2 Meso-loop — graph draft (~15–90 s)

One attempt to stand a Structure (or revise after collapse).

```
Gather Fragments ──► Combine Thread(s) ──► Weave (Tension)
       ▲                    │                    │
       │                    │ illegal snap       │ collapse
       │                    └──────────┬─────────┘
       │                               │ comedy tell + refund
       └────────── adjust one thing ───┘
                         │
                         ▼ stand
                    INHABIT gate opens
```

| Meso law | Lock |
|---|---|
| Carry tiny | 3–5 Fragment slots; full-hands is a comedy beat, never a shop |
| Thread budget readable | 4–8 provisional binds; last Thread always removable pre-weave |
| One-commit undo | Re-pin fiber, not “reload checkpoint” ([`../20_ELEVATIONS_V2.md`](../20_ELEVATIONS_V2.md) E12) |
| Collapse teaches | Culprit joint + audible tear; Fragments refunded with soft rustle |
| No auto-win on stand | Meso ends at **Stand**; macro still requires Inhabit |

### 3.3 Macro-loop — field / job clear (~3–8 min teach; ≤24 min first useful Structure)

The unit of pride. Aligns with [`../02_CORE_LOOP.md`](../02_CORE_LOOP.md) six-beat session, with expand made explicit.

| Beat | Prototype verb | Player does | System answers | Fail feel |
|---|---|---|---|---|
| 1 | Survey (entry) | Read the torn gap / starved basin | Solvable scarcity, no timer panic | Quiet — finger finds gap ≤3 s |
| 2 | **Gather** | Recover Fragments near the job | Typed atoms with ports | Wrong pick cheap |
| 3 | **Combine** | Bind Threads | Legal relations or craft snap | Comedy snap, not red toast |
| 4 | **Weave** | Tension the graph | Stand or readable collapse | ≤30 s adjust → retry |
| 5 | **Inhabit** | Walk / route / use Structure | Goal predicate (reach, irrigate, brace, silence) | Soft reset returns owned Fragments |
| 6 | **Expand** | Leave / accept field answer | Emit shed, residue stamp, next-field bias | Optional abandon; no shame economy |

**Macro win predicate (hard):**

```
CLEAR ⇔  goal_true AND ≥1 Structure standing AND player completed inhabit verb
```

Build-alone never clears. Tension-alone never clears. Emit while AFK never clears.

### 3.4 Meta-loop — Yard memory (session → campaign)

| Meta beat | Feeling | Fence |
|---|---|---|
| Return to Shed Yard | “My stamps are on the shelf” | Gallery is pride only — no currency ([`../34_ADVERSARIAL.md`](../34_ADVERSARIAL.md) A5) |
| Residue biases next field | Loom remembered your hand | Bias changes only on clear/abandon confirm — never wall-clock |
| Literacy unlock | New port / Thread type earned by doing | No XP bar theater; stamps name craft acts |
| Expand hunger | Standing Structures shed Fragments that invite the next gather | Emit is **post-inhabit dessert**, not an idle engine |

**Meta invariant:** progress without a hand verb is forbidden. Expand feeds gather; it does not replace gather.

## 4. Verb depth (gather / combine / weave / expand)

### 4.1 Gather — scarcity with weight

| Lock | Meaning |
|---|---|
| **Craft gather, not loot** | No rarity borders, magnet beams, or Pokémon catch juice ([`../35_JUICE.md`](../35_JUICE.md)) |
| **Palm literacy** | Families sort by settle mass + silhouette (reed / timber / copper) |
| **Full-hands comedy** | Refuse + soft knock: “Hands full.” — opens combine, never sell/trash |
| **Survey ≤3 s to a hand** | Gap tell is tangible before the first tip |

**Micro comedy catalog (gather):**

| Fail | Tell | Retry |
|---|---|---|
| Wrong-tug | Stretch → recoil; Fragment stays | Immediate |
| Full hands | Dry knock; carry slots flash once | Combine or drop last (if field allows) |
| Starved basin empty | Dust only; coach silence | Re-read gap; Structure emit may refill later |

### 4.2 Combine — relations, not wiki cells

| Lock | Meaning |
|---|---|
| **Ports over paragraphs** | Brace notch / feed mouth / oppose vent / echo tick |
| **Slack before taut** | Provisional Thread always starts slack; climb is the skill surface |
| **Illegal = comedy snap** | Dry break; ports flash once; budget unspent |
| **Anti-spreadsheet** | Authored jobs teach pairs in place; no encyclopedia before jobs exist |

**Combine does not “craft an item.”** It authors a **relation**. The dopamine is *this stitch will hold* — not a green checkmark.

### 4.3 Weave — ceremony with teeth

| Lock | Meaning |
|---|---|
| **Commit is deliberate** | Hold/release; ~200 ms input lock; no mash-to-win seat |
| **Seat phrase** | Crease → lift → seat → settle; wood/cord downbeat is the loudest honest hit |
| **Collapse is information** | Culprit highlight ~0.5 s; speech test: player names the fail without help UI |
| **Stand ≠ clear** | Camera may hold 2 s on lock — then the job still asks for feet |

### 4.4 Expand — the flywheel, fenced

**Expand** is the 1000× name for how a cleared (or inhabited-standing) field **answers** and invites the next gather. It unifies:

| Expand face | When | Player read |
|---|---|---|
| **Emit / shed** | After Structure stands *and* inhabit has begun (or clear) | “The loom answers” — new Fragments appear near the span |
| **Residue stamp** | On field clear | Quiet cloth panel / silhouette |
| **Next-field bias** | Entering the following job | Grammar shift you authored — not a buff % |
| **Yard hunger** | Hub return | One next-gap tell; never appointment lock |

| Expand fence | Why |
|---|---|
| No AFK emit progress | Idle death mode ([`../34_ADVERSARIAL.md`](../34_ADVERSARIAL.md)) |
| No emit while player is offline | Offline-first ≠ offline accrual |
| Emit never auto-clears the job | Inhabit-to-win |
| Emit kinds stay tiny | Anchor/Span teach; no loot table cosplay |
| Expand never requires network | Friend codes later; loop complete alone |

**Prototype note:** current Loom `emit_from_structure` is a **vertical-slice stand-in** for Expand. Depth work must retarget emit timing to **post-inhabit** (or gated by first foot on Structure) so build-and-walk-away cannot farm.

## 5. Failure comedy (primary teacher)

Collapse and rejection are **not punishment meters**. They are the anti-wiki curriculum ([`../20_ELEVATIONS_V2.md`](../20_ELEVATIONS_V2.md) E01).

### 5.1 Comedy contract

| Rule | Lock |
|---|---|
| **Body first** | Eye sees culprit; ear hears tear/snap; palm feels recoil — then optional one-line caption |
| **Cheap retry** | Soft fails <1 s; Tension collapse → adjust → stand under 30 s |
| **No shame economy** | Abandon leaves optional residue; never wipe account or tax “lives” |
| **Funny ≠ slapstick** | Dry workshop humor (overfull hands, slack joke, seam that won’t take) — not cartoon humiliation |
| **Same seed, same grammar** | Comedy fails are deterministic tells, not RNG pranks |

### 5.2 Fail taxonomy

| Class | Example | Player line | Refund |
|---|---|---|---|
| **Palm reject** | Full hands, wrong-tug | “Too much / too light” | Instant |
| **Port comedy** | Illegal bind snap | “Wrong mouth” | Thread unspent |
| **Slack joke** | Teach field forces one intentional slack before useful seat | “It wasn’t tight” | Redraw |
| **Collapse** | Overload / cycle / starve at Tension | “That brace took the tear” | Fragments back; undo Tension |
| **Inhabit miss** | Walked off; goal false; optional fray | “I built it and still had to cross right” | Structure may stand; retry path open |
| **Expand refuse** | Emit Fragment while carry full | “Hands full — combine first” | Fragment waits in field |

### 5.3 Teaching ladder via comedy (first hour)

| Field | Comedy teacher | Must feel |
|---|---|---|
| F0 | Soft wrong-tug + first legal seat | Parts became place |
| F1 | Illegal bind snap | Craft tell, not UI lecture |
| F2 | Collapse from overload | Failure is information |
| F3 | Inhabit miss on a standing span | Stand ≠ win |
| F4 | Expand shed with full hands | Flywheel invites combine, not sell |

## 6. Inhabit-to-win (non-negotiable)

Elevations E07 and adversarial A3 already state the bet. This section makes it **loop law**.

### 6.1 Win stack

| Layer | Success looks like | Explicitly not enough |
|---|---|---|
| Micro | Foot plant on new material | Watching the seat VFX |
| Meso | Structure stands | Graph looks “correct” in chalk |
| Macro | Goal predicate true **while** Structure stands **and** inhabit verb completed | Menu “Complete” after weave |
| Meta | Stamp + expand hunger | Gallery screenshot without a clear |

### 6.2 Inhabit verbs (spatial / systems only)

| Inhabit form | Goal example | Mute GIF must show |
|---|---|---|
| **Walk** | Cross the span you seated | Feet on stitch → far side |
| **Route** | Send flow through culvert, then cross dry | Flow then walk |
| **Brace-use** | Second Structure rests on your scaffold | Load transfer readable |
| **Pulse-match** | Cross gate on the beat you authored | Wait → step on beat |
| **Vent-and-go** | Dump Charge safely, then pass | Vent plume → path opens |

**Banned clear conditions:** kill-count, score chase, timer gold-only, “decorate the yard,” AFK emit quota.

### 6.3 Ceremony order (protect this)

1. Weave seats (pride inhale).  
2. **Inhabit proves ownership** (pride exhale).  
3. Expand answers (hunger, not fanfare).  

Swap 2 and 3 and the fantasy becomes idle. Skip 2 and the fantasy becomes a builder menu.

## 9. Resources (still tiny)

Scaricity stays **ports, spans, collapse risk** — not parallel currencies.

| Resource | Loop role | Cap intuition |
|---|---|---|
| Fragment carry | Gather pressure → combine comedy | 3–5 |
| Thread budget | Combine → weave tension | 4–8 |
| Tension commits | Weave ceremony scarcity | 1 teach / 2 mastery per field |
| Inhabit path | Win gate | Mandatory on campaign jobs |
| Expand marks | Residue + optional emit | 1 signature ± scrap; emit kinds tiny |

No gems, stamina, battle pass, or “expand energy.”

## 10. Acceptance tests (1000× gates)

| Gate | Pass |
|---|---|
| **Clip test** | 60–90 s silent: gather → combine → weave → inhabit (walk) → expand tell |
| **Layer test** | Designer can name which layer a bug lives on (micro/meso/macro/meta) in one sentence |
| **Comedy test** | Cold player recovers from three distinct fails (port snap, collapse, full hands) without help screen |
| **Inhabit test** | QA: weave stand without inhabit **fails** the job every campaign field |
| **Idle kill** | Structure emit does not advance clear or currency while input idle ≥30 s |
| **Speech test** | After collapse, player names the failing seam without opening UI |
| **Still test** | One frame of stand+walk reads as woven law underfoot, not a placed prop |
| **Purity test** | Removing “AI / multiplayer / idle / combat” does not empty the pitch |
| **Flywheel test** | After clear, expand creates a *want* to gather again — not a want to wait |
