## 0. Thesis

`04` locks **four Thread types** and the designer cheatsheet. `22` locks **how combinations are taught without a wiki**. This 1000× doc locks **depth inside the cap** — richer chemistry per type, discovery that lives in the field, recipe design that trails jobs, and hard ceilings that still feel like mastery.

**One-line brief:** _Four stitches, endless yards — chemistry taught by gaps, never by encyclopedia._

```
Thread¹⁰⁰⁰ˣ = (type ∈ {Brace,Feed,Oppose,Echo}, ports, span_cost, stress, tell)
Depth = remix × job fences × graded stress · NOT more type enums
```

**Still test:** mute + greyscale Bind clip — stranger names the stitch verb (“brace / feed / vent / beat”) from contour alone, recovers from one illegal snap without Help, and never asks for a recipe list.

**Cap reminder (law):** **≤4 Thread types for all ship milestones.** Vertical slice teaches Brace→Feed first; Oppose/Echo after clip gates. Structure recipes ≤8 slice / ≤20 at 1.0; recipe count ≤ job count always ([`../17_MVP.md`](../17_MVP.md) · [`../34_ADVERSARIAL.md`](../34_ADVERSARIAL.md) B5/B8).

## 2. Thread types (1000× bible — still four)

Ship **exactly four**. Resist a toolbox of twelve. Depth is **how each type behaves under load, remix, and field scarcity** — not new enums.

### 2.1 Type roster (unchanged names)

| Type | Ports it respects | Play meaning | Signature fail |
|---|---|---|---|
| **Brace** | `brace` ↔ `brace` or `brace` → `ground` | Holds load; makes spans stand | Overload tear |
| **Feed** | `out` → `in` (or `release` → `in`) | Moves flow / charge / material | Starve or burst |
| **Oppose** | `out`/`release` → stressed port | Cancels or vents excess | Blowback if mis-aimed |
| **Echo** | `sense`/`beat` → `sense`/`beat`/`in` | Copies rhythm or state; no mass transfer | Desync chatter / false beat |

### 2.2 Body & ear (each type must be distinguishable mute-on)

Authority contours: [`../26_AUDIO_V2.md`](../26_AUDIO_V2.md) · juice: [`../35_JUICE.md`](../35_JUICE.md) · clocks: [`../23_WEAVE_VERB.md`](../23_WEAVE_VERB.md).

| Type | Draw feel (forearm) | Legal seat tell | Fail tell | Banned cheap tell |
|---|---|---|---|---|
| **Brace** | Thick scrape; line fattens with span | Timber / cord bite; dust at pins | Rust creep → white tear at overload joint | Neon “STR +2” beam |
| **Feed** | Slicker pull; slight sag toward gravity / flow bias | Soft fill tick; damp or dust path along fiber | Starve hush (nothing arrives) or burst puff at far port | Pipe-game rainbow flow |
| **Oppose** | Short, stubborn drag; resists overshoot | Vent hiss / kiln copper crest ≤10% frame | Blowback kick toward source; heat shimmer wrong way | Shield bubble / combat block VFX |
| **Echo** | Light tick-tick contour; almost no mass | Beat shadow / pendulum ghost on destination | Desync chatter; false open on Gate | Purple pulse rings / chronometer UI |

**Literacy test:** blind A/B — players sort four seated Threads by sound+thickness alone ≥75% after teach set.

### 2.3 Mastery axes *inside* a type (not new types)

| Axis | What changes | What must not change |
|---|---|---|
| **Span cost** | Longer draws spend more budget; teach short→long | Separate “Long Brace” type enum |
| **Stress grade** | Slack → taut → rust → tear continuum | HP bars / floating integers on the fiber |
| **Crossing soft-rule** | Planarity stress rises; sometimes legal | Hard “no cross” puzzle rule as default |
| **Channel role** | Same type serves Topology / Flow / Load / Pulse / Vent jobs when ports allow | Multi-channel accept predicates before F3 ([`../34_ADVERSARIAL.md`](../34_ADVERSARIAL.md) B2) |
| **Composition count** | 1–2 Threads teach; sparse graphs mastery | “Use all budget” as a star primary |

### 2.4 Teach order (hard)

| Gate | Types available | Why |
|---|---|---|
| **W1 spike / F0–F1** | Brace (+ Feed when culvert jobs land) | 4×2 chemistry fence with Span/Anchor |
| **F2–F3** | Brace · Feed | Port mismatch + overload + irrigate literacy |
| **Post-clip** | + Oppose | Kiln / vent comedy |
| **Post-gate literacy** | + Echo | Pulse gate without chronomancy framing |
| **1.0** | All four only | No fifth type without a human reopen of MASTER |

### 2.5 Non-goals (reaffirmed + 1000× traps)

| Out | Why |
|---|---|
| Damage / aggro Threads | Combat mash |
| Trade / market Threads | Solo economy fence |
| Chrono / rewind Threads | Banned with Time Fragments |
| Friendship / faction Threads | Social sim mash |
| Freeform any-to-any | Deletes skill |
| **“Smart Thread” / auto-route** | Deletes authorship; Coach E3 partial ghost is the max assist ([`../22_DISCOVERY_UX.md`](../22_DISCOVERY_UX.md)) |
| **Fifth type for DLC heat** | Cap breach masquerading as ambition |
| **Type skins that change legality** | Cosmetics must not rewrite ports |

## 3. Discovery chemistry

Chemistry is the **player’s mental model** of which ports take which stitches and which graphs stand. 1000× chemistry is **discovered in the yard**, not looked up.

### 3.1 Chemistry stack (always on → escalate)

Aligned to [`../22_DISCOVERY_UX.md`](../22_DISCOVERY_UX.md) affordance stack; Thread-specific tells emphasized.

```
Port glyphs → affinity warmth → illegal snap → slack/rust/tear
        → collapse culprit (≤2 elements) → field scarcity staging
        → (optional) coach chalk → pattern whisper → partial ghost
```

| Layer | Thread lesson | Spoiler level |
|---|---|---|
| Port glyphs | Brace notch ≠ feed mouth | None |
| Affinity warmth | Soft fiber pull near legal port | Low — “might take a stitch” |
| Illegal snap | Names the port conflict in one glyph flash | Low |
| Slack / rust / tear | Load literacy on the fiber body | Low |
| Culprit highlight | Which Thread/Fragment lied | Medium |
| Scarcity staging | Gap implies Brace; flood implies Feed; heat implies Oppose; pendulum shadow implies Echo | Medium — channel without recipe |
| Coach E1–E2 | Hungry port or archetype noun | Medium |
| Coach E3 | ≤50% partial graph | High — opt-in only |

### 3.2 Pattern vocabulary (verbs, not menu IDs)

Players learn **patterns as verbs**. Designers may keep the internal cheatsheet (`04` §5); players never see it as UI.

| Pattern verb | Typical Threads | Field staging that teaches it | Player should say |
|---|---|---|---|
| **Span** | Brace ×2 to ground/anchors | Torn gap; only brace-legal parts | “I held the gap.” |
| **Scaffold** | Brace grid → longer Brace | Undersized first span; second Tension | “I pinned, then reached.” |
| **Irrigate** | Feed chain (+ Filter) | Hazard path + dry walk goal | “I routed it aside.” |
| **Vent** | Feed into Charge + Oppose out | Heat / burst without chimney | “I gave the push somewhere to go.” |
| **Gate** | Echo beat → Filter/sense; optional Feed | Pendulum shadow; cross on authored beat | “I walked my own tempo.” |
| **Brace-and-feed** | Brace skeleton + Feed service | Composition field after single-channel literacy | “The frame carries the flow.” |

**Remix rule:** every non-teach job accepts **≥2 distinct legal graphs** so “the” wiki solution is false ([`../34_ADVERSARIAL.md`](../34_ADVERSARIAL.md) B7).

### 3.3 Field ecology as chem lab

| Staging lever | Chemistry it suggests | Must not |
|---|---|---|
| Gap silhouette | Brace / Span | Floating objective marker that spells “USE BRACE” |
| Damp stain / dust river | Feed / Culvert | Full path ghost of the winning Feed chain |
| Kiln shimmer / Charge throb | Oppose vent | Tooltip “Oppose → ground” |
| Pendulum shadow | Echo / Gate | Chronometer overlay |
| Residue bias silhouette | Prior pattern family | Complete prior solution inject |

### 3.4 Speech test (discovery pass)

After a stuck-then-clear, the player can say one of:

- “The loom hinted — I still had to stitch it.”  
- “That edge wouldn’t take a feed.”  
- “Too much on one fiber.”  
- “Nothing reached the far port.”

If they say “I looked up the kiln recipe,” the field staging and hint ecology failed — fix content, do not ship a bigger wiki.

## 4. Anti-wiki recipe design

A **recipe** in Weaver is an *earned stamp of an archetype you stood*, not a craft encyclopedia entry. 1000× product stance: **jobs write chemistry; stamps trail clears**.

### 4.1 Recipe object (thin)

| Field | Allowed | Forbidden |
|---|---|---|
| Name | Craft noun (Span, Culvert, Kiln, Gate…) | RPG role / loot rarity title |
| Silhouette | Greyscale standing graph outline | Step-by-step node map |
| Primary channel | Topology / Flow / Load / Pulse / Vent | Multi-channel dump on teach stamps |
| First-clear date / yours | Local save pride | Global leaderboard of “fastest wiki clear” |
| Optional study ghost | **Your** best graph from **your** save | Global optimal inject into campaign jobs |
| Thread sequence list | Never in stamp UI | Designer-only internal docs |

### 4.2 Recipe ↔ job law (hard)

| Law | Spec | Ship test |
|---|---|---|
| **Recipes trail jobs** | Recipe stamp count ≤ job count at every milestone | Content spreadsheet gate in ROADMAP reviews |
| **Slice ceiling** | ≤8 recipes with 8–12 jobs | Vertical-slice audit |
| **1.0 ceiling** | ≤20 Structure recipes; 40–60 jobs | MVP mountain (`17` §4) |
| **Jobs constrain chemistry** | Job spec lists `families[]`, `threads[]`, `channel` | Tools reject wild cards in teach set (B1) |
| **One channel until F3** | No dual-channel accept predicates early | Teaching ladder audit (B2) |
| **Alternate clears** | ≥2 legal graphs on standard jobs | Second solution sketched before lock (B7) |
| **No searchable wiki** | Compendium = earned stamps only | Cold playtest with Help closed + network off |

### 4.3 What authors write instead of a wiki

Content authors maintain:

1. **Internal chemistry cheatsheet** (`04` §5 + this §3.2) — never player UI.  
2. **Job fences** — allowed families/types/channel + scarcity staging.  
3. **E1 truthful highlight** + **E2 noun** + **E3 partial ghost** (authored, not raw solver MST).  
4. **Stamp silhouette** on first honest clear.

Players get affordances and jobs. External community guides may exist post-launch; the game must be completable without them ([`../22_DISCOVERY_UX.md`](../22_DISCOVERY_UX.md) §6).

### 4.4 Star / elegance (anti-spreadsheet)

If stars exist ([`../02_CORE_LOOP.md`](../02_CORE_LOOP.md) §5):

| Grade | Primary | Secondary | Never |
|---|---|---|---|
| Inhabit clarity | “Could a stranger walk it?” | Leftover Thread budget | Hidden weight matrix published to players |
| Comedy recovery | Collapse→retry without Help | — | Shame economy / hint debt |
| Sparse mastery | Few smarter Threads | — | “Use exactly N Threads” as only truth |

Star rubric must fit on **one index card** (B4).

### 4.5 Marketing & demo fences

| Surface | Policy |
|---|---|
| Trailer | May show **one** clear pattern; do not publish a public recipe bible before launch |
| Demo | First Structure clearable with Coach ≤ E2 unless player opts into E3 |
| Pause / Help | Verb grammar + port legend — **zero** recipe list |
| Achievements | No “found all combos” collection mash |

## 5. ≤cap with depth

1000× depth is **combinatorial remix under hard ceilings**, not catalog growth.

### 5.1 Hard caps (print on the wall)

| Cap | Slice | MVP 1.0 | Post-1.0 park |
|---|---|---|---|
| Thread **types** | ≤4 (teach ≤2 first) | **4** | Fifth type requires MASTER reopen |
| Thread **budget** / field | Teach ~4 · standard ~6 · mastery soft ~8 | Same intuition | Sandbox may raise with literacy gate |
| Fragment families | ≤6 | ≤12 ([`02_FRAGMENTS.md`](02_FRAGMENTS.md)) | Encyclopedia lane closed |
| Structure recipes | ≤8 | ≤20 | DLC only if jobs≥recipes still holds |
| Jobs | 8–12 | 40–60 | — |
| Tension commits / field | 1 teach / ≤2 mastery | Same | — |
| Coach spoiler | E3 ≤50% ghost | Same | No auto-complete win |

### 5.2 Depth levers (allowed — spend these, not new types)

| Lever | How it deepens Threads | Cap interaction |
|---|---|---|
| **Port literacy** | Illegal snap as teacher; more ports on deepen Fragments | Types stay four |
| **Stress continuum** | Slack→rust comedy; soft planarity | Still spatial tells, no DPS sheet |
| **Scarcity remix** | Same four stitches, new gaps | Jobs carry novelty |
| **Composition** | Brace frame + Feed service; Scaffold→Span | Second Tension, not new type |
| **Residue bias** | Next field favors/counters last pattern | Whisper, not wiki unlock tree |
| **Echo desync** | False beat mastery without chronomancy | Echo stays non-mass |
| **Oppose aim** | Blowback comedy as skill | Vent literacy, not combat |
| **Elegance** | Sparse graphs preferred | Budget soft cap teaches restraint |
| **Multi-Structure fields** | Structure #2 needs #1 load channel | Thread budget shared |

### 5.3 Depth math (honest)

```
Depth ≈ (4 types) × (port grammar) × (stress/span) × (job fences)
        × (≥2 solutions) × (residue bias)
        — NOT (types++) × (recipe encyclopedia)
```

If design meetings spend more time on compatibility matrices than on gap silhouettes, park content expansion (kill criterion B — [`../34_ADVERSARIAL.md`](../34_ADVERSARIAL.md) §2.3).

### 5.4 Prototype fence (do not skip)

| Spike | Chemistry | Exit |
|---|---|---|
| **W1** | Span/Anchor + Brace/(Feed) | Mute clip: gather→combine→weave without full matrix |
| **Post-W1** | Add Filter/Charge + Oppose | Vent kiln comedy readable |
| **Post-gate** | Add Pulse + Echo | Gate on authored beat; no rewind framing |

Adding Oppose/Echo before Brace/Feed literacy is a **cap violation in spirit** even if the enum count stays four.

### 5.5 Budget UX (soft cap, hard honesty)

| Signal | Player read |
|---|---|
| Chalk quota ticks (quiet) | Budget remaining — diegetic fiber stubs, not “MP 3/8” |
| Span cost thicken | Longer stitch spends more |
| Soft refuse on over-budget draw | Line won’t seat chalk; one coach line max |
| Mastery fields | Higher soft cap; stars still prefer sparse |

Never gate story on perfect Thread-count min-max.
