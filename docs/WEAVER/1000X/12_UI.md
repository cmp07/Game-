## 0. Thesis — what 1000× means for UI

**1000×** is not denser HUD widgets. It is **one shell fiction made undeniable**:

> The menu *is* the Shed Yard’s job book. In-run chrome *is* craft marginalia. Settings *are* tool-chest leaves. Captions *are* coach chalk.

| Soft spot today | 1000× elevation |
|---|---|
| Lattice folio hosts Weaver brand + CTAs ([`../BUILD_ON_LATTICE.md`](../BUILD_ON_LATTICE.md)) | **Yard Folio** owns IA, copy, and materials — Archive wing may remain, but primary CTA language is shed craft |
| Combine panel / prototype labels still read as panels | Diegetic **nest / spindle / stamp** language for carry + combine + weave |
| A11y lives as Settings checkboxes with engine chrome | Same **behavior contracts**; restyled as **Tool Chest** folio leaves |
| EL punch-card / habit ribbon temptation | **Banned as Weaver identity** — Thread budget + carry nest replace maze buffer |

**Still test:** mute audio; crop brand wordmark. A stranger must say *“workshop job book”* — not *“Godot menu”*, not *“Field Ledger survey”*, not *“purple void idle.”*

**Brand test:** remove nav labels from the title frame → still obviously **The Weaver** ([`../09_VISUAL.md`](../09_VISUAL.md) §4 · adversarial C4).

## 1. Hard rules (non-negotiable)

### 1.1 Diegesis

1. **No glass.** No translucent panels, blur, drop shadows stacks, or frosted overlays.
2. **No Godot chrome in the final look.** Default `Button` fills, `OptionButton` popups, `CheckButton` toggles, `HSlider` grooves, `PopupMenu`, `AcceptDialog`, and `TabContainer` skins are forbidden on-screen. Nodes may host logic; they must be fully restyled or replaced by Yard Folio components (§6).
3. **Paper / cloth substrate always visible.** Edge-to-edge shed page or Yard floor wash behind every shell — not an inset modal floating on void.
4. **One leaf per job.** One folio page (or one open spread) owns the interaction. Split with a paper turn rather than stacking panels.
5. **Type is the control.** Primary actions are underlined type or stamped tags (focus = kiln-copper / rust rule; hover = slate/ink rule). Never a filled neon pill CTA.
6. **Numbers stamp.** Discrete ink / brass stamps — not rolling odometers, not XP bars.
7. **Transitions are paper turns / tag flips.** No cross-fade through black. No 1-frame black-on-black.
8. **Kiln copper ≤10% of frame; warn flash ≤1%.** UI never uses cadmium/purple fills for focus.
9. **Icons are etched craft glyphs.** Single-weight, single-color. No emoji, no multi-color loot icons, no neon.

### 1.2 Brand / composition (shells)

- Brand-first on title: **THE WEAVER** is hero-level, not an eyebrow.
- First viewport: brand · one craft line · one CTA group · one dominant Yard/loom visual plane ([`../25_VOID_ART_V2.md`](../25_VOID_ART_V2.md) §8).
- **Not in hero:** job lists as dashboard, streak strips, rarity showcases, EL maze film plates, stat strips, address blocks.
- Cards: only as the **interaction container** (index card / tag). Prefer hairline ink rule + slight paper lift; corner radius ≤ 2 px. Never cards in the hero plane.
- Secondary shells carry a small **YARD FOLIO · {LEAF}** mono mark in the top margin so they remain on-world documents.

### 1.3 Ban list (UI-specific)

| Banned | Why |
|---|---|
| Hex HUD frames, sci-fi brackets, progress rings, XP bars | Wrong shelf |
| Modal dim that reads as game-pause blur | Use paper wash / desaturate one step; keep world legible |
| Purple / neon / glow / bloom on any control | Anti-AI-slop + Fragment ban |
| Rounded-full pills, multi-layer shadows, glassmorphism | Template UI |
| Echo Lattice punch-card buffer / habit MIR ribbon as Weaver chrome | Separate SKU mash |
| Searchable recipe wiki / full adjacency matrix | Discovery ban ([`../22_DISCOVERY_UX.md`](../22_DISCOVERY_UX.md)) |
| Floating tip carousels / badge clusters | Pedagogy budget: ≤1 diegetic caption per loop beat |
| Inter / Roboto / Arial as identity | Workshop faces only (art bible type roles) |
| Versus / Invade / lobby stubs | MP fence ([`../29_MULTIPLAYER_V2.md`](../29_MULTIPLAYER_V2.md)) |

## 7. Accessibility (behavior lock + diegetic skin)

### 7.1 Principle

Accessibility is **first-class product craft**, not an afterthought panel. Players must be able to finish Yard jobs when:

- they cannot rely on hue alone,
- flash / motion would harm them,
- they need larger type or remapped keys,
- they play on Steam Deck at 1280×800.

**Fiction rule:** every a11y control lives in the Tool Chest as a stamped instrument. **Behavior rule:** preserve the contracts already shipping in Lattice’s `AccessibilityService` / `ActionRemap` / `SettingsStore` ([`ACCESSIBILITY.md`](../../RELEASE/ACCESSIBILITY.md)) while the hybrid host remains.

### 7.2 Feature matrix (Weaver voice)

| Feature | Tool Chest control | Runtime expectation | Manual verify |
|---|---|---|---|
| **Color reading** | Eye → Color reading + Pattern cues | Ports, Thread stress, void edge, warn never hue-only | Protanopia + patterns: Brace vs Feed vs warn distinct |
| **Reduce flash** | Eye → Reduce flash | Illegal snap / seat flash capped; no full-screen strobe | Toggle on; force illegal bind — no white frame flood |
| **Reduce motion** | Eye → Reduce motion | PaperTurn → instant cut (still no black); kill ambient dust sway; numeral stamps skip | Toggle on; open Tool Chest — no slot tween |
| **Screen shake** | Eye → Shake + intensity | Default off / subtle; forced off under reduce motion | Confirm weave seat does not shake when off |
| **Coach chalk (subs)** | Eye → Coach chalk + size + plate | All critical audio tells also print chalk (`tr("chalk.*")` / existing `subtitle.*` keys OK during hybrid) | Large size readable at 1280×800 |
| **Type / UI scale** | Eye → Type scale 0.85–1.5 | `Window.content_scale_factor`; nest + budget remain on-screen | 1.25 on Deck-like window |
| **Remap** | Hands → Rebind | Keyboard remap; **gamepad events preserved**; footer glyphs follow | Rebind Weave; footer shows new glyph; pad still weaves |
