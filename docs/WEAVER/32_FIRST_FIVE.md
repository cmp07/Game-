## 1. Thesis

> In five minutes the player **recovers two Fragments, braces one Thread, tensions a Structure that opens a gap, walks it, and sees the field answer once.**

| Arc | Clock | Feeling |
|---|---|---|
| Place + job | 0:00–0:40 | Shed Yard corner → one gap that needs a span |
| Recover | 0:40–1:40 | Two Fragments in hand (Anchor + Span) — stuff, not icons |
| Bind | 1:40–2:40 | One Brace Thread; slack fail then taut success |
| Tension | 2:40–3:40 | Commit → stand **or** readable collapse → ≤20s undo |
| Inhabit | 3:40–4:30 | Walk / use the Structure to clear the gap |
| Residue close | 4:30–5:00 | One field answer + one next-hook line — stop |

**Hard gates (prototype fails if any miss)**

- Trailer verb (Fragment → Thread → stand) visible by **≤1:30** wall-clock from interactive start for a guided clip; cold solo may trail to **≤2:00**.
- First **useful Structure** standing by **≤3:40**.
- Field clear (goal true while Structure stands) by **≤4:30**.
- Zero UI catalogs, rarity, multiplayer, economy, Legacy gallery, or Echo Lattice chambers.
- One coach line max in the whole five minutes — prefer silence + material comedy.

## 2. Prototype content fence (do not enlarge)

| Allowed | Cap |
|---|---|
| Place | **One** Yard corner field — “East Post Gap” (or rename; keep the job) |
| Fragments | **Anchor** + **Span** only ([`03_FRAGMENTS.md`](03_FRAGMENTS.md)) |
| Thread type | **Brace** only ([`04_THREADS.md`](04_THREADS.md)) |
| Structure | **One** recipe: short brace-span that rewrites walkable topology |
| Thread budget | ≤3 draws (teach with 1–2) |
| Camera | Fixed-ish craft view; hold 2s on lock |
| Audio | Tension climb + one stand bite + one residue cue ([`10_AUDIO.md`](10_AUDIO.md) when present) |

**Banned in first five:** Filter/Charge/Pendulum, Feed/Oppose/Echo Threads, job board, second Structure, purple glow, tip stacks, shop CTA, login.

**Motion budget (≥3):** (1) Fragment settle with weight, (2) Thread tension climb (see + hear), (3) Structure lock — joints bite, dust, camera hold. Optional fourth: footfalls across the new span.

## 3. Second-tight spine

### 0:00–0:40 · Survey (place reads the job)

| t | Beat | Pass if |
|---|---|---|
| 0:00–0:15 | Atmosphere: loom-shed light, fiber dust. Brand readable without dashboard. | Mute still ≠ purple void |
| 0:15–0:25 | One CTA into the field (**Begin**). No headline essay. | Single click/button |
| 0:25–0:40 | Player faces a **gap** + two loose Fragments in the dust + two pin posts. Goal is spatial: cross / close the gap. | Scarcity readable with HUD off |

**Exit:** Player can point at the gap and the stuff that will fix it.

### 0:40–1:40 · Recover (material literacy — compressed)

| t | Beat | Pass if |
|---|---|---|
| 0:40–1:00 | Pick **Anchor** (stake/weight). Hand/bin shows mass. | Not a rarity gem |
| 1:00–1:20 | Pick **Span** (plank/cloth strip). Length readable. | Distinct silhouette from Anchor |
| 1:20–1:40 | Seat both near the posts (or auto-seat on carry-to-slot). Ports faintly marked. | Ports findable without a wiki |

**Exit:** Two Fragments seated; player has not yet drawn a Thread.

### 1:40–2:40 · Bind (line literacy — compressed)

| t | Beat | Pass if |
|---|---|---|
| 1:40–2:00 | Draw first Brace: Anchor ↔ Span (or Span ↔ post ground). | Illegal snap is craft-tell, not toast |
| 2:00–2:15 | **Slack demo (forced once):** leave line loose — Structure will not stand / gap stays closed. Comedy, not punish. | Slack reads without words |
| 2:15–2:40 | Re-pin / tension the line until it sings taut. Cut once allowed. | Player edits without fail-state shame |

**Exit:** One legal Brace under load-ready tautness.

### 2:40–3:40 · Tension (authorship ceremony — compressed)

| t | Beat | Pass if |
|---|---|---|
| 2:40–3:00 | Commit Tension. Solver checks load. | Deterministic for seed |
| 3:00–3:20 | **Path A — Stand:** joints bite, dust falls, camera holds 2s. Walkable edge appears. | Clip-worthy lock |
| 3:00–3:20 | **Path B — Collapse:** culprit highlight; undo Tension ≤20s; retry once inside this window. | Player names *why* it fell |
| 3:20–3:40 | Name plate / chalk mark optional; **do not** open a menu. Structure must already be useful. | Useful = gap now crossable |

**Hard gate:** Standing useful Structure by **3:40** or prototype pedagogy is broken.

### 3:40–4:30 · Inhabit

| t | Beat | Pass if |
|---|---|---|
| 3:40–4:10 | Walk the span / use the Structure to satisfy the field goal. | Goal ≠ kill-count |
| 4:10–4:30 | Brief settle on the far side. No loot rain. | Pride > reward pop |

**Exit:** Goal true while Structure stands.

### 4:30–5:00 · Residue close

| t | Beat | Pass if |
|---|---|---|
| 4:30–4:45 | **One** world answer: wind shift, dust path, post shadow, or distant loom knock. | Single readable cue |
| 4:45–5:00 | Auto-save tell + one desire line (“The north pin still leans.”). Stop. No shop, no skill tree, no Next Fest dump. | Session feels finished |

## 4. Cold-player vs guided-clip clocks

| Surface | Use | Timing law |
|---|---|---|
| **Guided clip / internal trailer** | Prove juice for ROADMAP G2 / W1 exit | Fragment→Thread→stand by **≤1:30**; full clear optional |
| **Cold solo playtest** | Pedagogy truth | Full spine ≤5:00; Structure ≤3:40; clear ≤4:30 |
| **Wishlist demo** | Do **not** ship this compression as the demo | Expand to [`16_FIRST_THIRTY.md`](16_FIRST_THIRTY.md) |

If cold players miss Structure by 3:40, **cut content** (coach, second Fragment flourish, camera toys) — do not add tutorial slides.

---

## 5. Pedagogy rules (five-minute edition)

| Do | Don’t |
|---|---|
| One job: brace a gap | Teach Feed, economy, or Legacy |
| Fail with slack / snap comedy | Soft-lock, invisible port rules |
| Hold camera on first stand | Smash-cut to meta UI |
| Keyboard/mouse **and** gamepad draw parity | Mouse-only precision gate |
| One coach line max if stuck at 2:20 | Tip spam, badge clusters, lore crawl |

**Stuck recovery (single):** At 2:20 with no Thread, highlight the two ports + one line: “Brace the span to the stake.” Never a multi-page tutorial.

---

## 6. Acceptance checks (playtest — five minutes)

A cold player should answer **yes** to all:

1. Did I make a span that worked?
2. Did I feel slack vs taut before I knew the words?
3. Would I show someone the stand (or the fair collapse)?
4. Can I say the next hook in one sentence?

If any answer is no, the prototype is not done — cut systems, do not add slides.

**W1 ROADMAP exit map:** This script is the timed skeleton for “one field: recover → bind → tension → inhabit” in [`ROADMAP.md`](ROADMAP.md) §W1. Clip of Tension seat still must pass mute identity (no purple-void).
