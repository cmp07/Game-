## 0. One sentence

A **Structure** is a tensed Fragment–Thread graph that has **stood** — it rewrites the field so you must inhabit what you authored.

```
Structure = seated(Fragments + Threads) → local law / topology change
```

Yarn in hand is not a Structure. Chalk plans are not Structures. Only a passed Tension is.

---

## 1. Fantasy

| Layer | Promise |
|---|---|
| **Identity** | Structures are *your* cloth panels — bridges, culverts, kilns, gates — not prefab buildings from a menu |
| **Cost** | Standing a Structure spends the graph; you live with its seams |
| **Pride** | Recognition (“that span is mine”) beats loot |
| **Fairness** | Collapse tells the truth; standing Structures are deterministic for the seed |

**Player line:** *“I have to walk the thing I wove.”*

---

## 2. Lifecycle

| State | Meaning | Player verbs |
|---|---|---|
| **Plan** | Loose Fragments + provisional Threads | Recover, bind, undo |
| **Tension** | Commit check | Tension / cancel |
| **Stand** | Structure alive in the field | Inhabit, optional second Structure |
| **Fray** | Damaged by misuse / field fault | Vent (Oppose), reinforce, or abandon |
| **Residue** | After clear — archived silhouette / bias | Museum / next-field seed (docs later) |

No build menu of finished houses. If it didn’t come from your graph, it isn’t a Structure — it’s scenery.

---

## 3. What standing *does* (rewrite channels)

A Structure may rewrite the field through **one primary channel** (keep readable):

| Channel | Example Structure | Field change |
|---|---|---|
| **Topology** | Brace-span bridge | Walkable cells / edges appear |
| **Flow** | Channel + Filter run | Liquid / dust / heat path opens or blocks |
| **Load** | Anchor grid | Supports a heavier second Structure |
| **Pulse** | Pendulum gate | Oscillating open/close on a beat (not rewind) |
| **Vent** | Oppose chimney | Safe dump so a Charge may run |

Multi-channel Structures are mastery content — teach **one channel** at a time.

## 4. Archetypes (MVP catalog)

Name by craft, not by RPG role.

| Archetype | Typical graph | Clear fantasy |
|---|---|---|
| **Span** | Anchor–Span–Anchor | Cross the gap you made |
| **Culvert** | Channel chain + Filter | Route a hazard aside; walk the dry path |
| **Kiln** | Charge + Feed + Oppose vent | Spend stored push to crack a seal |
| **Gate** | Pulse + Filter | Cross on the beat you authored |
| **Scaffold** | Anchor brace lattice | Enable a longer Span as Structure #2 |
| **Loom-mark** | Any standing graph kept as residue | Leaves a silhouette the next field can answer |

Cap the MVP catalog. Prefer remixing six Fragment families + four Thread types over adding prefab buildings.

---

## 5. Solver contracts (implementation-facing)

| Check | On Tension | On fail |
|---|---|---|
| Port legality | All Threads match ports + type | Snap highlight |
| Capacity | Σ load ≤ Fragment capacities along brace/feed paths | Culprit Fragment |
| Feed cycles | Illegal unless marked as Pulse loop | Cycle highlight |
| Grounding | Brace graphs that claim span must reach `ground` or equivalent | Floating seam tell |
| Goal relevance (soft) | Warn if Structure cannot interact with goal predicate | Optional coach chalk — never auto-build |

Determinism: same field seed + same graph → same stand / fail. No hidden rolls.

---

## 6. Inhabit rules

| Rule | Spec |
|---|---|
| **Live inside it** | Clear requires using the Structure (walk, release, time a gate) — not merely building it |
| **No combat HP** | Fray comes from systems stress, not enemy DPS |
| **Second Structure** | Allowed when teaching composition; budget Threads accordingly |
| **Demolish** | Rare; prefer vent / re-tension. Full demolish refunds Fragments only if authored |
| **Scenery ≠ Structure** | Pre-placed world props never count as player Structures for residue |

---

## 7. Residue & legacy (hook only)

On field clear, the standing Structure may leave:

1. **Silhouette stamp** — recognition / museum / share still  
2. **Bias tag** — next field favors or counters your archetype (scaffold bias, pulse bias, …)  
3. **Scrap Fragment** — optional S-tier leftover of one family  

Full economy / legacy policy lives in sibling docs (`07_ECONOMY`, `08_LEGACY`). This doc only asserts: **Structures are the unit of authorship worth remembering.**
