## 0. One sentence

Teach Fragment × Thread × Structure **combinations** through a living **hint ecology** — never a spoiler wiki that lists every legal recipe.

```
Field tells → port affinity → collapse culprit → coach chalk → stamp residue
         (never: searchable recipe dump / external wiki as the skill surface)
```

**Player line after a stuck-then-clear:** *“The loom hinted — I still had to stitch it.”*

---

## 1. Why this doc exists

Weaver’s skill surface is **chemistry**: which ports take which Threads, which graphs stand, which Structures clear a job. That skill dies if the product (or community expectation) becomes “open the wiki / catalog and copy the graph.”

| Threat | Product failure |
|---|---|
| **Spoiler wiki as default path** | Authorship dopamine collapses to checklist dopamine |
| **Recipe encyclopedia UI** | Besiege gravity (risk D3) — catalog outruns jobs |
| **Tip-stack pedagogy** | Verb mud (risk D1) + tutorial slides (risk D7) |
| **Zero feedback on illegal / collapse** | Players quit or alt-tab to guides |

This doc locks how the game **teaches combinations in situ** and how hints escalate without spoiling the weave.

---

## 2. Hard bans

| Banned | Why |
|---|---|
| **In-game searchable recipe wiki** (“all Structures / all legal binds”) | Spoils discovery; becomes the real game |
| **Full adjacency matrix UI** (every Fragment×Thread cell filled) | Spreadsheet craft; wrong shelf |
| **Auto-complete graph / ghost build-to-win** | Deletes authorship; okay only as last-resort abandon path (see §7) |
| **Floating badge clusters / tip spam** | Fights first-thirty pedagogy |
| **Purple “discovery aura” / rarity ping on correct combo** | Gameslop signal; wrong tell language |
| **Online-required hint server / account tips** | Offline-first |
| **Community wiki as ship requirement** | External guides may exist; the game must be completable without them |

**Allowed catalog (thin):** earned **recipe stamps** after a first honest clear of that archetype ([`11_PROGRESSION.md`](11_PROGRESSION.md) §3) — silhouette + one job noun, **not** a step-by-step graph dump.

---

## 3. What “discovery” means here

Not Steam shelf discovery ([`15_MARKET.md`](15_MARKET.md)). This is **in-session combination literacy**.

| Layer | Player learns | Must feel |
|---|---|---|
| **Port grammar** | Which edges take Brace / Feed / Oppose / Echo | Illegal snap is information |
| **Graph patterns** | Bridge, culvert, kiln, gate… as *verbs*, not menu IDs | Remix, don’t memorize IDs |
| **Field ecology** | Scarcity + residue bias suggest *what kind* of weave | The place coaches quietly |
| **Elegance** | Fewer smarter Threads beat busy graphs | Stars (if any) reward economy |

Discovery is successful when a cold player invents a valid graph they were never shown as a screenshot — and can explain *why* it stood.

## 4. Combination teaching model

Combinations are taught as **affordances**, not as encyclopedia entries.

### 4.1 Affordance stack (always on)

| Signal | Where it lives | Spoiler level |
|---|---|---|
| **Port glyphs** | On Fragments / cursor | None — grammar only |
| **Affinity warmth** | Hover near a legal port: soft fiber pull / copper tick | Low — “this edge might take a stitch” |
| **Illegal snap** | On bind | Low — names conflict in one glyph flash ([`04_THREADS.md`](04_THREADS.md) §7) |
| **Slack / rust / tear** | On provisional + seated Threads | Low — load literacy |
| **Collapse culprit** | On failed Tension | Medium — highlights ≤2 graph elements |
| **Field scarcity staging** | Authored layout of Fragments + gap | Medium — suggests *channel* (span vs flow vs beat) without naming the recipe |

### 4.2 Pattern introduction (jobs, not wiki pages)

| Teach order | Pattern | How it is introduced |
|---|---|---|
| T0 | Simple Span (Anchor–Span–Anchor) | Field *is* a gap; only brace-legal parts present |
| T1 | Port mismatch | One wrong port available; snap teaches |
| T2 | Overload collapse | Undersized Span; culprit highlight |
| T3 | Scaffold → Span | Two Tension commits; second job needs the first |
| T4 | Feed / Culvert | Hazard path + Channel/Filter only |
| T5 | Oppose vent / Kiln | Charge that bursts without a vent |
| T6 | Echo / Gate | Pulse beat without chronomancy framing |
| T7 | Residue bias | Next field favors or counters last stamp |

**Rule:** a new Thread type or Fragment family appears only when the field’s scarcity *requires* it — never as a catalog unlock toast with twelve greyed recipes.

### 4.3 Remix over list

Content authors may keep an internal chemistry cheatsheet ([`04_THREADS.md`](04_THREADS.md) §5). Players get:

- Jobs that force one new relation  
- Optional sandbox after literacy ([`11_PROGRESSION.md`](11_PROGRESSION.md) §7)  
- Earned stamps: **name + silhouette + primary channel** (Topology / Flow / Load / Pulse / Vent)

Stamps never include a numbered “how to build” unless the player explicitly opens **Coach** at max tier (§5).

## 5. Hint ecology

Hints are a **layered ecosystem**, not a single tip button. Each layer has a budget, a diegetic voice, and a spoiler ceiling.

### 5.1 Ecology diagram

```
                    ┌─────────────────────────┐
                    │   FIELD ECOLOGY (always) │
                    │  scarcity · ports · tells │
                    └────────────┬────────────┘
                                 │ still stuck
                                 v
                    ┌─────────────────────────┐
                    │  MATERIAL COACH (soft)   │
                    │  one chalk line / glow   │
                    └────────────┬────────────┘
                                 │ still stuck
                                 v
                    ┌─────────────────────────┐
                    │  PATTERN WHISPER         │
                    │  archetype noun only     │
                    └────────────┬────────────┘
                                 │ still stuck / asked
                                 v
                    ┌─────────────────────────┐
                    │  STRUCTURE COACH (opt-in)│
                    │  partial graph ghost     │
                    └────────────┬────────────┘
                                 │ abandon only
                                 v
                    ┌─────────────────────────┐
                    │  SAFETY NET              │
                    │  exit job · keep scrap   │
                    └─────────────────────────┘
```

### 5.2 Layers (spec)

| Tier | Name | Trigger | What it may say / show | What it must not |
|---|---|---|---|---|
| **E0** | Field ecology | Always | Port glyphs, affinity warmth, scarcity staging, residue bias silhouettes | Recipe name before first encounter |
| **E1** | Material coach | Idle / fail thresholds (see §5.3) | One diegetic chalk line: highlight a hungry port, a slack Thread, or a Fragment still on the ground | “Bind A to B”; multi-step lists |
| **E2** | Pattern whisper | After E1 spent + another fail, or player opens Coach | Archetype noun + channel (“needs a **span**” / “vent the charge”) | Full part list; Thread sequence |
| **E3** | Structure coach | Explicit Coach confirm (opt-in) | Ghost **partial** graph: ≤50% of nodes/edges, or first seam only | Complete solution ghost; auto-Tension |
| **E4** | Safety net | Player abandons / softlock fence | Leave job; refund Fragments; optional scrap; never shame | Force-complete with full spoiler build |

Voice temperature: dry workshop cartographer ([`04_THREADS.md`](04_THREADS.md) §7). One coach line max per beat ([`16_FIRST_THIRTY.md`](16_FIRST_THIRTY.md) §4).

### 5.3 Escalation budgets

| Context | E1 fire when… | E2 fire when… | E3 available when… |
|---|---|---|---|
| **Teaching field (F0–F2)** | 45–60s no progress *or* 2 illegal snaps *or* 1 collapse | E1 shown + 1 more collapse / 90s | After E2; still optional |
| **Standard Yard job** | 90s no progress *or* 3 snaps *or* 2 collapses | E1 + another fail cycle | Player opens Coach (never auto) |
| **Mastery / elegant-star job** | Off by default; player must open Coach | Same | Same; ghosts cost a star tier if stars exist |
| **Sandbox** | Off | Off | Optional “study stamp” from earned recipes only |

**Anti-spam:** after any hint fires, silence ≥20s. Never stack two tiers in the same second. Never re-show the same chalk line until the player changes the graph.

### 5.4 Diegetic carriers (prefer these)

| Carrier | Use for |
|---|---|
| Chalk tick on a port | Hungry / mismatched edge |
| Fiber dust drift toward a gap | Topology suggest (span) |
| Damp stain / dust path | Flow suggest (culvert) |
| Heat shimmer / kiln tick | Charge needs vent |
| Pendulum shadow on a gate | Pulse / Echo suggest |
| Residue ghost outline (prior clear) | Bias — “the yard remembers a line like this” |
| Stamp shelf silhouette | Post-clear literacy, not pre-clear spoiler |

Avoid: modal dialogs, encyclopedia side panels, “HINT 3/3” meta chrome in the hero viewport.

### 5.5 Copy bank (examples — not exhaustive)

| Event | Line |
|---|---|
| E1 hungry brace | “That edge wants a holding stitch.” |
| E1 slack | “Loose fiber carries nothing.” |
| E1 unpicked Fragment | “Something on the ground still wants a seat.” |
| E2 span | “The gap asks for a span.” |
| E2 vent | “The charge has nowhere to go.” |
| E2 starve | “Nothing reaches the far port.” |
| E3 open | “Show a first seam?” (confirm) |
| E4 abandon | “Leave the job. The scraps keep.” |

No LOOT / CRIT / COMBO FOUND banners.

## 6. Anti-wiki product stance

| Surface | Policy |
|---|---|
| **In-game Compendium** | Earned stamps only: silhouette, name, channel, first-clear date. Optional “your best graph” ghost from *your* save — not a global solution. |
| **Pause / Help** | Verb grammar (Recover → Bind → Tension → Inhabit) + port legend. Zero recipe list. |
| **Demo** | Must clear first Structure without any wiki; Coach max E2 unless player opts into E3. |
| **Marketing** | Trailer may show *one* clear pattern; do not publish a public recipe bible before launch. |
| **Post-launch community** | Guides will exist — design so watching a guide is optional mastery, not required literacy. |
| **Share codes / ghosts** ([`12_MULTIPLAYER.md`](12_MULTIPLAYER.md)) | Other players’ Structures are inspiration silhouettes, never forced solution injectors in campaign jobs. |

**Designer test:** if a player can finish the vertical slice *only* by reading an external list of graphs, the hint ecology and field staging failed — fix content, do not ship a bigger wiki.

## 7. Stuck recovery (aligned with first thirty)

From [`16_FIRST_THIRTY.md`](16_FIRST_THIRTY.md): if no Structure by ~20:00 in the opening spine, offer a single coach line + highlight the missing joint.

Extended contract for all Yard jobs:

| State | Response |
|---|---|
| Softlock-possible graph | Forbidden — solver/content tools BFS ([`02_CORE_LOOP.md`](02_CORE_LOOP.md) §5) |
| Player looping same illegal bind | E1 once; then silence until graph changes |
| Repeated collapse same culprit | Culprit stays highlighted; E2 may name the *channel* |
| Wants the answer | E3 opt-in partial ghost only |
| Gives up | E4 abandon — no account punishment, no “hint debt” currency |

Never sell hints. Never gate hints behind premium ([`13_MONETIZATION.md`](13_MONETIZATION.md)).

## 9. Content author checklist

Before a job ships:

1. **Solvable with taught grammar only** — no hidden fifth Thread type.  
2. **Scarcity stages the channel** — gap implies span; flood implies culvert; heat implies vent.  
3. **E1 has a truthful single highlight** if the player stalls.  
4. **E2 noun matches the archetype** without listing parts.  
5. **E3 partial ghost is authored** (not a raw solver dump of the full MST).  
6. **At least one alternate legal graph** so wiki-perfect uniqueness is false.  
7. **Stamp on first clear** unlocks silhouette — not the ghost solution for others.  
8. **Zero purple discovery VFX**; materials per [`09_VISUAL.md`](09_VISUAL.md).

## 10. Acceptance tests

| Gate | Pass |
|---|---|
| **Wiki independence** | Cold playtest clears F0–F3 with network disabled and Help closed |
| **Hint ladder** | Stuck player receives E1 before E2; E3 never auto-fires on standard jobs |
| **Spoiler ceiling** | E2 never names both Fragment kinds *and* Thread sequence |
| **Partial ghost** | E3 reveals ≤50% of the intended graph; player must finish the stitch |
| **Alternate clear** | Two distinct legal graphs clear the same standard job |
| **Stamp thinness** | Compendium entry has no step list until/unless player opens study on *their* clear |
| **Speech test** | After collapse, player can say what failed without opening Help |
| **Purity test** | Removing “wiki / guide / look up” from the player’s vocabulary still leaves a completable toy |
| **Anti-Besiege** | Recipe stamp count never exceeds job count in the current milestone ([`18_RISKS.md`](18_RISKS.md) D3) |

## 13. Lock line
