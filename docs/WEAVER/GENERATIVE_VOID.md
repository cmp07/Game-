## 0. Decision (read this first)

| Lock | Meaning |
|---|---|
| **Start in void** | Boot lands in **true black**. No yard, no shelf, no tutorial room, no prefab biome. |
| **One spark** | The only given is a single **Spark** — a live seed the player can approach, touch, name, or ignore. Everything else is earned by intent. |
| **Evolve from nothing** | Worlds are **grown**, not loaded. Content appears as consequence of what the player does with what already exists. |
| **Infinite components** | There is **no catalog ceiling**. New atoms, relations, and place-laws can keep emerging for as long as the session has energy and coherence. |
| **No prescribed steps** | No quest log, no “first gather Anchor,” no East Post Gap script. Pedagogy is **spatial comedy + consequence**, never a checklist. |
| **Generative around the player** | Generation is **local and reactive** — densest near attention, thinner at the frontier — not a pre-baked map the player tours. |
| **Still a game** | Friction, mass, failure, scarcity of attention, and irreversible costs exist. A polite text reply is **not** a win condition. |
| **No shed** | **Shed Yard is out** as session fantasy and hub. Workshop nostalgia, timber staging rooms, and job-board hubs do not open a void session. |

**One line:** You wake in black with one spark; whatever you do next authors a world that only your hands could have made — and the void pushes back.

```
Void → Spark → Intent → Component → Combine / Place → Consequence → denser world → repeat
```

## 1. Session open — black void, one spark

### 1.1 First interactive frame

| t (feel) | What exists | What does **not** exist |
|---|---|---|
| Boot fade | Pure black field; silent or near-silent bed | Menu yard, brand billboard essay, tip stack |
| First frame | **One Spark** — small, legible, alive (pulse / heat / grain) | Fragment shelf, Thread chalk board, Structure recipes |
| First second | Player embodiment (cursor / body / gaze) can move | HUD catalogs, rarity chrome, chat transcript pane |
| First act | Any verb aimed at the Spark **counts** | Forced “press E to begin tutorial” corridor |

**Still test:** Crop UI. A stranger sees **nothing but black and a spark**. If they see a shed, a desk, or a craft lobby, this lock has failed.

### 1.2 What the Spark is

| Property | Law |
|---|---|
| **Role** | Seed of possibility — the first **Component** and the first **invitation** |
| **Not** | An NPC guide, a chatbot avatar, a lore dump, or a collectible gem |
| **Affordances** | Can be approached, circled, touched, typed-at, spoken-toward, split, fed, bound, or left alone |
| **Reply** | Answers with **physics and place**, not paragraphs. Heat, light radius, grain, a second mote, a pull, a refuse |
| **Persistence** | The Spark’s history (how you treated it) biases what can emerge next |

Leaving the Spark alone is legal. The void stays empty. Boredom is the player’s; the game does not invent a shed to rescue them.

### 1.3 Brand without lobby

Brand may exist as **wordmark / tone / material of the Spark** — never as a dashboard hub. If removing the Spark leaves a place that could be any other game’s lobby, branding is wrong.

## 2. Player intent — the only content pipe

Intent is any **committed act** the toy can sense. The world grows by answering intent with **components and laws**, not with quest stages.

### 2.1 Intent channels (open set)

| Channel | Examples | Generative reply shape |
|---|---|---|
| **Move** | Walk, orbit, push, flee, linger | Paths wear; density follows attention; frontiers cool |
| **Type** | Name, label, short command, glyph | Names stick to matter; labels become handles; bad names cost clarity |
| **Speak** | Voice / emote / call into the dark | Rhythm and volume bias pulse, flock, echo — not dialogue trees |
| **Touch** | Grab, stretch, strike, cradle | Mass and stress teach; breakage is data |
| **Combine** | Join, braid, oppose, nest whatever exists | New Components appear only from legal contact + energy |
| **Attend** | Gaze / aim / hold focus | Generation prefers the cone of attention; periphery stays thin |

Channels are **not** skill trees. Unlocking is literacy: the player learns what the void will tolerate.

### 2.2 No prescribed steps

| Allowed | Banned |
|---|---|
| Soft scarcity tells (Spark dims if starved of attention) | Numbered objectives / quest markers |
| Consequence pedagogy (“that braid collapsed”) | Coach scripts that force Anchor → Span → Brace |
| Optional mute glyphs born from prior acts | Tip stacks, wiki overlays, recipe stamps as gate |
| Player-authored goals (“I want a bridge”) | Designer-authored job board / East Post Gap ladder |

If a designer can write the first five minutes as a fixed beat script that every seed must follow, **stop** — that is shed pedagogy wearing a void costume.

### 2.3 Unique world per session

| Lever | Effect |
|---|---|
| **Seed + intent history** | Same binary, different hands → different Component graphs |
| **Local generation** | New matter spawns near acts, not as remote map reveals |
| **Irreversible scars** | Collapses, burns, renames, and breaks leave residue the next act must live with |
| **No shared prefab hub** | There is no Yard everyone returns to that resets fantasy |

Recognition pride: *“this place only exists because of how I moved and named.”*

## 3. Infinite component creation

### 3.1 Component (working term)

A **Component** is any durable atom the void will keep: mote, fiber, mass, rule-shard, named glyph, seated machine, weather cell. It replaces the closed Fragment catalog as the **growth unit**.

| Law | Meaning |
|---|---|
| **Born from intent + prior matter** | Nothing useful appears from a menu; things appear from contact |
| **Ports / affordances emerge** | How it can combine is discovered in play, not from a six-family enum |
| **Infinite in principle** | Session length and coherence are the ceilings — not a stamped roster of twenty recipes |
| **Finite in attention** | Hands, focus, and local energy stay scarce so infinity does not become sludge |

### 3.2 Combine whatever exists

Combination is the core craft verb:

1. **Select** two or more Components (or a Component and raw void-energy from the Spark line).  
2. **Commit** a relation (bind, feed, oppose, nest, name-fuse, …).  
3. **Judge** — physics / conservation / stress accepts, mutates, or refuses.  
4. **Seat or spill** — success densifies place; failure teaches with comedy and cost.

There is **no** “only these families may touch.” Legality is **situational**: temperature, tautness, name conflict, load, distance from Spark lineage.

### 3.3 Growth without catalog theater

| Elevate | Thin (reject) |
|---|---|
| Emergence that surprises *and* can be re-used | Rarity gacha drops from the void |
| Player-named Components that stick | Procedural synonym spam with no mass |
| Graphs that rewrite walkable / usable law | Chat proposing “you could build a house next” |
| Infinity as depth of remix | Infinity as autofill wallpaper |

## 4. Generative around the player

### 4.1 Attention as the camera of creation

Generation is **player-centric**:

| Zone | Behavior |
|---|---|
| **Focus core** | Highest birth rate; fine detail; readable stress |
| **Near field** | Echoes and supports; secondary Components |
| **Horizon** | Thin suggestion — silhouette, hum, cool grain — not a second biome waiting off-map |
| **Behind** | May cool, forget, or fossilize if abandoned too long |

The world is not a tourist map. It is a **pressure bubble** around will.

### 4.2 What “generative” means here

| Means | Does not mean |
|---|---|
| Rules + seed + intent → novel stable states | LLM narrator as gameplay |
| Local simulation with readable conservation | Invisible DM inventing quests |
| Components that keep existing when you look away | Dream fog that deletes the toy when unobserved |
| Surprise bounded by physics tells | Random purple cosmogenesis |

### 4.3 Anti-empty / anti-sludge pair

Borrowed from adversarial pressure ([`34_ADVERSARIAL.md`](34_ADVERSARIAL.md)) and inverted for void start:

| Death mode | Void-specific kill |
|---|---|
| **Empty void** | Spark with no affordance; black forever; “mystery” without mass |
| **Sludge void** | Infinite spawn with no stress; wallpaper Components; no refusal |
| **Chat void** | Typed intent answered as prose companion instead of place-change |

**Mandatory:** every generative burst must leave **mass, constraint, or scar** the next intent can use or fight.

## 5. Anti-chatbot — still a GAME

This lock exists so generative ambition cannot collapse into a talking void.

### 5.1 Hard ban — chatbot gravity

| Banned | Why |
|---|---|
| Win-by-conversation | Clever prompts must not replace play |
| Soft DM that invents goals in prose | Reintroduces prescribed steps through the side door |
| Unlimited undo via apology | Removes consequence |
| Omnipotent spawn on request (“give me a sword”) | Deletes friction and combine literacy |
| Personality NPC as the Spark | Turns the seed into a companion app |
| Transcript-first UI | Signals chat product, not toy |

### 5.2 Game laws that must survive generation

| Law | Player-facing tell |
|---|---|
| **Friction** | Moves have inertia; binds take stretch; names can misfit |
| **Physics / conservation** | Mass, heat, tension, charge — something is kept, spent, or transformed |
| **Failure** | Collapse, burn, mute, scatter — readable, retryable, sometimes irreversible |
| **Consequence** | Scars bias the next birth; you inhabit what you authored |
| **Skill** | Better hands get denser, kinder, stranger worlds — not better essays |
| **Risk** | Reaching farther from the Spark lineage costs stability |

**Recognition line the player should earn:** *“I built this — and it almost killed the spark.”*  
Not: *“The void and I had a great chat.”*

### 5.3 Where language is allowed

Type and speak are **verbs that touch matter**, not a help desk.

| Allowed language use | Forbidden language use |
|---|---|
| Naming a Component so it becomes addressable | Asking for a walkthrough |
| Short glyphs that bias fusion (“hot”, “brace”, “split”) | Open-ended lore Q&A |
| Calling rhythm into a pulse field | NPC therapy / quest giver banter |
| Labels that can be wrong and cause stress | Autocomplete that plays the game for you |

If text ever becomes the highest-bandwidth way to progress, strip bandwidth from text until hands win again.

## 6. No shed (explicit reject)

Prior corpus often centers a **Shed Yard** hub ([`06_WORLD.md`](06_WORLD.md), [`MASTER_GDD.md`](MASTER_GDD.md), 1000× vision). **This lock supersedes that hub for generative-void sessions.**

| Shed fantasy (out) | Void fantasy (in) |
|---|---|
| Timber lobby, fragment shelf, gallery wall | Black field, one Spark |
| Job board / authored East Post Gap | Player-authored scarcity from intent |
| Workshop lamp as default sky | Light born from Spark lineage and seated Components |
| Return-to-Yard cadence | Stay-in-world growth; exit is sleep/save, not lobby |
| Craft nostalgia as first read | Absence as first read |

**Still allowed as optional later skins:** material warmth (fiber, chalk, rust) *after* matter exists — never as the opening set dressing. Warmth is earned residue, not a prefab shed.

**Agent rule:** Do not “help” a void prototype by adding a shed staging room, yard CTA, or job board “so players aren’t lost.” Lost-in-void with a Spark is the fantasy; rescue-by-lobby is identity suicide.
