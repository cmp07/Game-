## 0. One sentence

The world is a **Yard of authored fields** — frayed work-sites the loom presents one at a time — not an open-world biome tour and not a living MMO sim.

```
Hub (Shed Yard) → pick a field / job → weave Structures → leave residue → return / next field
```

If a place does not host Survey → Recover → Bind → Tension → Inhabit → Residue, it is scenery, not World content.

## 1. Fantasy of place

| Layer | Promise |
|---|---|
| **Material** | Dust, fiber, timber, wire, chalk, rust — a worked yard, not a purple void |
| **Scale** | Human hands and short spans; you author local law, not continents |
| **Memory** | Fields remember *your* seams as residue bias — never as other players’ stalls |
| **Honesty** | Every hazard is a systems problem (gap, load, flow, beat), not an enemy camp |

**Player line:** *“This yard answers the way I stitch.”*

## 2. Topology (MVP → 1.0)

### 2.1 Shed Yard (hub)

One hub for the vertical slice and MVP 1.0.

| Element | Role |
|---|---|
| **Shed** | Quiet staging — Fragment shelf (tiny), Thread chalk, recipe stamps you have earned |
| **Yard floor** | Job board / field gate — pick the next authored contract |
| **Gallery wall** | Local Legacy silhouettes ([`08_LEGACY.md`](08_LEGACY.md)) — recognition, not social feed |
| **Optional second corner (1.0)** | One extra teach zone (e.g. wind / wet corner) — not a second biome pack |

The hub is a **menu made of place**. It must pass the brand test without HUD chrome: fiber, dust, hardware.

### 2.2 Fields (play spaces)

A **field** is one solvable scarcity with a clear goal predicate.

| Field property | Spec |
|---|---|
| **Seed** | Deterministic; same seed → same fray, anchors, Fragment spawns |
| **Scarcity** | Missing law / broken load path / starved basin / sealed gate |
| **Fragment pool** | Authored subset of families (see [`03_FRAGMENTS.md`](03_FRAGMENTS.md)) |
| **Thread budget** | Soft cap (teach ~4 / mastery ~8) |
| **Structure slots** | Usually 1 stand; composition fields allow 2 |
| **Clear** | Goal true while required Structure(s) stand and are *inhabited* |
| **Residue out** | Silhouette + optional bias tag + optional scrap ([`08_LEGACY.md`](08_LEGACY.md)) |

Fields are **panels of cloth**, not open-world chunks. Travel fantasy is “return to Yard → next job,” not tourism.

### 2.3 Job board (world answer)

MVP world content is **authored contracts**, not emergent town sim.

| Milestone | Fields / jobs |
|---|---|
| Vertical slice | 8–12 jobs on one Yard |
| MVP 1.0 | 40–60 jobs; still one hub (+ optional corner) |
| Post-MVP | Second biome **or** async ghosts — pick one ([`17_MVP.md`](17_MVP.md)) |

Each job names: teach focus, Fragment families allowed, Thread budget, Structure archetype target, clear predicate, residue policy.

## 3. Field archetypes (place grammar)

Name by the scarcity the player must weave against — not by RPG biome.

| Archetype | Scarcity | Typical Structure answer |
|---|---|---|
| **Gap** | Missing walkable span | Span / Scaffold→Span |
| **Spill** | Flow floods the path | Culvert / Filter chain |
| **Seal** | Block that needs spent push | Kiln + vent |
| **Beat** | Crossing only on a rhythm you author | Gate (Pulse + Filter) |
| **Overload** | Existing props cannot take load | Anchor grid, then Span |
| **Starve** | Source never reaches sink | Feed chain literacy |
| **Fray remnant** | Prior residue biases the teach | Answer or counter your last hand |

Biomes (wind, wet, kiln-heat) are **material skins on these archetypes**, not separate open worlds.

---

## 4. How the world answers the player

| Stimulus | World response |
|---|---|
| Standing Structure | Topology / flow / load / pulse / vent rewrite (one primary channel) |
| Collapse | Culprit highlight; field props stay; Fragments refund per loop rules |
| Clear | Stamp + residue; job board marks contract done |
| Residue bias | Next field favors or counters your archetype (scaffold-heavy, pulse-heavy, …) |
| Abandon | No shame economy; optional keep chalk plan locally |

**Hard rule:** the world answers *your graph*, not a hidden reputation spreadsheet and not other humans’ inventories.

## 5. Scale fences (anti-creep)

| In (World) | Out (wrong game) |
|---|---|
| One Shed Yard hub | Open-world biome tourism |
| Authored job list | Living town economy / NPC schedules |
| Short fields (3–8 min teach) | Seamless continent streaming |
| Local gallery wall | Player housing districts |
| Deterministic seeds | Always-online shared instance |
| Material weather as tell (dust, damp) | Survival hunger / day-night tax |

If a proposal needs a map the size of a survival craft title, it fails this doc.

## 6. Presentation contract

| Surface | Feel |
|---|---|
| Yard enter | Quiet dust; tools at rest; job chalk readable at a glance |
| Field enter | Fray visible without a quest log novel |
| Structure stand | Place visibly rewrites — walkable seam, dry path, open gate |
| Return to Yard | Gallery gains a silhouette; board ticks one contract |

Materials language stays textile–hardware hybrid. **No** purple void skyboxes, **no** mystery-AI “memory realms,” **no** combat arena kits.

## 8. Acceptance tests

| Gate | Pass |
|---|---|
| **Hub test** | Greyscale Yard still reads as a craft shed, not a town MMO |
| **Job test** | Player can name the scarcity of a field in one sentence before recovering |

## 10. Lock line

Weaver’s world is a **Shed Yard of authored fields** — short, fair, material — where Structures rewrite place and residue teaches the next panel. Tourism and trade plazas are someone else’s game.
