## 0. One sentence

Weaver’s economy is **solo-satisfying scarcity**: ports, Thread spans, Tension commits, and residue marks that make *your* weave feel precious — not other players’ inventories, not stalls, not fees.

```
V1 instinct:  scarcity → invent trade to “fix” loneliness
V2 lock:      scarcity → author cleverness → inhabit pride   (trade never enters)
```

## 1. Verdict (read this first)

| Field | Lock |
|---|---|
| **Product fantasy** | Solo craft authorship under honest caps |
| **Trade** | **Out** at MVP, 1.0, and default post-1.0 — not a deferred pillar |
| **What scarcity is for** | Force elegant graphs, readable collapse, and “I had to live in it” |

**One line:** If removing every other human from the universe empties the economy, the design failed — Weaver’s economy must sing in airplane mode.

## 2. Why V2 (replace the trade fantasy)

[`07_ECONOMY.md`](07_ECONOMY.md) correctly **banned** player trade. V2 goes further: stop treating “no trade” as the interesting sentence.

| V1 gravity (wrong center) | V2 gravity (correct center) |
|---|---|
| Long critique of auction houses | Short fence + long **solo feel** design |
| “How do we prevent RMT?” | “How does a tight Thread budget feel *good* alone?” |
| Social substitutes (share codes) as apology | Social residue is optional dessert — scarcity already pays out |
| Scarcity justified by anti-trade rhetoric | Scarcity justified by **authorship tension** |

Player-trade fantasy relocates dopamine from **“I wove that”** to **“I acquired that.”** Solo-satisfying scarcity keeps dopamine on the stitch.

## 3. Solo satisfaction model

Scarcity must produce **four feelings** in a single-player session. If a cap only produces frustration or FOMO, retune the field — do not invent coin or trade.

| Feeling | Player read | Design lever |
|---|---|---|
| **Preciousness** | “This Fragment seat matters.” | Carry slots 3–5; ports that refuse waste |
| **Cleverness** | “I spent the budget well.” | Thread budget 4–8; illegal snaps refund, elegance stars optional |
| **Commitment** | “I meant that Tension.” | 1–2 commits / field; undo before seat; collapse names the culprit |
| **Memory** | “The yard kept my hand.” | Residue bias + local gallery stamp — never a tradeable asset |

### 3.1 Satisfaction beats (per field)

```
Survey scarcity  →  Recover under carry pressure  →  Bind under span pressure
        →  Tension under commit pressure  →  Inhabit (pride)  →  Residue (memory)
```

Each pressure must have a **readable relief** that is not “buy more”:

| Pressure | Relief (solo-native) |
|---|---|
| Full carry | Seat or abandon loose; field pool refreshes on retry |
| Spent Thread budget | Cut / redraw; refund on illegal snap |
| Failed Tension | Culprit highlight + re-tension; no wallet |
| Ugly clear | Optional elegance retry — never gated content |

### 3.2 Anti-feelings (fail the design)

| Anti-feeling | Tell | Fix |
|---|---|---|
| **Grind debt** | Caps feel like chores between fun | Lower job count; tighten teaching, not pad sinks |
| **Wallet FOMO** | Player asks where the shop is | Remove soft-currency UI; show ports/budget only |
| **Lonely stall** | Yard implies other weavers’ stalls | Authored job board + local gallery only |
| **Import craving** | “I’d clear this if I had *their* Fragment” | Same-seed compare only; no inventory move |

## 4. Loop economy (unchanged spine, V2 voice)

Borrowed from [`02_CORE_LOOP.md`](02_CORE_LOOP.md) §4 — still the **only** economy the vertical slice may ship:

| Resource | Source | Sink | Cap (MVP intuition) | Solo satisfaction |
|---|---|---|---|---|
| **Fragment slots** | Field pool / recover | Seat into Structure; abandon loose | 3–5 carry | Forces triage — authorship under weight |
| **Thread budget** | Field grant | Draw length + count; illegal snaps refund | Teach ~4 / mastery ~8 | Forces elegant graphs |
| **Tension commits** | Field grant | Stand / failed stand (refund on fail) | 1–2 per field | Forces intent; chalk stays cheap |
| **Residue marks** | Clear | Bias next field; gallery stamp | 1 signature ± scrap | Continuity without meta currency |

**No parallel currencies** in MVP: no gems, stamina bars, premium fiber, battle-pass tokens, reputation ledgers, or soft coin that exists to enable trade later.

Stars / ranks (if any) score **Thread elegance** and graph clarity — never a speed tax as the only grade, never a pay wall, never a leaderboard that implies market rank.

## 5. Solo sink catalog (positive design)

Use these sinks. Do **not** invent human-to-human sinks.

| Sink | Solo job | Ship? |
|---|---|---|
| **Port scarcity** | Wrong family won’t bind — teach literacy | **Yes** |
| **Span budget** | Long Brace costs more than short | **Yes** |
| **Collapse risk** | Overload / starve / cycle fails Tension | **Yes** |
| **Carry triage** | Leave a Fragment on the chalk to free a slot | **Yes** |
| **Recipe stamps** | Structure unlocks by clearing teach jobs | **Yes** |
| **Residue bias** | Prior hand changes next field’s tell | **Yes** (light) |
| **Elegance stars** | Optional pride metric after clear | Soft yes |
| Soft coin / fees / stalls / AH / wallets | Trade fantasy | **Never** |
| Energy / login calendars | Live-ops loneliness patch | **Never** |
| Gacha Fragment rarity | Loot ladder | **Never** ([`03_FRAGMENTS.md`](03_FRAGMENTS.md)) |

If designers need a number-go-up sheet to balance a field, the field’s scarcity is wrong — tighten ports and budgets, don’t invent coin.

## 6. Soft material costs (authored, not simulated town)

| Layer | Policy |
|---|---|
| **Job costs** | A field may withhold a Fragment family until a prior job clears — unlock order, not shop price |
| **Recipe stamps** | Structure archetypes unlock by teaching jobs, not by gold sinks |
| **Scrap Fragment** | Optional Legacy leftover ([`08_LEGACY.md`](08_LEGACY.md)) — one family, never a trade good |
| **Sandbox** | Free-build dessert may relax caps; campaign jobs keep them honest |

Sandbox relaxing caps is a **solo reward** (mastery toy), not a surplus farm for export.

## 8. Tuning rubric (solo-satisfying)

Before shipping a field’s caps, score each axis 1–5. **Ship only if every axis ≥3** and at least two axes ≥4.

| Axis | 1 (fail) | 5 (sing) |
|---|---|---|
| **Readable pressure** | Caps hidden until fail | Player can name the scarce thing on Survey |
| **Fair retry** | Softlock / wallet wall | Undo + refund paths obvious |
| **Cleverness room** | One forced graph | ≥2 elegant solutions under same budget |
| **Inhabit pride** | Clear by checklist UI | Must walk/use the Structure |
| **Offline complete** | Needs friends / shop | Airplane mode clears the job |
| **No import craving** | Wants external Fragments | Field pool is the whole toolbox |

### 8.1 Designer checklist

1. Does it tighten **ports / budget / collapse readability**?  
2. Can a blind 60s clip show authorship **without a wallet UI**?  
3. Does it work **fully offline**?  
4. Would the feature still be fun if **no other player exists**? If no → cut.  
5. Does it create value that would be **more fun to trade than to weave**? If yes → cut.  
6. After clear, does the player feel **clever / proud**, not **relieved the grind ended**?

## 11. Acceptance tests

| Gate | Pass |
|---|---|
| **Solo song test** | A mastery field is hard because of graph skill, not missing coin or missing friends |
| **Trade absence test** | Grep of MVP scope: no trade window, stall, AH, wallet |
| **Offline test** | Campaign clearable with network killed |
| **Pride test** | Players screenshot Structures, not inventories |

| **Relief test** | Collapse → re-tension feels informative within one retry, not punitive sink |

## 12. Lock line

Weaver is rich when **stitches are scarce and satisfying alone**. Player trade is not a missing feature — it is a competing fantasy. V2 designs the scarcity that makes solitude feel like authorship, not loneliness.
