## 0. Thesis

Weaving is not “crafting vibes.” It is a **sequence of physical micro-events** the player can feel without reading UI:

> Pick something with weight → drag fiber that fights the span → hear load climb → seat a graph that suddenly becomes floor → walk on your own stitch.

If a beat cannot be timed in **tenths of a second** and named as a body sensation, it is not locked yet.

**One-line brief:** _Weight in the palm, scrape across the gap, breath at crease, wood hit at seat, dust after — then your feet own the law._

**Hard ban on this doc’s language:** “satisfying,” “juicy,” “immersive,” “premium feel,” “polish pass,” “game feel TBD.” Name the clock or cut the claim.

---

## 1. Timing base

Assume **60 fps presentation**. Tables below use wall-clock seconds (`t=`) for session beats and **frames (F0…)** for micro-verbs.

| Unit | Duration | Use |
|---|---|---|
| Frame | 16.7 ms | Recover settle, snap flash, foot plant |
| Tenths | 100 ms | Tension stages, stress creep ticks |
| Half-second | 500 ms | Illegal-snap rest, collapse hold |
| Second | 1.0 s | Survey read, inhabit first step on new law |
| Seat phrase | **0.9–1.2 s** total | Crease → lift → seat → settle (sync [`09`](09_VISUAL.md) / [`10`](10_AUDIO.md)) |
| Trailer verb | **60–90 s** | Recover → bind → stand → walk must land inside this window |
| Teach-field clear | **3–8 min** | Full Survey→Residue; not this doc’s micro focus |

**Invariant:** reaction VFX advance on **wall-clock**. If Tension hitstop dips timescale, dust/crease keep moving or the seat reads as lag.

**Reduce-motion:** drop crease/lift staging; keep outcome (seat or tear) readable in ≤3 frames + one audio hit.

## 2. Body map (what the player’s nervous system tracks)

| Channel | Healthy weave signal | Cheap fail (ban) |
|---|---|---|
| **Palm / cursor mass** | Fragment has inertia on pick; Thread drag thickens with span | Weightless icon teleport; rubber-band cursor |
| **Forearm resistance** | Draw pitch + line thickness climb with stress | Constant-thickness neon beam |
| **Thumb commit** | Tension is a deliberate hold/release — not a spam click | Mash-to-win seat |
| **Ear load** | Slack scrape → taut tick → seat downbeat | Choir swell / UI blip fanfare |
| **Foot ownership** | First step on seated Structure changes material underfoot | Same footstep on dirt and span |
| **Eye culprit** | Collapse holds the failing seam ~0.5 s before refund | Red fullscreen flash, no named seam |

## 3. Trailer weave — second-by-second (60–90 s)

Cold silent clip. Clock starts at first interactive frame in the field (not boot brand).

| Clock | Player action | Must feel (body) | Must show / hear | Must not |
|---|---|---|---|---|
| **0.0–2.0** | Enter frayed field; camera settles | Quiet orientation — no timer panic | Torn gap / missing span readable at a glance; shed hush | Objective spam, rarity toast |
| **2.0–5.0** | Eyes find 1–2 Fragments near the gap | Curiosity with weight pending | Material silhouettes (timber strip, peg, copper scrap) | Loot sparkles |
| **5.0–9.0** | Recover first Fragment | **Palm mass** — 120–180 ms settle into hold/bin | Soft unstick SFX; dust mote ≤3 | Inventory panel takeover |
| **9.0–14.0** | Recover second Fragment / place near ports | Second weight confirms “parts, not currency” | Ports visible as body glyphs | DPS / rarity numbers |
| **14.0–18.0** | Aim first Thread; finger down | Decision tension — “where does this stitch go?” | Cursor becomes fiber tip; provisional chalk appears | RTS power-line snap grid |
| **18.0–28.0** | Draw Thread across the gap | **Forearm fight** — scrape rises with span; line fattens | Chalk dashed → semi-taut; pitch climb ≤+4 st | Instant perfect line |
| **28.0–32.0** | Port hover / release bind | Click of honesty — legal or not | Legal: short fiber settle. Illegal: §5 snap | Red error toast essay |
| **32.0–38.0** | Draw second Thread (brace or feed) | Composition thought — graph is becoming a sentence | Two lines readable in greyscale | Crossing spaghetti without stress tell |
| **38.0–42.0** | Thumb commits Tension | Held breath — commit cool-down arms | Input lock ~200 ms; no mash | Instant pop Structure |
| **42.0–43.3** | Crease | Cloth/page gathers at pins — **body lean in** | Multi-fiber rustle; micro silence gaps | Screen bloom warp |
| **43.3–44.0** | Lift | Soft mass inhale — shadow / weight | Air body, not library whoosh | Jump cut to finished mesh |
| **44.0–44.6** | Seat | **Wood/cord downbeat** — loudest honest hit | Structure becomes walkable law; joints bite | Confetti / portal swallow |
| **44.6–45.5** | Settle | Dust fall; pride without brass | Stitch lock ticks; bed returns to hush | XP banner |
| **45.5–55.0** | Inhabit — walk the Structure | **Feet own the stitch** — material footstep change | Goal predicate advances (reach / irrigate / brace) | Combat hitstop kit |
| **55.0–70.0** | Clear or optional collapse→retry demo | Consequence lands | Stamp *or* culprit tear then ≤30 s retry | Shame economy |
| **70.0–90.0** | Hold still / residue tease | “I wove that — and I lived in it.” | Silhouette readable mute; optional next-gap hunger | Shop CTA mid-clip |

**Clip test pass:** mute the video — a stranger still narrates *parts → line → place → walk*.

## 4. Micro-verbs (frame charts)

### 4.1 Recover (pick / unstick)

Intent: Fragment is **stuff**, not a UI chip.

| Frame | Visual | Audio | Input |
|---|---|---|---|
| **F0** | Target Fragment lifts 1–2 px; contact highlight on body (not rarity border) | Soft fiber brush / grit unstick | Consume pick |
| **F1–F4** | Arc toward palm/bin with ease-out; shadow shortens | Mass whoom ≤40 ms (timber) or filament tick (wire) | Cursor carries mass — slight follow lag ≤40 ms |
| **F5–F8** | Seat into hold slot; slot depresses like cloth pocket | Settled tick | Inventory count updates without panel flash |
| **F9+** | Still. No idle bob. No rarity breathe | Silence | Wrong pick: same timing, return path ≤0.4 s — comedy, not punish |

**Fail (weak tug):** F0–F3 stretch → recoil; Fragment stays; teach weight without tip spam.

---

### 4.2 Bind draw (provisional Thread)

Intent: pulling fiber across a page — resistance is the skill surface.

| Clock inside draw | Visual | Audio | Body read |
|---|---|---|---|
| **t=0.00** | Finger down on from-port; chalk mote | Dry chalk kiss | Pin planted |
| **t=0.00–∞** (while dragging) | Dashed slack fiber follows tip; thickness ∝ stress estimate | Continuous scrape; pitch ↑ with span_cost | Forearm load |
| **Port enter (legal)** | To-port glyph brightens once (≤100 ms) | Soft tick −12 dB under scrape | “It will take” |
| **Port enter (illegal)** | Glyph flashes white once | Pre-snap grit | “Wrong mouth” |
| **Release legal** | Line settles to chalk-taut; endpoints pin | Fiber settle 30–50 ms | Bind confirm ([`02`](02_CORE_LOOP.md) §7) |
| **Release illegal** | → §4.3 snap | — | Cheap undo; Thread budget unspent |

**Rules:** last Thread always removable before Tension. Crossing lines may raise stress (rust speck) but do not auto-fail.

---

### 4.3 Illegal snap

Intent: dry break — craft tell, not UI scold. Total phrase **≤0.55 s**.

| Clock | Visual | Audio |
|---|---|---|
| **0–50 ms** | Thread whites out; ports flash conflict glyph once | Short white transient |
| **50–200 ms** | Fiber retracts to from-port; chalk dust ≤4 particles | Rest (designed silence) |
| **200–550 ms** | World quiet; cursor free | Optional tiny refund rustle if a provisional spent |

No buzzer cartoon. No modal. Player should be drawing again before one second passes.

---

### 4.4 Tension seat (signature — healthy stand)

Total authored length **900–1200 ms**. Stages are one sentence with [`09`](09_VISUAL.md) §5 and [`10`](10_AUDIO.md) §4.

| Stage | Clock | Visual | Audio | Input |
|---|---|---|---|---|
| **Arm** | 0–200 ms | Graph dims provisional chalk → ink promise | Bed ducks −3 dB | Commit locked; mash ignored |
| **Crease** | 200–550 ms | Cloth/page gathers at pins; Threads pull taut | Multi-fiber rustle; micro-gaps | — |
| **Lift** | 550–750 ms | Brief cast shadow / Structure rises a hair | Soft mass inhale (air) | Camera hold — no shake spam |
| **Seat** | 750–950 ms | Joints bite; Structure becomes law (walkable / usable) | Wood/cord downbeat — peak | Hitstop OK ≤90 ms @ floor 0.06 |
| **Settle** | 950–1200 ms | Dust fall; ink seams commit; rust clear if healthy | Stitch lock; return to shed hush | Input returns; inhabit unlocked |

Players should clap or hum the seat after three hearings. Trailer and in-game share the same masters.

---

### 4.5 Collapse (readable tear)

Intent: failure is information. Culprit named in one glance.

| Clock | Visual | Audio | Player agency |
|---|---|---|---|
| **0–80 ms** | Culprit Thread/Fragment highlights (rust → gap) | Fiber tear onset | — |
| **80–500 ms** | Hold on culprit; rest of graph greys | Tear → rest | Eyes learn *why* |
| **500–900 ms** | Graph undoes to pre-Tension; Fragments refund to owned set | Refund rustle | Undo path obvious |
| **≤30 s after** | Player adjusts one Thread → re-Tension | Seat or tear again | Retry test ([`02`](02_CORE_LOOP.md) §9) |

No “you died.” No shame stamp. Collapse clips must be shareable comedy.

---

### 4.6 Inhabit (first steps on your law)

| Clock | Feel |
|---|---|
| **0.0–0.3 s** after seat unlock | Cursor/character weight shifts onto Structure material |
| **First foot plant** | Distinct footstep (timber / cloth / wire grate) — louder than yard dirt by ~2–4 dB, shorter transient |
| **0.3–2.0 s** | Route toward goal; Pulse gates tick only if Pulse Fragments present (craft beat, never rewind swoosh) |
| **Goal true** | World answers once ([`16`](16_FIRST_THIRTY.md)) — wind, dust path, light — then stamp path arms |

If footsteps do not change on the Structure, inhabit is a lie — the seat was only a prop.

---

### 4.7 Residue stamp

| Clock | Visual | Audio |
|---|---|---|
| **0–120 ms** | Cloth/paper panel presses into view or Yard wall | Pressed stamp |
| **120–400 ms** | Silhouette of *your* Structure holds | Hungry interval — silence that wants the next gap |
| **400 ms+** | Soft meta: one next-session hook max | No brass fanfare, no battle-pass drip |

## 5. Stress creep (the seconds *before* disaster)

Overload is felt **before** tear — literacy lives here.

| Signal | Timing | Channel |
|---|---|---|
| Rust speck on Thread | Starts when stress ≥ ~70% for **≥0.4 s** continuous | Eye |
| Dry grit along cord | Loop ≤ −18 dB under bed; optional slow pitch rise | Ear |
| Line micro-vibrate | ±0.5 px at 8–12 Hz while hovering near commit | Hand |
| Culprit nomination | On collapse, the Thread that carried grit longest wins highlight | Speech test |

If collapse is the first time the player hears stress, the toy failed.

## 6. Per-verb sensation dictionary (anti-vague)

| Verb | In one breath | Clock intuition |
|---|---|---|
| **Survey** | Eyes map a tear in the yard; shoulders drop; no clock panic | 2–5 s quiet read |
| **Recover** | Palm fills; pocket takes weight | ~150 ms settle |
| **Bind** | Finger pulls fiber that argues back | Drag continuous; confirm ≤50 ms |
| **Snap** | Dry break; blink; try again | ≤0.55 s total |
| **Tension** | Breath in → cloth gathers → wood hits → dust | 0.9–1.2 s phrase |
| **Collapse** | Tear points a finger; refund rustle | 0.5 s hold + refund |
| **Inhabit** | Boots change voice on your stitch | First plant proves authorship |
| **Residue** | Quiet press; hunger for the next gap | ≤0.4 s stamp |

## 7. Contrasts — what weaving is *not* (timed)

| Fake cousin | Their first second | Weaver’s first second |
|---|---|---|
| Combat hitstop kit | Impact flash + bass drop | Fiber scrape only |
| Builder menu place | Ghost prefab + green check | Ports + provisional chalk |
| Loot pickup | Magnet + chime + rarity | Mass settle into pocket |
| Spell cast | Charge orb + purple bloom | Crease → seat on materials |
| EL rewrite slam | Origami chamber fossil | Structure seats *law you walk* — different toy ([`PIVOT.md`](PIVOT.md)) |

## 8. Input contract (parity)

| Device | Draw | Tension commit | Undo last Thread |
|---|---|---|---|
| Mouse/KB | Click-drag from port; release on port | Dedicated key / button (not same as draw release) | One clear control |
| Gamepad | Aim + trigger pull stretch; shoulder to pin | Face button hold ≥150 ms or dual-tap confirm | Dedicated face/shoulder |

**Ban:** mouse-only pixel precision as the only legal bind. Sticky ports (≥12–16 px / generous stick aim) required for teach fields.

**Anti-mash:** Tension cool-down ≥350 ms after seat or collapse before next commit.

## 9. Acceptance tests (feel)

| Gate | Pass |
|---|---|
| **Hum test** | After three stands, tester can hum/clap the seat phrase timing without picture |
| **Mute trailer** | 60–90 s silent capture still reads parts → line → place → walk |
| **Palm test** | Blindfolded assistant feels Recover vs empty click as different (haptic optional; audio+animation must carry if no rumble) |
| **Culprit speech** | On collapse, player names the failing seam without opening help |
| **Foot proof** | First step on Structure is audibly/visually different from yard dirt |
| **Retry clock** | Failed tension → change one Thread → stand again in **≤30 s** |
| **Language ban** | Doc review finds zero unexplained “satisfying/juicy/immersive” claims |

## 10. Implementation notes (for W1 spike)

Not a full tech design — fences for the feel proof in [`ROADMAP.md`](ROADMAP.md) W1:

1. Author seat phrase as a **timed state machine** (Arm/Crease/Lift/Seat/Settle), not a single VFX prefab.  
2. Drive scrape pitch from `span_cost` / stress, not from a random modulator.  
3. Collapse highlight uses the same stress accumulator the solver used — no separate “drama pick.”  
4. Footstep material tag flips the frame the Structure enters `Stand`.  
5. Record acceptance clips at 60 fps; judge against §3 clock table, not vibes.

---

## 11. Lock line

Weaving feels like **weight, scrape, breath, wood, dust, then feet** — on a clock you can point at. If you cannot say what the player’s hand and ear are doing at `t=0.4` of a seat, you are not designing Weaver yet; you are describing a mood board.
