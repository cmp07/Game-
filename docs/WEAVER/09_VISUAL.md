## 0. Thesis

The Weaver is a **void-weave** toy: you recover craft atoms, pull fiber across a **frayed gap** (the void in the field), tension a Structure, then inhabit what you authored. Pixels must say *workshop page / textile loom* — never cosmic dungeon, never Echo Lattice maze rebrand.

**One-line brief:** _Dusty shed light on fiber, timber, and kiln copper — stitch the gap, live in the seam._

**Still test:** mute audio, crop UI. A stranger must say “parts became a bridge/gate” — not “purple magic ruins.”

## 1. Hard ban — purple-void AI look

| Banned | Why |
|---|---|
| Near-black cosmic void clear color, nebula gradients | Default generative-fantasy plate |

| Soft painterly haze, god-rays, volumetric “aether” fog | Enchantment language; we seat fiber, we do not radiate |
| Glassmorphism, frosted HUD, holographic rarity borders | OS chrome / loot ladder |
| Chronoshard / hourglass / “time fragment” iconography | Banned cliché lane |
| Prefab neon build ghosts, sci-fi hard-light bridges | Wrong shelf (risk D5 / D6) |
| Echo Lattice chamber UI pasted as Weaver shell | Separate SKU ([`PIVOT.md`](PIVOT.md)); no store mash |

**Allowed “void”:** the **physical gap** in a frayed field (missing span, starved basin, torn load path). Render as torn paper edge, dust fall, missing planks — never chroma-purple emptiness.

## 2. Material language (single identity)

Borrow craft warmth from Field Ledger lessons; do **not** inherit maze chrome.

| Material | Role | Notes |
|---|---|---|
| **Page / cloth substrate** | Field surface | Warm bone paper or raw canvas; fiber grain visible |
| **Dust / chalk** | Provisional Threads, survey marks | Dashed slack fiber before Tension |
| **Ink / seated seam** | Passed Tension | Taut Threads become inked stitches |
| **Timber / wire** | Span / Anchor silhouettes | Greyscale-readable family shapes |
| **Kiln rust / copper** | Heat, Charge, stress creep | Only accent family — ≤10% of frame |
| **Shed light** | Single practical lamp / skylight | Hard-ish falloff; no bloom stack |

**Ratio intuition (per field frame):** ~60% substrate · ~25% craft objects (Fragments/Structures) · ~10% Threads · ≤5% kiln accent · ≤1% warn flash on illegal snap.

## 3. Object grammar (what must read)

### 3.1 Fragments

Six MVP families — one silhouette language each ([`03_FRAGMENTS.md`](03_FRAGMENTS.md) §3):

| Family | Visual tell |
|---|---|
| **Span** | Beam / plank / cloth strip; length reads capacity |
| **Anchor** | Peg, stake, weight; grounded mass |
| **Channel** | Culvert / trough / duct |
| **Charge** | Spring, bladder, kiln-heart; stored push |
| **Filter** | Sieve, baffle, one-way flap |
| **Pulse** | Pendulum, bellows, knocker |

Ports = **glyphs on the body**, not paragraph tooltips. Capacity = thickness / stitch density — not DPS numbers. Seat = press into cloth/page — never Pokémon catch beam.

### 3.2 Threads

| State | Look |
|---|---|
| Provisional | Dashed chalk / slack fiber across the gap |
| Healthy seated | Taut ink seam |
| Approaching overload | Rust creep along the Thread |
| Illegal snap | White flash → settle; name the port conflict in one glyph |
| Tear | Gap at culprit — collapse comedy readable in one glance |

Drawing feels like **pulling fiber across a page**, not RTS power lines.

### 3.3 Structures

Stood graphs only ([`05_STRUCTURES.md`](05_STRUCTURES.md)). Stand juice: **crease → lift → seat** (quiet weight). Archetypes (Span, Culvert, Kiln, Gate, Scaffold, Loom-mark) remix families — no prefab house menu art.

### 3.4 Frayed field / void weave

The field presents scarcity: torn margin, missing load path, open air over a drop. Trailer beat = Thread stretched **across the void** then Tension seats a walkable law. The gap is the antagonist; purple cosmos is not.

## 5. Signature moment — Tension seat (visual half)

Align with Structure juice contract:

| Stage | Must show | Must not |
|---|---|---|
| Pull | Fiber drawn across gap; chalk slack | Energy beam |
| Crease | Cloth/page gathers at pins | Screen warp bloom |
| Lift | Brief cast shadow / weight | Rim-light magic |
| Seat | Seam locks; Structure becomes walkable/usable law | Portal swallow, confetti |
| Stress tell | Rust creep if near fail | Floating red DPS |

**Sync:** audio owns the same seat phrase ([`10_AUDIO.md`](10_AUDIO.md) §4). Progression never paints Tension as XP level-up ([`11_PROGRESSION.md`](11_PROGRESSION.md)).

## 6. Motion craft

| Allowed | Forbidden |
|---|---|
| Fiber draw, press-seat, dust settle, stamp residue | Idle UI breathe/pulse, tracking “cinematic” reveals |
| Illegal snap + settle | Full-screen glitch / chromatic explosion |
| Reduce-motion → hard seat / cut | Ugly time-stretch of physics |

Ship **2–3 intentional motions** on shell + Tension. Physics readability > particle noise.
