## 0. One sentence

Enter a frayed field → recover **Fragments** → bind them with **Threads** → tension a **Structure** → inhabit what you wove → leave a residue the next field must answer.

```
Survey → Recover → Bind → Tension → Inhabit → Residue → next field
```

If a feature does not serve one of those six beats, it is not core loop.

---

## 1. Fantasy contract

| Lock | Meaning |
|---|---|
| **Craft, not conquest** | You author local law; you do not clear a combat arena |
| **Readable authorship** | A stranger watching a 20s clip should see *parts → relations → place* |
| **Fair toy** | Deterministic rules; softlock-safe; short retries; same seed → same grammar |
| **Offline-first** | The loop never requires a network to feel complete |
| **One pure category** | Systems authorship / spatial craft puzzle — not idle, not horror, not coin, not deckbuilder |

**Player line after first clear structure:** *“I wove that — and now I have to live in it.”*

---

## 2. Session shape

| Beat | Player verb | System answer | Fail / retry feel |
|---|---|---|---|
| **1. Survey** | Enter a field; read fray, anchors, scarce slots | Field presents a solvable scarcity (missing law, broken load path, starved basin) | Quiet — no timer panic on enter |
| **2. Recover** | Pick / sift / unstick Fragments in the field | Fragments are local atoms with typed ports (see [`03_FRAGMENTS.md`](03_FRAGMENTS.md)) | Wrong pick is cheap; inventory stays tiny |
| **3. Bind** | Draw Threads between Fragment ports | Typed relations (feed, brace, oppose, echo…) validate or reject | Illegal bind snaps with a craft tell, not a red error toast |
| **4. Tension** | Commit the graph → Structure stands | Graph solver tense-checks load, cycles, starve; Structure rewrites cells | Collapse is readable (*why* it failed); undo one tension |
| **5. Inhabit** | Walk / route / use the Structure to solve the field goal | Goal is spatial / systems (reach, irrigate, brace, silence a fault) — never kill-count | Death/reset returns Fragments you owned; world residue may persist by design |
| **6. Residue** | Leave the field | Stable Structures + chosen residue seed the next field’s grammar | Pride beat: stamp / silhouette of *your* cloth panel |

Target first-clear of a teaching field: **3–8 minutes**. Trailer verb must land inside **60–90 seconds**.

## 4. Resources (loop economy — tiny)

| Resource | Role in loop | Hard cap (MVP intuition) |
|---|---|---|
| **Fragment slots** | How many atoms you may carry unbound | 3–5 |
| **Thread budget** | How many relations you may draw before tension | 4–8 |
| **Tension commits** | How many Structure stands per field (usually 1–2) | 1 teaching / 2 mastery |
| **Residue marks** | Persistent authorship that biases the next field | 1 signature + optional scrap |

No parallel currencies (gems, stamina bars, battle pass). Scarcity is **ports, spans, and collapse risk**.

---

## 5. Win / lose / retry

| Outcome | Condition | Player read |
|---|---|---|
| **Field clear** | Goal predicate true while at least one Structure stands (or the field allows a no-Structure teach) | Stamp / quiet cloth panel |
| **Collapse** | Tension fails load / cycle / starve checks | Graph shows the failing Thread or overloaded Fragment |
| **Softlock** | Forbidden — always a legal recover or undo path | BFS / solver net in content tools |
| **Abandon** | Player leaves; no shame economy | Residue optional; never wipe account |

Stars / ranks (if any) score **economy of Threads** and **elegance of graph**, never speed-run tax as the only grade.

---

## 6. Teaching ladder (first hour)

| Field | Teaches | Must feel |
|---|---|---|
| F0 | Recover one Fragment, one Thread, one Structure, walk the result | “Parts became place” |
| F1 | Port mismatch / illegal bind | Craft snap, not UI lecture |
| F2 | Collapse from overload | Failure is information |
| F3 | Two Structures in sequence (scaffold → span) | Composition |
| F4 | Residue biases the next field | The loom remembers your hand |

Ceremony scarcity: one **First Stand** moment (first Structure that truly rewrites the floor) — protect it like Echo Lattice protected Mirror Birth.

## 7. Juice beats (loop-critical only)

| Beat | Feel |
|---|---|
| Bind confirm | Fiber pull / ink settle — short |
| Illegal snap | Dry break; ports flash once |
| Tension stand | Crease → lift → seat (origami of cloth, not explosion) |
| Collapse | Seam tear with readable culprit highlight |
| Clear stamp | Quiet press into paper/textile hybrid |

No combat hitstop kit. No purple bloom. No loot fountain.

---

## 8. Explicit non-goals (core loop)

| Out | Why |
|---|---|
| Combat encounters as the clear condition | Wrong fantasy |
| RNG loot behind the Structure | Authorship dopamine ≠ slot dopamine |
| Infinite procedural fields with three verbs | Demoware |
| Live-service daily login as the loop spine | Offline-first |
| Time-rewind / chronomancy as the primary verb | Banned cliché lane (see Fragments) |
| Echo Lattice chamber rewrite as a required subsystem | EL is frozen craft lesson; Weaver loop is Fragment→Thread→Structure |

---

## 9. Acceptance tests

| Gate | Pass |
|---|---|
| **Clip test** | 60–90s silent capture shows recover → bind → stand → walk |
| **Still test** | One frame of a standing Structure reads as woven law, not a prop crate |
| **Speech test** | Player can say what failed on collapse without opening a help screen |
| **Retry test** | Failed tension → adjust one Thread → stand, under 30s |
| **Purity test** | Removing “AI / multiplayer / idle” words does not empty the pitch |

---

## 10. Lock line

Weaver’s core loop is a **fair craft cycle**: scarce Fragments, honest Threads, Structures you must inhabit — then a residue that proves the loom learned your hand.
