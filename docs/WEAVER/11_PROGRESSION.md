## 0. Thesis

Progression in The Weaver is **deeper void-weave literacy**: fewer, smarter Threads; Structures you can inhabit; a gallery of cloth panels that are *yours*. Scarcity is ports, spans, and collapse risk — not currencies.

**Spine:**

```
Survey → Recover → Bind → Tension → Inhabit → Residue → next job
```

**Player line:** *“I wove that — and now I have to live in it.”*

**Weaver rule:** unlocks appear as workshop stamps and new craft nouns — never neon level-ups. Visual/audio craft ([`09_VISUAL.md`](09_VISUAL.md), [`10_AUDIO.md`](10_AUDIO.md)) own celebration materials.

## 2. What “progress” means (four layers)

| Layer | Player feels | Systems | Must not become |
|---|---|---|---|
| **Literacy** | “I know which port takes a Brace” | Teaching Yard jobs F0… ([`02_CORE_LOOP.md`](02_CORE_LOOP.md) §6) | Tip-stack slides |
| **Catalog** | “I earned a wider Span / a Pulse” | Fragment families & tiers (S/M/L plain names) | Loot rarity |
| **Authorship** | “That gate is mine” | Structure recipes; inhabit requirement | Prefab build menu meta |
| **Memory** | “I can see what I stood” | Local gallery + ghost replays ([`17_MVP.md`](17_MVP.md) §3.5) | Server monuments / housing MMO |

If a feature does not feed one of these four, it is out of MVP progression scope.

## 3. Unlock order (MVP craft)

Authority: [`17_MVP.md`](17_MVP.md) §3.5 — thin and honest.

| Stage | Unlocks | Gate |
|---|---|---|
| **1 — Hands** | Recover + carry 3–5 Fragments; chalk Thread draw; undo | Complete Survey/Recover teach job |
| **2 — Stitch** | Four Thread types (Brace, Feed, Oppose, Echo) introduced one-at-a-time | Illegal snap literacy before next type |
| **3 — Seat** | Tension commit; collapse readability; first Structure stand | Inhabit clears the job — build-alone does not |
| **4 — Recipes** | ≤8 Structure recipes in vertical slice; ≤20 at MVP 1.0 | Jobs first; catalog never outruns jobs (risk D3) |
| **5 — Yard corners** | More contracts / optional second corner at 1.0 | Not open-world tourism |
| **6 — Gallery** | Local Structures + ghosts | No trade, no seasons |

**Content mountain reminder:** vertical slice ≈ 1 Yard, 4–6 Fragment families, Thread literacy, 3 Structures, 8–12 jobs. Do not schedule World/Legacy/Multiplayer as MVP unlocks.

## 4. Job board progression (not a skill tree)

| Beat | Craft |
|---|---|
| Job list | Authored Yard contracts; one primary accept predicate each |
| Difficulty | Harder graphs, tighter Thread budgets, inhabit timing — never HP |

| Fail | Collapse is comedy + lesson; refund Fragments per [`03_FRAGMENTS.md`](03_FRAGMENTS.md); abandon without shame |

Teaching ladder lives in core loop + first-thirty docs; this doc only asserts: **jobs teach verbs**, recipes do not replace jobs. How combinations are hinted without a spoiler wiki: [`22_DISCOVERY_UX.md`](22_DISCOVERY_UX.md).

## 5. Residue as the long loop

On field clear ([`05_STRUCTURES.md`](05_STRUCTURES.md) §7):

1. **Silhouette stamp** — recognition / gallery / share still  
2. **Bias tag** (light) — next field may favor or counter your archetype  
3. **Scrap Fragment** — optional S-tier leftover — **never** a purple drop  

Full economy / legacy policy may live in `07_ECONOMY` / `08_LEGACY` when authored. MVP: local gallery is enough pride.

**Daily / shared seed (post or thin):** “same loom, different hands” — offline comparable codes OK; never gate campaign jobs on appointment modes.

## 10. Acceptance playtest (one evening)

1. Cold player completes one Structure job without tip-stack drowning (risk D1).  
2. Unlock of a second Thread type happens only after illegal-snap literacy.  
3. Clear requires **inhabit**, not merely Tension.  
4. No XP bar, rarity gems, or purple level-up anywhere in shell.  
5. Gallery shows a recognizable silhouette without UI chrome.  
6. Session scarcity (slots/budget) never confused with meta currencies.
