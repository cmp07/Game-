# Echo Lattice — Quality Bar

**Product:** Echo Lattice  
**Repo:** [cmp07/Game-](https://github.com/cmp07/Game-) (working tree historically nicknamed *sandpile-tycoon*; that is not the Steam product name)  
**Locked fantasy:** pure **habit → geometry** authorship labyrinth — a Field Ledger that fossilizes how you walk.  
**This doc’s job:** extract **craft standards** (polish, presentation, moment design) from top puzzle / authorship-adjacent Steam games — **not** to mash their genres into Echo Lattice.

Companion authorities: [`../ECHO_LATTICE/00_OVERVIEW.md`](../ECHO_LATTICE/00_OVERVIEW.md) · [`../ECHO_LATTICE/05_ART_BIBLE.md`](../ECHO_LATTICE/05_ART_BIBLE.md) · [`../ECHO_LATTICE/07_JUICE.md`](../ECHO_LATTICE/07_JUICE.md) · [`../AUDIT/DESIGN_GAMEPLAY.md`](../AUDIT/DESIGN_GAMEPLAY.md) · [`../GAME_PLAN.md`](../GAME_PLAN.md)

## 0. Non-goals (read first)

| Do | Do not |
|---|---|
| Steal **craft**: pedagogy, restraint, punchline timing, diegetic presentation, feedback honesty | Steal **genres**: FPS puzzle, 1-bit deduction sim, rule-block Sokoban, open-world knowledge RPG, Metroidvania secrets |
| Keep one verb: walk → checkpoint → transform → fossil walls → goal | Add combat, HP, loot, slots, coin physics, idle prestige, deckbuilding |
| Treat comps as a **quality ceiling** Echo Lattice must clear | Pitch Echo Lattice as “Witness + Baba + Buckshot” on a store page |

**Hard rule (same as catalog strategy):** one pure category per Steam product. Echo Lattice ships as a **2D habit→geometry puzzle / authorship toy**. Tension-vignette, coin-machine, and idle/particle products are **separate** later games — never hybridized here.

## 3. Craft standards Echo Lattice must hit

Each standard is phrased as a **ship gate**: pass/fail language for RC polish and content review. Map to Field Ledger pillars in the art bible where noted.

### 3.1 Polish — every input earns a layered answer

| # | Standard | Borrowed from | Echo Lattice test |
|---|---|---|---|
| P1 | **One verb, infinite clarity** — the core action is obvious in the first minute; mastery deepens *that* verb, not a toolbox sprawl | Parabox, Baba, Portal | A muted clip of Quiet Span → Mirror Birth sells walk → checkpoint → wall without voiceover |
| P2 | **Punctuated authorship** — the commit beat (rewrite) has hitstop, stinger, and origami slam; it never feels like a soft toggle | Juice craft across Portal / Cocoon; our [`07_JUICE.md`](../ECHO_LATTICE/07_JUICE.md) | Rewrite is the loudest honest moment in a chamber; not drowned by shake/particles |
| P3 | **Fair failure, fast retry** — softlocks are impossible or one-button recoverable; undo/restart are first-class | Witness pedagogy (front-load faulty assumptions safely); Portal chamber reset culture | BFS safety net + undo across rewrites; death/stuck → retry under ~2 s friction |
| P4 | **No placeholder in the hero path** — Act I + Mirror Birth + menus that appear in trailer/demo use final materials, type, and audio policy | Cocoon / Lorelei store trust | Demo gate: no purple-void tiles, no missing caption, no silent rewrite |
| P5 | **Accessibility without apologizing for the look** — reduce-motion, flash gate, colorblind fossil roles, remappable input | Industry floor for authorship indies | Options match release a11y doc; Field Ledger stays readable under each toggle |

### 3.2 Presentation — the frame is a document, not a mood board

| # | Standard | Borrowed from | Echo Lattice test |
|---|---|---|---|
| R1 | **Legibility above spectacle** — a still frame explains the loop | Witness panels; Cocoon restraint; Obra Dinn’s one look | Art pillar P1: stranger sees “walls are footprints” in ≤5 s |
| R2 | **One material language end-to-end** — paper / ink / rust / slate; menus, chambers, capsules, trailer share one grammar | Lorelei monochrome hotel; Obra Dinn 1-bit commitment; Gorogoa hand-frame unity | No neon purple, cyber glow, or glass HUD overlays on the hero path (art ban list) |
| R3 | **Diegetic chrome** — HUD is page header + punch-card ribbon, not floating RPG glass | Cocoon (almost no HUD); Obra Dinn pocketwatch as tool | Seed, transform, buffer live as ledger UI; cadmium ≤1% of frame |
| R4 | **Cartographer honesty** — every particle/flash names the data it encodes | Witness environmental panels; Cocoon interact tells | Juice that doesn’t teach (decorative bloom, aimless grit) is cut |
| R5 | **Store page is the same game** — capsule/screenshot/trailer show the playable Field Ledger, not a mood collage | Cocoon / Lorelei / Animal Well store discipline | Partner slate matches in-game Mirror Birth composition |

### 3.3 Moment design — setup, insight, signature

| # | Standard | Borrowed from | Echo Lattice test |
|---|---|---|---|
| M1 | **Puzzle-as-joke** — buildup, misdirection-of-habit, punchline | Lorelei (“structured like a good joke”); Baba insight levels | Each chamber teaches **one** rewrite idea; the clear is the punchline, not a checklist |
| M2 | **Teach → remix → identity** — introduce clean, remix under pressure, then ask for a legible signature | Portal chamber arcs; Witness region themes; our Act → boss identity plan | Acts Induction → Reflection → Pressure → Mastery; bosses leave a readable portrait (loop, barcode, face, negative space) |
| M3 | **First-hook moment is non-negotiable** | Portal’s first portal; Baba’s first rule break; Obra Dinn’s first triple-lock | **Mirror Birth** must land in demo/trailer as the product hook — path becomes wall, caption + motif aligned |
| M4 | **Certainty beats spinning wheels** | Obra Dinn’s three-correct lock-in | Stars, undo, telegraph, and win readout confirm *what you authored*; player never wonders if the rewrite “counted” |
| M5 | **Observation resolution rises** | Witness midgame world-panels; Animal Well attention rewards | Late Acts make *habits* readable (lean, loop, zigzag) — not just *this path*; reactive authorship is the north-star gap to close |
| M6 | **Silence is a tool** | Cocoon / Obra Dinn restraint; our audio silence policy | Early Induction stays quiet enough that the first operator stinger and rewrite slam *matter* |

## 4. What “good enough for Steam” means here

Echo Lattice does **not** need Witness’s island density or Lorelei’s cipher count. It **does** need their **finish quality on a smaller surface**.

| Axis | Floor (ship) | Ceiling (aspire) |
|---|---|---|
| Session | Demo proves Mirror Birth + one remix in a short clip | Full campaign: four Acts, identity bosses that *judge* the portrait |
| Feel | Every rewrite is punctuated and readable | Habit archetype actually biases geometry (reactive authorship toy) |
| Look | Field Ledger materials on all hero-path screens | Wing tints + authored audio stems; zero procedural placeholders on store assets |
| Fairness | No softlocks; undo; colorblind roles | Hard+ / daily / endless share the same honest verb |
| Store | Capsules + 5+ screenshots that pass the 5-second loop test | Trailer beat sheet where Mirror Birth is the irreversible “want” moment |

If a feature raises systems count without raising **authorship legibility**, it fails this bar.

---

## 5. Anti-patterns (automatic fail)

- Genre mash store copy (“horror coin-pusher puzzle idle”).
- Glow-on-void / purple mystery default; shake-as-spectacle that muddies the ledger.
- Tutorial walls of text that replace a Quiet Span → Echo Plate → Mirror Birth teach path.
- Chambers that introduce two rewrite ideas at once.
- Identity bosses that are only “denser mazes” with no portrait intent.
- Juice that sells combat impact on a non-combat verb.
- Citing RACCOIN, Particul, Windrose, Wildfrost, or Brawlhalla as *Echo Lattice* comps (wrong lane).
- Cloning Buckshot Roulette’s premise while claiming originality.

## 6. Review checklist (use on content / juice / store PRs)

Copy into PR descriptions when touching hero-path craft:

- [ ] Still sells habit → geometry with audio muted  
- [ ] One new idea per chamber; punchline on clear  
- [ ] Rewrite commit has layered feedback (sight + weight + time) without illegible shake  
- [ ] Diegetic HUD / Field Ledger materials only  
- [ ] Mirror Birth (or equivalent first authorship beat) intact if demo-adjacent  
- [ ] No banned palette / genre mash / wrong-comp naming  
- [ ] Failure recoverable; solvability net not used as design crutch  
- [ ] Screenshot/trailer candidate would not look like another brand if the logo were removed
