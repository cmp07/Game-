## 0. One sentence

A Field Ledger labyrinth that **fossilizes how you walk into walls** — you escape by rewriting your own habits, not by beating RNG, combat, or loot.

```
Walk → trail → checkpoint → walls become your handwriting → walk differently.
```

That sentence is the product. Everything below is how it becomes a **finished indie** instead of a clever vertical slice.

---

## 1. Fantasy pillar (locked)

### 1.1 The fantasy

You are a surveyor inside a printed document. The page is honest: every wall you meet later is a transcript of how you moved earlier. The lattice does not *fight* you with enemies; it **answers** you with geometry. Recognition — “that orange scribble is me” — is the dopamine, not kill-feed, payout, or number-go-up.

| Pillar | Player promise | Ship test |
|---|---|---|
| **Habit → geometry** | My path becomes architecture | Blind player names the loop from one still of a rewrite slam |
| **Reactive authorship** | The lattice answers my *style*, not only this path | After Act II, player can say “it punished my looping” without HUD jargon |
| **Field Ledger look** | Ink on paper, rust calcification — never glow-on-void | Frame reads as a document; no purple bloom / combat juice default |
| **Fair toy** | Deterministic, softlock-safe, short retries | Same seed → same rules; BFS net; undo; stars never gate story |
| **Offline first** | Full campaign / Daily / Endless without network | Steam optional; friend-code compare without ranked ladders |

### 1.2 Why this fantasy is 1000× *and* shippable

**1000×** is not “more systems.” It is **one verb made undeniable** across store, demo minutes 0–3, campaign climax, Daily return, and Museum retention — so strangers feel authorship in under ninety seconds and owners still feel named by their handwriting weeks later.

**Shippable** means the verb already exists on RC1 (walk → checkpoint → forced transform → origami slam → goal → stars). The vision upgrades *legibility, reactivity, ceremony, and retention around that verb* — not a new genre on top of it.

### 1.3 Category purity

| Shelf | Echo Lattice |
|---|---|
| Primary | **Puzzle** · Minimalist · Singleplayer · Replay Value |
| Session shape | Short deterministic wing; GIF-able rewrite slam |
| Price band | **$4.99–$9.99** (list **$6.99**) |
| Explicitly not | Horror vignette, roguelike loot, idle tycoon, coin machine, deckbuilder, AI dungeon |

`GAME_PLAN.md` once ranked “tension / horror vignette” as Game 1 for *format economics* (short, clip-friendly, low-$ band). Echo Lattice **kept the economics** and **resolved into pure puzzle**. That resolution is final.

## 2. Emotional arc

The campaign is not a plot about saving a city. It is a **relationship with your own habits**, staged as four ledger chapters.

| Act | Emotional job | Felt beat | Failure mode if thin |
|---|---|---|---|
| **I — Induction** | Curiosity → first authorship | Quiet silence → **Mirror Birth** recognition shock | Slam reads as VFX, not “I did that” |
| **II — Reflection** | Self-consciousness | Dual-axis literacy; you see yourself from two directions | Remix fatigue before Portrait lands |
| **III — Pressure** | Unease / ownership | Habits *hurt* — thicken / densify as consequence of overuse | Theme without teeth (forced op only) |
| **IV — Mastery** | Signature / release | You compose transforms and **sign** a nameplate | Climax is “harder maze,” not portrait |

### 2.1 Micro-arc of a single chamber (the unit of feeling)

1. **Survey** — chalk ghost, paper floor, no lecture.  
2. **Tension** — cadmium telegraph: the page is about to remember you.  
3. **Commit** — origami crease → lift → slot → rust bleed.  
4. **Recognition** — the new walls are legibly *yours*.  
5. **Rewrite the self** — walk differently through your own fossil.  
6. **Stamp** — stars / habit title / (bosses) ledger silhouette.

### 2.2 Meta emotional loop (after clear)

| Loop | Feeling | 1.0 necessity |
|---|---|---|
| Campaign clear | Completion of a signed document | Required |
| Daily shared seed | “Same page, different handwriting” | Required (shipped core) |
| Endless climb | Pressure without new genre | Thin vertical OK if same verb |
| **Museum of Selves** | Archive who you were; race your chalk | **Required for finished indie** |
| Stars / archetype titles | Cleaner handwriting, named habit | Required for mastery feel |

## 3. Signature moments

These are the **clip / memory / trailer** beats. If marketing, demo, or Act structure buries them, the product is invisible.

### 3.1 Must-ship ceremony set

| Moment | Intent | Player memory line | Design bar |
|---|---|---|---|
| **Mirror Birth** | First authorship | “My path became wall.” | Teach without essay; slam readable at 1280×800; post-slam one-line coach |
| **Looking Glass** | Second birth (dual axis) | “It sees both sides of me.” | Unique PA + slam chroma within ledger; Mirror-Birth-tier ceremony |
| **First Thicken** | Habit solidifies underfoot | “I walked it into stone.” | Visual verb = calcification, not spark |
| **Who Walked** | Induction portrait | “That’s my signature.” | Visible ledger stamp differing by route |
| **Portrait / Calcify / Nameplate** | Act bosses as identity | “The maze is a picture of how I move.” | Signature metrics or stamp gallery — not only denser `REACH_GOAL` |
| **Daily friend-code clear** | Social without MP | “We walked the same seed.” | Offline comparable string; same UTC chamber + variation |
| **Museum race self** | Retention fantasy | “I’m racing yesterday’s me.” | Chalk overlay; deaths never archive; cap selves |

### 3.2 Trailer / store still hierarchy

1. Field Ledger brand + paper page (brand-first, not eyebrow).  
2. Telegraph → origami slam mid-point (muted-safe open).  
3. Rust fossil silhouette that is obviously a walk path.  
4. End card: recognition / “it learned you” energy **without** combat juice or AI dungeon copy.

Anti-still: purple void, enemy sprites, loot cards, horror antagonist close-ups, “mysterious labyrinth” without the handwriting reveal.

## 4. Non-negotiables

Break these and you are making a different game.

### 4.1 Systems

1. **One verb.** Walk → trail → checkpoint → transform → fossil walls → goal. No combat, HP, enemies, inventory, or loot for 1.0.  
2. **Determinism.** Seeded rules; Daily is calendar/catalog authority, not server RNG.  
3. **Solvability honesty.** BFS safety net stays; authors do not design softlock traps.  
4. **Stars never gate progression.** Mastery is optional handwriting quality.  
5. **Lessons stay forced.** Pedagogy chambers teach one transform; soft habit bias belongs on remix / Daily / Endless, never on first lessons.  
6. **Undo is a player right** in Standard/Reader; Cold may tighten — never remove fairness for marketing difficulty.  
7. **Offline complete.** Steam Cloud / achievements degrade; no always-online gate.

### 4.2 Art & juice (Field Ledger)

1. **Ink on paper, not glow on void.** Ban neon purple, bloom spectacle, vaporwave grids.  
2. **Fossilization, not radiance.** Rust / silt / crease — not particle fireworks as default.  
3. **Cadmium warn = one heartbeat** for rewrite-imminent; not constant combat flash.  
4. **Screen shake / hitstop / confetti are opt-in Impact,** default off — document fantasy first.  
5. **Diegetic HUD.** Punch-card / seed header language over translucent gamer chrome.  
6. **Legibility above spectacle.** If a still cannot explain the loop in one sentence, cut the flourish.

### 4.3 Product & store

1. **Never lead with AI / mystery / loot / horror.** Store freeze stays honest: habits, Daily, Endless, handmade chambers.  
2. **Demo spine is sacred:** Quiet Span → Echo Plate → **Mirror Birth** inside ~0–3 minutes.  
3. **One wishlist CTA** at demo end (real AppID) — no link farm.  
4. **Price stays in band** ($4.99–$9.99; recommend $6.99).  
5. **DLC fence:** Act V / Workshop / cosmetics MX are post-1.0 or never — not launch blockers.

## 5. Anti-mash fences

Hard fences so scope panic cannot reintroduce a second fantasy.

| Temptation | Why it shows up | Fence |
|---|---|---|
| Horror stakes meter / antagonist | Old Game 1 research lane | **Out.** Keep clip length; reject shotgun-roulette structure and fear-HP |
| Enemies / pulsars / combat juice | Stale `07_JUICE.md` TS arena | **Out of product.** Archive as non-product; Godot Field Ledger only |
| Deckbuilder transforms-as-cards | “More mastery” urge | **Out.** Transforms are chamber grammar, not a build |
| Roguelike loot / meta unlock trees that change verbs | Retention anxiety | **Out.** Unlocks open chambers / modes / Museum — not new combat verbs |
| Idle automation / particle tycoon | Sibling product taste | **Separate Steam product later** — never inside Echo Lattice |
| Coin-pusher / slot debt | Adjacent heat | **Separate product** — never mash |
| Generative AI dungeon / chatbot narrator | Trend bait | **Out.** Deterministic authored content; compliance AI = No |
| Online ranked ladders / live seasons | Live-ops pressure | **Out for 1.0.** Friend codes + local Museum only |
| Battle pass / gacha cosmetics | Revenue panic | **Never** |
| Act V before Museum / slam gold | Content mountain cosplay | **Fence.** Finish the verb’s home before adding chapters |

**Fence test:** If a feature still works after you remove habit→geometry recognition, it does not belong in Echo Lattice.

## 6. What “finished indie” means *for this game*

Not “AAA content mountain.” Not “systems RPG.” A finished Echo Lattice is a **complete authorship toy** with a sharp store face and a return loop that still speaks the same sentence.

### 6.1 Definition of Done — Finished Indie 1.0

| Surface | Done means |
|---|---|
| **Fantasy** | Blind playtester describes habit→walls without reading the store page |
| **Campaign** | Acts I–IV playable end-to-end; four identity bosses leave **visible stamps** |
| **Reactivity** | At least once per mid/late chamber (remix/Daily/Endless), habit style visibly biases or counters geometry — deterministically |
| **Demo** | Cold clear to Mirror Birth <3 min; Act I finish → one wishlist CTA; no late-act spoilers in PCK |
| **Daily** | UTC calendar/catalog featured + eligible fillers; friend-code comparable; offline |
| **Endless** | Same verb, rising rewrite pressure; best depth local — not a new genre |
| **Museum** | Clear → archive Self; browse; race chalk ghost; deaths excluded |
| **Look/Feel** | Field Ledger defaults (paper slam first); production audio earprints per transform; placeholder art/audio gone from store surfaces |
| **Store** | Real AppID; final capsules/screenshots/trailer; frozen copy pasted; Coming Soon convertible |
| **Trust** | Offline ship bar green; a11y flash/motion gates honest; Windows (+ Deck path) bugbash cleared |
| **Fence** | No Act V / Workshop / MX / online ladder required to call it 1.0 |

### 6.2 Explicitly *not* required for finished indie

- Full VO novel  
- Online ghosts / leaderboards  
- Reader/Cold if balance dials are deleted instead of shipped (truth > dead UI)  
- macOS notarized public SKU  
- Procedural infinite content claims  
- Every balance_v2 lever if it fights the pure puzzle fantasy (prefer delete over fake)

### 6.3 Success feelings (acceptance quotes)

A 1.0 build may claim the vision when strangers and owners produce lines like:

1. “The walls are my walk.”  
2. “It punished my looping.”  
3. “That’s my signature on the ledger.”  
4. “Same daily seed — different handwriting.”  
5. “I’m racing yesterday’s me.”

## 8. Sequencing toward the vision (no mash)

Aligned with product-upgrade read order; vision priority is **conversion → verb gold → retention → deepen same systems**.

```
1. Store oxygen     — AppID, capsules, trailer encode, freeze paste, Coming Soon
2. Demo oxygen      — Mirror Birth <3 min, slam readability, production SFX for teach path
3. Thesis oxygen    — habit answer legible; boss stamps; Looking Glass ceremony
4. Retention oxygen — Museum race self, streaks, Daily share string
5. Truth oxygen     — juice defaults, balance dials ship-or-delete, doc congruence
6. Only then        — NG+/Short Run polish, wing paper tints, post-1.0 DLC fence items
```
